# リポジトリ取得手順

## 一文方針

- clone 直後に `bash tools/docs_lint/run_lint.sh` が exit 0 になることを「リポジトリ取得完了」の唯一の定義とし、baseline が green でない状態で formal 軸の作業を開始しない。

> **pre-P0 注記**: `tools/docs_lint/` は P2 deliverable、`src/` は P10 deliverable。pre-P0 時点では以下のコマンドは実行不可。`git clone` 完了 + `ls docs/` で docs/ 存在確認をもって代替とする。

## clone 手順

```bash
git clone <repo-url> k1s0
cd k1s0
```

デフォルトブランチは `main`。作業ブランチは `main` からのみ切る。

## .gitignore の確認

```bash
cat .gitignore
# 確認項目: __pycache__/ *.pyc *.pyo .venv/ が含まれること
```

## venv の用意

clone 後に venv を作成し PyYAML を入れる。

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## baseline lint 確認

```bash
bash tools/docs_lint/run_lint.sh
```

exit 0 が得られれば baseline が green。exit 1 の場合はエラーを確認し、dangling link や schema 変更漏れを修正してから次の手順に進む。

## formal 軸固有の確認

clone 後、proof spec サンプルが正しいパスに存在することを確認する。

```bash
ls docs/05_環境構築/10_formal/
# README.md および 01_責務とスコープ.md ～ 14_Claude_Code連携.md が存在すること
```

## 検収コマンド

```bash
bash tools/docs_lint/run_lint.sh && echo "BASELINE GREEN"
python3 tools/docs_lint/run_lint.py && echo "PYTHON LINT GREEN"
```
