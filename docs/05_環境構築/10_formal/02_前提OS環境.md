# 前提 OS 環境

## 一文方針

- formal 軸エンジニアの開発環境は **WSL2 + Ubuntu 22.04 LTS 以上** を前提とし、Java 21（Apalache / TLA+ Toolbox 用）と JVM 17+（Stainless 用）を必須とする。Lean 4 の mathlib ビルドには 16GB RAM を推奨する。

## OS 構成

| 項目 | 必須値 | 理由 |
|---|---|---|
| ホスト OS | Windows 11 | draw.io Desktop の安定動作保証（共通要件） |
| Linux 環境 | WSL2 + Ubuntu 22.04 LTS 以上 | Java / Rust / Python の各ツールが apt / rustup でインストール可能 |
| WSL2 バージョン | 2.0 以上 | `/mnt/c/` マウントの信頼性 |
| Java | 21（LTS） | Apalache（JVM 実行）および TLA+ Toolbox 実行環境 |
| JVM | 17 以上 | Stainless の最低動作要件 |
| RAM | 16GB 以上を推奨 | Lean 4 + mathlib フルビルド時にメモリ不足を避けるため |
| git | 2.40 以上 | `git log --format` の安定 |
| bash | 5.0 以上 | `set -euo pipefail` / `<<<` heredoc 安定 |
| GNU coreutils | Ubuntu 標準 | find / awk / grep / sort / uniq / sed / mktemp |

## Java 21 のインストール

```bash
sudo apt update
sudo apt install -y openjdk-21-jdk
java -version   # openjdk 21.x を確認
```

既に Java 17 が入っている環境では Stainless は動作するが、Apalache は Java 21 を推奨するため 21 を優先する。`update-alternatives` で複数バージョンを切り替えることも可能。

```bash
# 複数バージョンが存在する場合のデフォルト設定
sudo update-alternatives --config java
```

## Rust / cargo のインストール

Kani は `cargo install kani-verifier` で導入するため Rust ツールチェインが必要。

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source ~/.cargo/env
rustup update stable
```

## WSL2 が使えない場合

Linux ネイティブ環境（Ubuntu 22.04 以上）でも動作する。その場合、draw.io Desktop 連携が手動エクスポートになる点を除き、全ツールが同様に動作する。

## 検収コマンド

```bash
uname -r          # WSL2 kernel (例: 5.15.xx-microsoft-standard-WSL2)
java -version     # openjdk 21.x
git --version     # git 2.40 以上
bash --version    # bash 5.0 以上
rustc --version   # Rust ツールチェイン確認
```
