# テスト検証環境

## 一文方針

- 5 proof_class（TLA+ / Dafny / Lean 4 / Kani / CBMC）それぞれの sample proof をローカルで実行し、全て pass することを「テスト検証環境の構築完了」の定義とする。また counter-example が発生した場合に閉鎖する演習を必ず行う。

## proof_class 1: TLA+ sample（tlc）

```tla
---- MODULE HelloSpec ----
EXTENDS Naturals
VARIABLES x
Init == x = 0
Next == x' = x + 1
Spec == Init /\ [][Next]_x
====
```

上記を `HelloSpec.tla` として保存し、TLC で検査する。

```bash
tlc HelloSpec.tla -deadlock
# 期待: "No error has been found." または deadlock メッセージ
```

## proof_class 2: Apalache sample

```tla
---- MODULE CounterApalache ----
EXTENDS Integers
VARIABLE x
TypeOK == x \in Int
Init == x = 0
Next == x' = x + 1
====
```

```bash
apalache-mc check --length=5 CounterApalache.tla
# 期待: "Verification PASSED" (bounded check 5 steps)
```

## proof_class 3: Dafny sample

```dafny
method Add(a: int, b: int) returns (result: int)
  ensures result == a + b
{
  result := a + b;
}
```

上記を `Sample.dfy` として保存し検証する。

```bash
dafny verify Sample.dfy
# 期待: "Sample.dfy: Verified" と表示される
```

## proof_class 4: Lean 4 sample

```lean
theorem add_comm (n m : Nat) : n + m = m + n := by
  omega
```

上記を `Sample.lean` として保存し検証する。

```bash
lean Sample.lean
# 期待: エラーなく終了する
```

## proof_class 5: Kani sample

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}

#[cfg(kani)]
#[kani::proof]
fn check_add() {
    let a: i32 = kani::any();
    let b: i32 = kani::any();
    let _ = add(a, b);
}
```

上記を Rust プロジェクト内の `src/lib.rs` として保存し検証する。

```bash
cargo kani
# 期待: "VERIFICATION:- SUCCESSFUL"
```

## counter-example 閉鎖演習

意図的に不正な spec を作成し、counter-example が出力されることを確認する。その後 spec を修正して閉鎖する。

```bash
# TLA+ での例: 境界違反を意図的に作成
# apalache-mc check --length=2 BrokenSpec.tla
# counter-example を確認し、仮定の追加や型制約の強化で閉鎖
```

## 検収コマンド

```bash
# 5 proof_class の sample spec を実行して全 pass を確認
echo "=== TLA+ ===" && tlc HelloSpec.tla -deadlock 2>&1 | tail -3
echo "=== Dafny ===" && dafny verify Sample.dfy 2>&1 | tail -3
echo "=== Lean 4 ===" && lean Sample.lean 2>&1
echo "=== Kani ===" && cargo kani 2>&1 | tail -3
echo "=== CBMC ===" && cbmc cbmc_sample.c 2>&1 | tail -3
```
