# 必須ランタイム

## 一文方針

- formal 軸エンジニアは TLA+ CLI（`tlc`）/ Apalache（`apalache-mc`）/ Dafny CLI（`dafny`）/ Lean 4 + mathlib（`elan` 経由）/ Kani（`cargo kani`）/ CBMC（`cbmc`）/ Stainless（`stainless-dotty`）の 7 ツールを全て手元で動作させることを必須とする。

## ランタイム一覧

| ツール | コマンド | インストール方法 | 用途 |
|---|---|---|---|
| TLA+ CLI | `tlc` | 手動ダウンロード（tla2tools.jar） | TLA+ spec の構文検査・モデル検査 |
| Apalache | `apalache-mc` | 手動ダウンロード（Java jar） | TLA+ の型付き bounded model checking |
| Dafny CLI | `dafny` | GitHub Releases バイナリ | 証明付きプログラム検証 |
| Lean 4 | `lean` | `elan` ツールチェインマネージャー | 定理証明 / Mathlib 利用 |
| Kani | `cargo kani` | `cargo install kani-verifier` | Rust コードの形式検証 |
| CBMC | `cbmc` | apt（`cbmc` パッケージ） | C / C++ のバウンデッドモデル検査 |
| Stainless | `stainless-dotty` | GitHub Releases jar | Scala コードの形式検証 |

## Python（lint ツール連携用）

`tools/docs_lint/run_lint.py` は Python 3.12 を要求する。共通手順（`00_k1s0作者` 参照）に従い venv を作成する。

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## バージョン固定方針

各ツールのバージョンは `docs/05_環境構築/10_formal/` の `05_主要OSS導入.md` にバージョン番号を明記する。CI で使用するバージョンと手元バージョンを一致させ、diff による false positive を防ぐ。

## 検収コマンド

```bash
java -jar ~/tools/tla2tools.jar -help 2>&1 | head -3  # TLA+ tlc 応答確認
apalache-mc help 2>&1 | head -3                        # Apalache 応答確認
dafny --version                                         # Dafny CLI 応答確認
lean --version                                          # Lean 4 応答確認
cargo kani --version                                    # Kani 応答確認
cbmc --version                                          # CBMC 応答確認
```
