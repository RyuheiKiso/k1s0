# 検収基準

## 一文方針

- `kubectl version` / `helm version` / `kind version` / `istioctl version` / `argocd version` の 5 コマンド全応答 + kind cluster が green を「infra 軸環境構築完了」の検収条件とし、1 つでも欠けた場合は完了とみなさない。

## 検収チェックリスト

以下を全て満たすこと。

### 必須ランタイム

```bash
kubectl version --client
# → v1.30.x 以上

helm version --short
# → v3.15.x 以上

kustomize version
# → v5.x.x 以上

kind version
# → kind v0.23.0 以上
```

### 主要 OSS

```bash
argocd version --client
# → argocd: v2.x.x 以上

istioctl version --remote=false 2>/dev/null
# → Istio バージョン応答

calicoctl version
# → Client Version: vx.x.x

bao --version
# → OpenBao バージョン応答

cosign version
# → GitVersion: v2.x.x 以上

litmusctl version
# → バージョン応答
```

### kind cluster

```bash
kind get clusters | grep k1s0
# → クラスタ名が表示される

kubectl get nodes
# → 全ノードが Ready

kubectl get pods -n kyverno | grep -c Running
# → 1 以上（kyverno が Running）

kubectl get pods -n argocd | grep -c Running
# → 1 以上（argocd-server が Running）
```

### docs_lint

> **pre-P0 注記**: `tools/docs_lint/` は P2 deliverable（pre-P0 時点で実体ゼロ）。以下の手順は P2 完了後に有効。

```bash
bash tools/docs_lint/run_lint.sh 2>&1 | tail -1
# → === docs_lint: 7 check 全 green ===

python3 tools/docs_lint/run_lint.py 2>&1 | tail -1
# → === docs_lint (Python): 8 check 全 green ===
```

## 一括検収スクリプト

```bash
set -e
echo "=== infra 軸 環境構築 検収 ==="

echo "[1/4] 必須ランタイム確認"
kubectl version --client --short 2>/dev/null || kubectl version --client
helm version --short
kustomize version
kind version

echo "[2/4] 主要 OSS 確認"
argocd version --client 2>/dev/null | head -1
istioctl version --remote=false 2>/dev/null | head -1 || true
cosign version 2>/dev/null | head -1

echo "[3/4] kind cluster 確認"
kind get clusters

echo "[4/4] docs_lint 確認"
bash tools/docs_lint/run_lint.sh 2>&1 | tail -1
python3 tools/docs_lint/run_lint.py 2>&1 | tail -1

echo "=== 検収完了 ==="
```
