# リポジトリ取得手順

## 一文方針

- clone 直後に `bash tools/docs_lint/run_lint.sh` が exit 0 になることを「リポジトリ取得完了」の唯一の定義とする。それ以前の状態で cluster 操作を開始しない。

## clone 手順

```bash
git clone <repo-url> k1s0
cd k1s0
```

デフォルトブランチは `main`。infra 作業ブランチは `main` からのみ切る。k8s manifest は `src/` 配下の各軸ディレクトリに配置する。

## .gitignore の確認

```bash
cat .gitignore
# 確認項目: __pycache__/ *.pyc .venv/ が含まれること
# kubeconfig は絶対に commit しないこと
```

## Python venv の用意

docs_lint 実行のために Python venv を作成する。

```bash
sudo apt update && sudo apt install -y python3.12 python3.12-venv
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## baseline lint 確認

```bash
bash tools/docs_lint/run_lint.sh
```

exit 0 が得られれば baseline が green。exit 1 の場合はエラーを確認し修正してから次の手順に進む。

## root allowlist 検査

```bash
python3 tools/docs_lint/run_lint.py 2>&1 | grep -E "FAIL|green"
```

root 直下に許可外ファイルを置いた場合も FAIL になる。`kubeconfig` や cluster 接続情報を root に置かないこと。

## 検収コマンド

```bash
bash tools/docs_lint/run_lint.sh && echo "BASELINE GREEN"
python3 tools/docs_lint/run_lint.py && echo "PYTHON LINT GREEN"
```
