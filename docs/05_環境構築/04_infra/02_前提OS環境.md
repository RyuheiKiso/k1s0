# 前提 OS 環境

## 一文方針

- infra 軸エンジニアの開発環境は **WSL2 + Ubuntu 22.04 LTS 以上** を前提とし、Docker Desktop または Docker Engine (WSL2 内) が必須である。kind cluster は Docker 上で動作するため Docker なしでは検証環境が成立しない。

## OS 構成

| 項目 | 必須値 | 理由 |
|---|---|---|
| ホスト OS | Windows 11 または Linux | WSL2 または ネイティブ Linux |
| Linux 環境 | WSL2 + Ubuntu 22.04 LTS 以上 | kubectl / kind / helm が apt / binary でインストール可能 |
| WSL2 バージョン | 2.0 以上 | Docker Engine の安定動作 |
| Docker | Docker Desktop 4.x または Docker Engine 24.x | kind が Docker を要求 |
| git | 2.40 以上 | GitOps manifest 管理 |
| bash | 5.0 以上 | cluster 操作スクリプト |
| GNU coreutils | Ubuntu 標準 | find / awk / grep / sort / uniq / sed |

## Docker のインストール確認

Docker Desktop（Windows 側）を使う場合は WSL2 integration を有効にする。WSL2 内に直接 Docker Engine をインストールする場合は以下を実行する。

```bash
sudo apt update
sudo apt install -y docker.io
sudo usermod -aG docker $USER
# ログアウト後に再ログインして反映
docker --version
```

## WSL2 で kind が動作するための設定

kind は Docker を使って k8s cluster を起動する。WSL2 で Docker daemon が動作していることを確認する。

```bash
docker info
# ERROR がなければ OK
```

## 検収コマンド

```bash
uname -r          # WSL2 kernel (例: 5.15.xx-microsoft-standard-WSL2)
git --version     # git 2.40 以上
bash --version    # bash 5.0 以上
docker --version  # Docker 24.x 以上
docker info 2>&1 | grep "Server Version"
```
