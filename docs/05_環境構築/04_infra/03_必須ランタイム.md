# 必須ランタイム

## 一文方針

- infra 軸エンジニアは kubectl 1.30+ / helm 3.15+ / kustomize 5+ / kind 0.23+ の 4 ツールを必須ランタイムとし、全て PATH に入っていることを確認してから次の手順に進む。

## kubectl のインストール

```bash
curl -LO "https://dl.k8s.io/release/$(curl -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
chmod +x kubectl
sudo mv kubectl /usr/local/bin/kubectl
kubectl version --client
# バージョンが 1.30 以上であること
```

## helm のインストール

```bash
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash
helm version
# バージョンが 3.15 以上であること
```

## kustomize のインストール

```bash
curl -s "https://raw.githubusercontent.com/kubernetes-sigs/kustomize/master/hack/install_kustomize.sh" | bash
sudo mv kustomize /usr/local/bin/kustomize
kustomize version
# バージョンが 5.x 以上であること
```

## kind のインストール

```bash
curl -Lo ./kind https://kind.sigs.k8s.io/dl/v0.23.0/kind-linux-amd64
chmod +x ./kind
sudo mv ./kind /usr/local/bin/kind
kind version
# kind v0.23.0 以上であること
```

## バージョン固定方針

CI で使うバージョンと手元のバージョンに差が生じると manifest の挙動が変わる。バージョンを上げる場合は `.github/workflows/` の設定と同時に変更し、dual sign-off を経てから反映する。

## 検収コマンド

```bash
kubectl version --client --short 2>/dev/null || kubectl version --client
helm version --short
kustomize version
kind version
```

4 コマンド全て応答することを確認する。
