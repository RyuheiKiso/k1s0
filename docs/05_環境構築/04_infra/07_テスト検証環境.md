# テスト検証環境

## 一文方針

- `kind create cluster` でローカル k8s cluster を起動し、Kyverno policy apply と admission test / Litmus chaos experiment を手元で実行できることを infra 軸の検証環境確認条件とする。

> **pre-P0 注記**: `src/` は P10 deliverable（pre-P0 時点で実体ゼロ）。以下の手順は P10 完了後に有効。

## kind cluster の起動

```bash
# クラスタ設定ファイルを作成（multi-zone 相当）
cat <<'EOF' > /tmp/kind-config.yaml
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
nodes:
  - role: control-plane
  - role: worker
    labels:
      topology.kubernetes.io/zone: zone-a
  - role: worker
    labels:
      topology.kubernetes.io/zone: zone-b
  - role: worker
    labels:
      topology.kubernetes.io/zone: zone-c
EOF

kind create cluster --name k1s0-local --config /tmp/kind-config.yaml
kubectl get nodes
```

全ノードが `Ready` 状態になることを確認する。

## Kyverno のインストールと policy テスト

```bash
# Kyverno のインストール
helm repo add kyverno https://kyverno.github.io/kyverno/
helm repo update
helm install kyverno kyverno/kyverno -n kyverno --create-namespace

# Kyverno が Ready になるまで待機
kubectl rollout status deployment kyverno -n kyverno

# サンプル ClusterPolicy の適用テスト
cat <<'EOF' | kubectl apply -f -
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata:
  name: require-labels
spec:
  validationFailureAction: audit
  rules:
    - name: check-for-labels
      match:
        any:
          - resources:
              kinds:
                - Pod
      validate:
        message: "The label 'app.kubernetes.io/name' is required."
        pattern:
          metadata:
            labels:
              app.kubernetes.io/name: "?*"
EOF

kubectl get clusterpolicy require-labels
```

## admission test の実行

Kyverno policy が正しく機能するかをテストする。

```bash
# ラベルなし Pod の作成を試みる（audit mode のため作成されるが警告が記録される）
kubectl run test-no-label --image=nginx:alpine
kubectl get policyreport -A

# クリーンアップ
kubectl delete pod test-no-label 2>/dev/null || true
```

## Litmus chaos experiment のローカル実行

```bash
# Litmus ChaosHub のインストール
helm repo add litmuschaos https://litmuschaos.github.io/litmus-helm/
helm repo update
helm install chaos litmuschaos/litmus -n litmus --create-namespace

# インストール確認
kubectl get pods -n litmus
```

## クラスタのクリーンアップ

```bash
kind delete cluster --name k1s0-local
```

作業終了後は必ずクリーンアップする。

## 検収コマンド

```bash
kind get clusters | grep k1s0-local
kubectl get nodes --context kind-k1s0-local
kubectl get clusterpolicy -A
```

kind cluster が起動中で、Kyverno policy が適用されていることを確認する。
