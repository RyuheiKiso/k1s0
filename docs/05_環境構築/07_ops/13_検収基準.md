# 検収基準

## 一文方針

- Backstage local / Grafana local / Prometheus local の 3 コンテナが全て Up であり、`k6 run --version` が応答し、docs_lint が green になることが ops 軸エンジニアの環境構築完了の唯一の定義である。

> **pre-P0 注記**: `src/` および `tools/` は P0〜P10 deliverable（pre-P0 時点で実体ゼロ）。以下の検収コマンドは各 Phase 完了後に有効。

## 検収項目一覧

| # | 検収項目 | 検収コマンド | 期待結果 |
|---|---|---|---|
| 1 | WSL2 + Docker 動作 | `docker version` | Docker Engine 24.0 以上 |
| 2 | kubectl 動作 | `kubectl version --client` | バージョン表示 |
| 3 | helm 動作 | `helm version` | v3.x.x 表示 |
| 4 | grafana-cli 動作 | `grafana-cli --version` | バージョン表示 |
| 5 | k6 動作 | `k6 version` | k6 v0.x.x 表示 |
| 6 | Argo Rollouts CLI 動作 | `kubectl-argo-rollouts version` | バージョン表示 |
| 7 | Tekton CLI 動作 | `tkn version` | バージョン表示 |
| 8 | Backstage コンテナ起動 | `docker compose up -d` + `docker compose ps` | 全コンテナ Up |
| 9 | Grafana 起動 | `curl -s http://localhost:3000/api/health` | 200 OK |
| 10 | Prometheus 起動 | `curl -s http://localhost:9090/-/ready` | Prometheus is Ready |
| 11 | docs_lint bash | `bash tools/docs_lint/run_lint.sh`（P2 deliverable） | exit 0 |
| 12 | docs_lint python | `python3 tools/docs_lint/run_lint.py`（P2 deliverable） | 8 check 全 green |
| 13 | VS Code extension | `code --list-extensions` | grafana / yaml / backstage 含む |
| 14 | techdocs-cli 動作 | `techdocs-cli --version` | バージョン表示 |

## 全項目一括確認スクリプト

```bash
#!/bin/bash
set -euo pipefail
echo "=== ops 軸エンジニア 環境構築 検収 ==="

check() { echo -n "[$1] $2 ... "; eval "$3" > /dev/null 2>&1 && echo "OK" || echo "FAIL"; }

check 1  "Docker"               "docker version"
check 2  "kubectl"              "kubectl version --client"
check 3  "helm"                 "helm version"
check 4  "grafana-cli"          "grafana-cli --version"
check 5  "k6"                   "k6 version"
check 6  "Argo Rollouts CLI"    "kubectl-argo-rollouts version"
check 7  "Tekton CLI"           "tkn version"
check 8  "docker compose"       "docker compose version"
check 9  "techdocs-cli"         "techdocs-cli --version"
check 10 "docs_lint bash"       "bash tools/docs_lint/run_lint.sh"
check 11 "docs_lint python"     "python3 tools/docs_lint/run_lint.py"

echo "=== 検収完了 ==="
```
