# 前提 OS 環境

## 一文方針

- ops 軸エンジニアの開発環境は **WSL2 + Ubuntu 22.04 LTS 以上** を前提とし、Docker Engine が WSL2 内で動作することが必須要件である。Grafana / Prometheus / Backstage はコンテナとして起動するため Docker が動かない環境では検証不能である。

## OS 構成

| 項目 | 必須値 | 理由 |
|---|---|---|
| ホスト OS | Windows 11 | Docker Desktop の安定動作保証 |
| Linux 環境 | WSL2 + Ubuntu 22.04 LTS 以上 | kubectl / helm / k6 が apt / binary で安定インストール可能 |
| WSL2 バージョン | 2.0 以上 | Docker Engine の memory 制御安定 |
| Docker Engine | 24.0 以上 | compose v2 / buildkit が標準 |
| git | 2.40 以上 | `git log --format` の安定 |
| bash | 5.0 以上 | `set -euo pipefail` / `<<<` heredoc 安定 |
| GNU coreutils | Ubuntu 標準 | find / awk / grep / sort / uniq / sed / mktemp |

## Docker Engine の確認

```bash
docker version
docker compose version  # Docker Compose v2 (plugin 形式)
```

Docker Desktop for Windows を使う場合は WSL2 backend を有効化する。Docker Desktop が入っていない場合は WSL2 内で直接インストールする。

```bash
# Ubuntu WSL2 での Docker Engine インストール（Docker Desktop 不使用の場合）
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list
sudo apt update && sudo apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
sudo usermod -aG docker $USER
```

## WSL2 のメモリ制限

Grafana + Prometheus + Backstage を同時起動するため、WSL2 に最低 4GB を割り当てる。

```ini
# %USERPROFILE%\.wslconfig
[wsl2]
memory=8GB
processors=4
```

## 検収コマンド

```bash
uname -r          # WSL2 kernel (例: 5.15.xx-microsoft-standard-WSL2)
git --version     # git 2.40 以上
bash --version    # bash 5.0 以上
docker version    # Docker Engine 24.0 以上
docker compose version  # Compose v2
```
