# 必須ランタイム

## 一文方針

- ops 軸エンジニアは kubectl / helm / grafana-cli / k6 を必須ランタイムとし、Prometheus と Loki は docker 経由で動かすため直接インストール不要とする。ランタイムは全て手元で `--version` 応答が確認できる状態を検収条件とする。

## kubectl インストール

```bash
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
chmod +x kubectl
sudo mv kubectl /usr/local/bin/kubectl
kubectl version --client
```

クラスタへの接続は infra 軸エンジニアが提供する kubeconfig を使う。ops 軸エンジニアはクラスタ構築責務を持たない。

## helm インストール

```bash
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash
helm version
```

## Grafana CLI（grafana-cli）インストール

grafana-cli は Grafana Server のサイドカーとして動作する CLI である。docker で Grafana を動かす場合はコンテナ内で実行する。ローカル検証用にホスト側にも入れる。

```bash
# Ubuntu の場合
sudo apt install -y apt-transport-https software-properties-common wget
wget -q -O - https://apt.grafana.com/gpg.key | sudo gpg --dearmor -o /usr/share/keyrings/grafana.key
echo "deb [signed-by=/usr/share/keyrings/grafana.key] https://apt.grafana.com stable main" | sudo tee /etc/apt/sources.list.d/grafana.list
sudo apt update && sudo apt install -y grafana-cli
grafana-cli --version
```

## k6 インストール

```bash
sudo gpg --no-default-keyring --keyring /usr/share/keyrings/k6-archive-keyring.gpg --keyserver hkp://keyserver.ubuntu.com:80 --recv-keys C5AD17C747E3415A3642D57D77C6C491D6AC1D69
echo "deb [signed-by=/usr/share/keyrings/k6-archive-keyring.gpg] https://dl.k6.io/deb stable main" | sudo tee /etc/apt/sources.list.d/k6.list
sudo apt update && sudo apt install -y k6
k6 version
```

## Prometheus / Loki（docker 経由）

Prometheus と Loki はコンテナとして動かすため直接インストールは不要。05_主要OSS導入 の docker compose 手順で管理する。

```bash
# 動作確認はコンテナ起動後に実行
docker run --rm prom/prometheus --version
docker run --rm grafana/loki --version
```

## Python 3.12 + venv（docs_lint 用）

docs_lint を実行するために Python 3.12 が必要。

```bash
sudo apt install -y python3.12 python3.12-venv
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## 検収コマンド

```bash
kubectl version --client
helm version
grafana-cli --version
k6 version
python3 --version   # 3.12.x
```
