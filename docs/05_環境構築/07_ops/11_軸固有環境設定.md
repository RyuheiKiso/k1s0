# 軸固有環境設定

## 一文方針

- Backstage Software Catalog への software template 適用演習 / on-call シフト rotation 設定 / SLO error budget ローカル計算の 3 演習を全て完了することが、ops 軸固有環境の検収条件である。

## 演習 1: Backstage software template 適用

Backstage を起動した状態で software template を登録し、新しい Component を Catalog に追加する。

```bash
# Backstage 起動（docker compose）
docker compose up -d

# template YAML サンプル（catalog-info.yaml）
cat > /tmp/catalog-info.yaml << 'EOF'
apiVersion: backstage.io/v1alpha1
kind: Component
metadata:
  name: sample-service
  annotations:
    backstage.io/techdocs-ref: dir:.
spec:
  type: service
  lifecycle: production
  owner: ops-team
EOF

# Backstage UI または API で登録
# http://localhost:7007/catalog-import にてファイル URL を指定
```

TechDocs の確認:

```bash
techdocs-cli build --no-docker
```

## 演習 2: on-call シフト rotation 設定

Alertmanager の設定に on-call receiver を定義する演習。

```yaml
# alertmanager.yml サンプル
route:
  group_wait: 30s
  group_interval: 5m
  repeat_interval: 4h
  receiver: ops-oncall
receivers:
  - name: ops-oncall
    webhook_configs:
      - url: 'http://localhost:8080/alert'
```

```bash
# Alertmanager 設定の検証
docker run --rm -v $(pwd)/alertmanager.yml:/etc/alertmanager/alertmanager.yml \
  prom/alertmanager --config.file=/etc/alertmanager/alertmanager.yml --check-config
```

## 演習 3: SLO error budget ローカル計算

```bash
# SLO error budget 計算スクリプト
python3 - << 'EOF'
targets = {
    "availability": 0.999,
    "latency_p95_ms": 200,
}
window_days = 28
total_min = window_days * 24 * 60
availability_budget_min = total_min * (1 - targets["availability"])
print(f"=== SLO Error Budget ({window_days}d window) ===")
print(f"Availability target : {targets['availability']*100:.1f}%")
print(f"Error budget        : {availability_budget_min:.1f} min ({availability_budget_min/60:.2f} h)")
print(f"Latency target      : p95 <= {targets['latency_p95_ms']} ms")
EOF
```

spreadsheet（Google Sheets 等）でも同等の計算を行い、Backstage TechDocs の runbook に記録する。

```bash
# SLO script 実行
python3 -c "
target=0.999; w=28; t=w*24*60; b=t*(1-target)
print(f'Error budget: {b:.1f} min')
"
```
