# リポジトリ取得手順

## 一文方針

- clone 直後に `bash tools/docs_lint/run_lint.sh` が exit 0 になることを「リポジトリ取得完了」の唯一の定義とする。それ以前の状態でデータ操作を開始しない。

## clone 手順

```bash
git clone <repo-url> k1s0
cd k1s0
```

デフォルトブランチは `main`。data 作業ブランチは `main` からのみ切る。データ設定ファイルは `src/` 配下の data 軸ディレクトリに配置する。

## .gitignore の確認

```bash
cat .gitignore
# 確認項目: __pycache__/ *.pyc .venv/ が含まれること
# dump ファイル・バックアップファイルは絶対に commit しないこと
```

data 軸では以下のファイルを `.gitignore` に追加することを推奨する（リポジトリ root の `.gitignore` に既に含まれていない場合）:

```
*.sql.gz
*.dump
*.backup
*.parquet
```

## venv の用意

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## baseline lint 確認

```bash
bash tools/docs_lint/run_lint.sh
```

exit 0 が得られれば baseline が green。

## root allowlist 検査

```bash
python3 tools/docs_lint/run_lint.py 2>&1 | grep -E "FAIL|green"
```

## 検収コマンド

```bash
bash tools/docs_lint/run_lint.sh && echo "BASELINE GREEN"
python3 tools/docs_lint/run_lint.py && echo "PYTHON LINT GREEN"
```
