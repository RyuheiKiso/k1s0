# 前提 OS 環境

## 一文方針

- data 軸エンジニアの開発環境は **WSL2 + Ubuntu 22.04 LTS 以上** を前提とし、Docker Engine（docker compose v2）が必須である。5 OSS サービスは全て docker compose で起動するため Docker なしでは検証環境が成立しない。

## OS 構成

| 項目 | 必須値 | 理由 |
|---|---|---|
| ホスト OS | Windows 11 または Linux | WSL2 または ネイティブ Linux |
| Linux 環境 | WSL2 + Ubuntu 22.04 LTS 以上 | psql / kafka CLI が apt でインストール可能 |
| WSL2 バージョン | 2.0 以上 | Docker Engine の安定動作 |
| Docker | Docker Desktop 4.x または Docker Engine 24.x | docker compose v2 が必要 |
| docker compose | v2.x （`docker compose` サブコマンド形式） | 5 サービスの同時起動 |
| git | 2.40 以上 | データ設定ファイルのバージョン管理 |
| bash | 5.0 以上 | restore_drill スクリプト |

## Docker Compose v2 の確認

`docker compose`（スペース区切り）が動作することを確認する。旧来の `docker-compose`（ハイフン）は Docker Compose v1 であり使用しない。

```bash
docker compose version
# Docker Compose version v2.x.x であること
```

## WSL2 メモリ設定

ClickHouse は大量メモリを消費する。WSL2 のメモリ上限を引き上げることを推奨する。

`%USERPROFILE%\.wslconfig` に以下を追記:

```ini
[wsl2]
memory=8GB
processors=4
```

## 検収コマンド

```bash
uname -r              # WSL2 kernel 確認
docker --version      # Docker 24.x 以上
docker compose version  # v2.x 以上
git --version         # git 2.40 以上
bash --version        # bash 5.0 以上
```
