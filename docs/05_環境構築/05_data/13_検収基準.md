# 検収基準

## 一文方針

- `psql --version` / `docker compose up` で 5 サービス起動 / Apicurio schema register 成功の 3 条件 + docs_lint green を「data 軸環境構築完了」の検収条件とし、1 つでも欠けた場合は完了とみなさない。

## 検収チェックリスト

以下を全て満たすこと。

### 必須ランタイム

```bash
psql --version
# → psql (PostgreSQL) 14.x 以上

kafka-topics.sh --version
# → バージョン応答

clickhouse-client --version
# → バージョン応答

docker compose version
# → Docker Compose version v2.x 以上
```

### 5 OSS サービス起動

```bash
docker compose up -d
docker compose ps | grep -c healthy
# → 5 であること
```

### 接続確認

```bash
psql -h localhost -U k1s0 -d k1s0db -c "SELECT 'OK';" 2>/dev/null | grep -q OK && echo "PostgreSQL: OK"
kafka-topics.sh --bootstrap-server localhost:9092 --list 2>/dev/null && echo "Kafka: OK"
clickhouse-client --host localhost --query "SELECT 'OK'" 2>/dev/null | grep -q OK && echo "ClickHouse: OK"
redis-cli -p 6379 ping 2>/dev/null | grep -q PONG && echo "Valkey: OK"
curl -s http://localhost:8080/health/ready 2>/dev/null | grep -q '"status":"UP"' && echo "Apicurio: OK"
```

### Apicurio schema 登録

```bash
curl -s -X POST \
  http://localhost:8080/apis/registry/v2/groups/acceptance/artifacts \
  -H "Content-Type: application/json; artifactType=AVRO" \
  -H "X-Registry-ArtifactId: acceptance-test" \
  -d '{"type":"record","name":"AccTest","fields":[{"name":"id","type":"string"}]}' \
  | python3 -m json.tool | grep -q '"id"' && echo "Apicurio schema register: OK"
```

### restore_drill 完了確認

```bash
# restore_drill が完了済みであることを確認
psql -h localhost -U k1s0 -d k1s0db -t -c "SELECT 'restore_drill_ok';" 2>/dev/null | grep -q restore_drill_ok && echo "restore_drill: OK"
```

### docs_lint

```bash
bash tools/docs_lint/run_lint.sh 2>&1 | tail -1
# → === docs_lint: 7 check 全 green ===

python3 tools/docs_lint/run_lint.py 2>&1 | tail -1
# → === docs_lint (Python): 8 check 全 green ===
```

## 一括検収スクリプト

```bash
set -e
echo "=== data 軸 環境構築 検収 ==="

echo "[1/4] 必須ランタイム確認"

echo "[2/4] 5 OSS サービス起動確認"

echo "[3/4] Apicurio schema 登録確認"

python3 tools/docs_lint/run_lint.py 2>&1 | tail -1

echo "=== 検収完了 ==="
```
