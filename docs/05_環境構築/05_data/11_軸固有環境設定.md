# 軸固有環境設定

## 一文方針

- 5 OSS ローカル起動成功確認 / Apicurio schema register 演習 / restore_drill 手順一通り実行の 3 ステップを順に完了させ、全て green になることを data 軸固有環境設定の完了条件とする。

## Step 1: 5 OSS ローカル起動成功確認

```bash
# docker-compose.yml があるディレクトリで実行
docker compose up -d

# 全サービスの Healthy 確認
docker compose ps --format "table {{.Name}}\t{{.Status}}"
```

期待される出力（全サービスが healthy）:

```
NAME            STATUS
data-postgres-1     Up (healthy)
data-kafka-1        Up (healthy)
data-clickhouse-1   Up (healthy)
data-apicurio-1     Up (healthy)
data-valkey-1       Up (healthy)
```

接続確認:

```bash
psql -h localhost -U k1s0 -d k1s0db -c "SELECT 'PostgreSQL OK';"
kafka-topics.sh --bootstrap-server localhost:9092 --list && echo "Kafka OK"
clickhouse-client --host localhost --query "SELECT 'ClickHouse OK'"
curl -s http://localhost:8080/health/ready && echo "Apicurio OK"
redis-cli -p 6379 ping | grep -q PONG && echo "Valkey OK"
```

## Step 2: Apicurio schema register 演習

```bash
# Avro スキーマを登録
curl -s -X POST \
  http://localhost:8080/apis/registry/v2/groups/k1s0/artifacts \
  -H "Content-Type: application/json; artifactType=AVRO" \
  -H "X-Registry-ArtifactId: user-event-v1" \
  -d '{
    "type": "record",
    "name": "UserEvent",
    "namespace": "io.k1s0",
    "fields": [
      {"name": "user_id", "type": "string"},
      {"name": "action", "type": "string"},
      {"name": "timestamp", "type": "long"}
    ]
  }' | python3 -m json.tool

# 登録確認
curl -s http://localhost:8080/apis/registry/v2/groups/k1s0/artifacts/user-event-v1 | python3 -m json.tool

# 後方互換スキーマの追加（フィールド追加は BACKWARD 互換）
curl -s -X POST \
  http://localhost:8080/apis/registry/v2/groups/k1s0/artifacts/user-event-v1/versions \
  -H "Content-Type: application/json" \
  -d '{
    "type": "record",
    "name": "UserEvent",
    "namespace": "io.k1s0",
    "fields": [
      {"name": "user_id", "type": "string"},
      {"name": "action", "type": "string"},
      {"name": "timestamp", "type": "long"},
      {"name": "metadata", "type": ["null", "string"], "default": null}
    ]
  }' | python3 -m json.tool
```

## Step 3: restore_drill 手順一通り実行

```bash
echo "=== restore_drill 開始 ==="

# backup
pg_dump -h localhost -U k1s0 k1s0db > /tmp/k1s0_drill_backup.sql
echo "[1/4] backup 完了: $(wc -l < /tmp/k1s0_drill_backup.sql) lines"

# テーブル作成とデータ挿入
psql -h localhost -U k1s0 -d k1s0db -c "
  CREATE TABLE IF NOT EXISTS drill_table (id serial PRIMARY KEY, val text, created_at timestamptz DEFAULT now());
  INSERT INTO drill_table(val) SELECT 'row-' || generate_series FROM generate_series(1, 100);
"

# drop
psql -h localhost -U k1s0 -d k1s0db -c "DROP TABLE IF EXISTS drill_table;"
echo "[2/4] drop 完了"

# restore
psql -h localhost -U k1s0 -d k1s0db < /tmp/k1s0_drill_backup.sql 2>/dev/null
echo "[3/4] restore 完了"

# verify
COUNT=$(psql -h localhost -U k1s0 -d k1s0db -t -c "SELECT COUNT(*) FROM drill_table 2>/dev/null;" 2>/dev/null | tr -d ' ')
echo "[4/4] verify: drill_table row count = ${COUNT:-0}"

echo "=== restore_drill 完了 ==="
```
