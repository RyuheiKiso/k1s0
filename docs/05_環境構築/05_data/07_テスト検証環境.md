# テスト検証環境

## 一文方針

- docker compose 環境での integration test と restore_drill 演習（backup → drop → restore → verify）を一通り実行し、データ欠損なしで完了することを data 軸の検証環境確認条件とする。

## docker compose integration test

5 サービスが起動した状態で接続テストを実行する。

```bash
# PostgreSQL の接続テスト
psql -h localhost -U k1s0 -d k1s0db -c "
  CREATE TABLE IF NOT EXISTS test_table (id serial PRIMARY KEY, val text);
  INSERT INTO test_table(val) VALUES ('k1s0-test-1'), ('k1s0-test-2');
  SELECT COUNT(*) FROM test_table;
"

# Kafka の topic 作成と produce / consume テスト
kafka-topics.sh --bootstrap-server localhost:9092 --create --topic k1s0-test --partitions 1 --replication-factor 1 2>/dev/null || true
echo "k1s0-test-message" | kafka-console-producer.sh --bootstrap-server localhost:9092 --topic k1s0-test
kafka-console-consumer.sh --bootstrap-server localhost:9092 --topic k1s0-test --from-beginning --max-messages 1

# ClickHouse の接続テスト
clickhouse-client --host localhost --query "
  CREATE TABLE IF NOT EXISTS test_table (id UInt64, val String)
  ENGINE = MergeTree() ORDER BY id;
  INSERT INTO test_table VALUES (1, 'k1s0-test');
  SELECT COUNT(*) FROM test_table;
"

# Valkey の接続テスト
redis-cli -p 6379 set k1s0-test "hello"
redis-cli -p 6379 get k1s0-test
```

## restore_drill 演習（PostgreSQL）

restore_drill は「backup → drop → restore → verify」の 4 ステップで実行する。

```bash
# Step 1: backup
pg_dump -h localhost -U k1s0 k1s0db > /tmp/k1s0db_backup.sql
echo "Backup size: $(wc -c < /tmp/k1s0db_backup.sql) bytes"

# Step 2: データの削除（drop テーブル）
psql -h localhost -U k1s0 -d k1s0db -c "DROP TABLE IF EXISTS test_table;"

# Step 3: restore
psql -h localhost -U k1s0 -d k1s0db < /tmp/k1s0db_backup.sql

# Step 4: verify
psql -h localhost -U k1s0 -d k1s0db -c "SELECT COUNT(*) FROM test_table;"
# → 2 rows が返ることを確認（backup 前に挿入した 2 件）
```

## Apicurio スキーマ登録テスト

```bash
# Avro スキーマを Apicurio に登録
curl -s -X POST \
  http://localhost:8080/apis/registry/v2/groups/default/artifacts \
  -H "Content-Type: application/json; artifactType=AVRO" \
  -H "X-Registry-ArtifactId: test-schema" \
  -d '{
    "type": "record",
    "name": "TestEvent",
    "fields": [
      {"name": "id", "type": "string"},
      {"name": "timestamp", "type": "long"}
    ]
  }' | python3 -m json.tool

# 登録確認
curl -s http://localhost:8080/apis/registry/v2/groups/default/artifacts/test-schema | python3 -m json.tool
```

## 検収コマンド

```bash
# restore_drill 完了確認
psql -h localhost -U k1s0 -d k1s0db -c "SELECT COUNT(*) FROM test_table;" 2>/dev/null
# → 2 であること

# Apicurio schema 登録確認
curl -s http://localhost:8080/apis/registry/v2/groups/default/artifacts | python3 -m json.tool 2>/dev/null | grep "test-schema"
```
