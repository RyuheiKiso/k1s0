# 必須ランタイム

## 一文方針

- data 軸エンジニアは psql（PostgreSQL CLI）/ kafka-topics.sh（Kafka CLI）/ ClickHouse CLI / Docker Compose 2+ の 4 ツールを必須ランタイムとし、全て PATH に入っていることを確認してから次の手順に進む。

## PostgreSQL CLI (psql) のインストール

```bash
sudo apt update
sudo apt install -y postgresql-client
psql --version
# psql (PostgreSQL) 14.x 以上
```

サーバー本体は不要。CLI クライアントのみインストールする。docker compose で起動した PostgreSQL に接続するために使用する。

## Kafka CLI のインストール

Kafka CLI は Kafka の binary パッケージに含まれる。Java が必要。

```bash
sudo apt install -y default-jdk-headless
# Kafka binary のダウンロード
curl -LO https://downloads.apache.org/kafka/3.7.0/kafka_2.13-3.7.0.tgz
tar xf kafka_2.13-3.7.0.tgz
sudo mv kafka_2.13-3.7.0 /opt/kafka
# PATH への追加
echo 'export PATH="$PATH:/opt/kafka/bin"' >> ~/.bashrc
source ~/.bashrc
kafka-topics.sh --version
```

## ClickHouse CLI のインストール

```bash
curl https://clickhouse.com/ | sh
sudo ./clickhouse install
clickhouse-client --version
```

## Docker Compose のバージョン確認

```bash
docker compose version
# Docker Compose version v2.x 以上であること
```

## Python venv（docs_lint 用）

```bash
sudo apt install -y python3.12 python3.12-venv
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
python3 --version  # 3.12.x
```

## 検収コマンド

```bash
psql --version
kafka-topics.sh --version
clickhouse-client --version
docker compose version
```

4 コマンド全て応答することを確認する。
