# 軸固有環境設定

## 一文方針

- ops 軸固有の環境設定として、KEK shamir M-of-N ceremony ローカル rehearsal / break-glass dry-run 演習 / audit hash chain ローカル replay の 3 演習を完走することを必須とし、production KEK は本ページのスコープ外とする。

## 演習 1: KEK shamir M-of-N ceremony ローカル rehearsal

production KEK は本番 ceremony でのみ生成する。本演習はローカルで手順を体得するための rehearsal である。

```bash
# OpenBao dev mode 起動
bao server -dev -dev-root-token-id="root-token" &
export BAO_ADDR='http://127.0.0.1:8200'
export BAO_TOKEN='root-token'

# M=3, N=5 での operator init rehearsal
bao operator init \
  -key-shares=5 \
  -key-threshold=3 \
  -format=json > /tmp/init-output.json 2>&1

# 出力確認
cat /tmp/init-output.json | python3 -c "
import json, sys
data = json.load(sys.stdin)
print('unseal_keys_b64:', len(data.get('unseal_keys_b64', [])), 'keys')
print('root_token: present' if data.get('root_token') else 'root_token: missing')
"
```

3 つの unseal key を使って unseal する。

```bash
bao operator unseal $(cat /tmp/init-output.json | python3 -c "import json,sys;d=json.load(sys.stdin);print(d['unseal_keys_b64'][0])")
bao operator unseal $(cat /tmp/init-output.json | python3 -c "import json,sys;d=json.load(sys.stdin);print(d['unseal_keys_b64'][1])")
bao operator unseal $(cat /tmp/init-output.json | python3 -c "import json,sys;d=json.load(sys.stdin);print(d['unseal_keys_b64'][2])")
bao status | grep Sealed
# 期待: Sealed: false
```

演習後は rehearsal で生成した key を全て削除する。

```bash
rm /tmp/init-output.json
kill %1 2>/dev/null || true
```

## 演習 2: break-glass dry-run 演習

kind cluster がローカルで動いている場合に実行する（kubeconfig の設定が前提）。

```bash
kubectl --as=system:masters get pods --all-namespaces --dry-run=client
# 期待: dry-run 出力が表示される（実際の変更なし）
```

dry-run 実行後、postmortem テンプレートを作成して手順を確認する。

```bash
cat > /tmp/breakglass-rehearsal-postmortem.md << 'TEMPLATE'
# break-glass rehearsal postmortem

## 日時
2026-05-13 (rehearsal)

## 実行内容
kubectl --as=system:masters get pods --dry-run=client

## 理由
環境構築演習のための rehearsal

## 事後対応
rehearsal のため実際の変更なし
TEMPLATE
echo "postmortem テンプレート: 作成完了"
```

## 演習 3: audit hash chain ローカル replay

```bash
# audit hash chain の手動作成例
LOG_ENTRIES=("2026-05-13T00:00:00Z action=init" "2026-05-13T00:01:00Z action=unseal" "2026-05-13T00:02:00Z action=seal")
PREV_HASH=""
for entry in "${LOG_ENTRIES[@]}"; do
    CURRENT=$(echo "${PREV_HASH}${entry}" | sha256sum | awk '{print $1}')
    echo "entry: ${entry} | hash: ${CURRENT}"
    PREV_HASH=$CURRENT
done
echo "audit hash chain replay: 完了"
```
