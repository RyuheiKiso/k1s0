# 検収基準

## 一文方針

- `bao --version` / `ykman --version` / `kubectl version --client` / `cosign version` の全コマンドが正常応答し、shamir assembly 演習完了 / break-glass dry-run 完了 / audit hash chain replay 成功の 3 演習が完走することがプラットフォーム運営者の環境構築完了の唯一の定義である。

## 検収コマンド一覧

```bash
# 1. OpenBao CLI
bao --version
# 期待: "OpenBao vX.Y.Z" の形式でバージョンが表示される

# 2. ykman
ykman --version
# 期待: "YubiKey Manager X.Y.Z" の形式でバージョンが表示される

# 3. kubectl
kubectl version --client
# 期待: "Client Version: vX.Y.Z" が表示される

# 4. cosign
cosign version
# 期待: "GitVersion: vX.Y.Z" が表示される

# 5. shamir assembly 演習完了確認
echo "演習 1 (shamir assembly): 完走を口頭・文書で確認済みか確認する"

# 6. break-glass dry-run 完了確認
echo "演習 2 (break-glass dry-run): 完走を口頭・文書で確認済みか確認する"

# 7. audit hash chain replay 確認
echo "test" | sha256sum && echo "演習 3 (audit hash chain): sha256sum 利用可能"
```

## 検収チェックリスト

| 項目 | コマンド | 期待 |
|---|---|---|
| OpenBao CLI 応答 | `bao --version` | バージョン表示 |
| ykman 応答 | `ykman --version` | バージョン表示 |
| kubectl 応答 | `kubectl version --client` | バージョン表示 |
| cosign 応答 | `cosign version` | バージョン表示 |
| shamir assembly 演習 | 11_軸固有環境設定 演習 1 | 完走 |
| break-glass dry-run | 11_軸固有環境設定 演習 2 | 完走 |
| audit hash chain replay | 11_軸固有環境設定 演習 3 | 成功 |
| docs lint | `bash tools/docs_lint/run_lint.sh` | exit 0 |

上記 8 項目を全て満たした時点で「プラットフォーム運営者の環境構築完了」とする。
