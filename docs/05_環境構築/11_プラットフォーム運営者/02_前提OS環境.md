# 前提 OS 環境

## 一文方針

- プラットフォーム運営者の開発環境は **WSL2 + Ubuntu 22.04 LTS 以上** を前提とし、Yubikey PIV ハードウェアトークンは production ceremony では必須、演習環境では optional とする。

## OS 構成

| 項目 | 必須値 | 理由 |
|---|---|---|
| ホスト OS | Windows 11 | Yubikey manager GUI の安定動作 |
| Linux 環境 | WSL2 + Ubuntu 22.04 LTS 以上 | OpenBao / kubectl / ykman が apt でインストール可能 |
| WSL2 バージョン | 2.0 以上 | `/mnt/c/` マウントの信頼性 |
| git | 2.40 以上 | `git log --format` の安定 |
| bash | 5.0 以上 | `set -euo pipefail` 安定 |
| GNU coreutils | Ubuntu 標準 | find / awk / grep / sort / uniq |

## Yubikey PIV の要件

| 環境 | Yubikey 要件 |
|---|---|
| production ceremony | Yubikey 5 Series 以上（PIV 対応）を物理的に保持すること |
| ローカル rehearsal（演習） | Yubikey なしで OpenBao のソフトウェア shamir を使用可能 |

Yubikey は USB ポートに挿入し、`ykman piv info` で認識されることを確認する。

```bash
ykman piv info
# 期待: "PIV version: X.X.X" が表示される
```

## USB パススルー設定（WSL2）

WSL2 では USB デバイスを使うために `usbipd-win` を使ったパススルーが必要。

```powershell
# Windows 側（PowerShell）でインストール
winget install usbipd
usbipd list              # Yubikey の busid を確認
usbipd attach --wsl --busid <busid>
```

```bash
# WSL2 側で確認
lsusb | grep Yubico
ykman info
```

## WSL2 が使えない場合

Linux ネイティブ環境（Ubuntu 22.04 以上）でも動作する。Yubikey は USB 直接接続で利用可能。

## 検収コマンド

```bash
uname -r          # WSL2 kernel 確認
git --version     # git 2.40 以上
bash --version    # bash 5.0 以上
ykman --version   # ykman インストール確認（演習環境でも必須）
```
