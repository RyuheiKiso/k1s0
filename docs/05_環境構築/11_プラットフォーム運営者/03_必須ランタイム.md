# 必須ランタイム

## 一文方針

- プラットフォーム運営者は OpenBao CLI（`bao`）/ Cosign（`cosign`）/ Grafana CLI（`grafana-cli`）/ kubectl / ykman の 5 ツールを全て手元で動作させることを必須とし、Python venv（PyYAML）は docs lint 実行のために追加で用意する。

## ランタイム一覧

| ツール | コマンド | インストール方法 | 用途 |
|---|---|---|---|
| OpenBao CLI | `bao` | binary ダウンロード | KEK shamir ceremony / break-glass |
| Cosign | `cosign` | binary ダウンロード | artifact 署名検証 |
| Grafana CLI | `grafana-cli` | apt | 監視ダッシュボード管理 |
| kubectl | `kubectl` | apt / binary | production cluster 操作 |
| ykman | `ykman` | pip / apt | Yubikey PIV 管理 |

## Python（docs lint 連携用）

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## バージョン固定方針

ツールのバージョンは `05_主要OSS導入.md` に明記する。production 環境で使用するバージョンと手元バージョンを一致させ、rehearsal と本番の diff を最小化する。

## 検収コマンド

```bash
bao --version             # OpenBao CLI 応答確認
cosign version            # Cosign 応答確認
kubectl version --client  # kubectl 応答確認
ykman --version           # ykman 応答確認
```
