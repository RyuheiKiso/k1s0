# リポジトリ取得手順

## 一文方針

- clone 直後に `bash tools/docs_lint/run_lint.sh` が exit 0 になることを「リポジトリ取得完了」の唯一の定義とし、baseline が green でない状態でオペレーション作業を開始しない。

## clone 手順

```bash
git clone <repo-url> k1s0
cd k1s0
```

デフォルトブランチは `main`。runbook や audit スクリプトへの変更は `main` からブランチを切って作業する。

## .gitignore の確認

```bash
cat .gitignore
# 確認項目: __pycache__/ *.pyc *.pyo .venv/ が含まれること
# また: *.key *.pem（秘密鍵）が含まれていることを確認
```

## venv の用意

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## baseline lint 確認

```bash
bash tools/docs_lint/run_lint.sh
```

exit 0 が得られれば baseline が green。exit 1 の場合は FAIL メッセージを確認し修正する。

## ops 固有の runbook ディレクトリ確認

```bash
ls docs/05_環境構築/11_プラットフォーム運営者/
# README.md および 01_責務とスコープ.md ～ 14_Claude_Code連携.md が存在すること
```

## 検収コマンド

```bash
bash tools/docs_lint/run_lint.sh && echo "BASELINE GREEN"
python3 tools/docs_lint/run_lint.py && echo "PYTHON LINT GREEN"
```
