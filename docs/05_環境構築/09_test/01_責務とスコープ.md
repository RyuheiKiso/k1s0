# test 軸エンジニア 責務とスコープ

## 一文方針

- test 軸エンジニアは 5 verification_class × 19 軸 = 95 cell coverage matrix 管理 / mutation score 維持 / contract test / chaos test / property-based test / scenario replay の 6 責務を持ち、tier1-3 実装（実装は他軸）と formal proof（formal 軸）は対象外である。

## 5 verification_class

| class | 内容 | 主要ツール |
|---|---|---|
| unit | 単体テスト・property-based test | pytest + Hypothesis / Vitest + fast-check / jqwik / proptest |
| contract | サービス間 contract test | Pact broker |
| integration | integration / Testcontainers | Testcontainers |
| chaos | chaos engineering | Litmus |
| mutation | mutation testing | pitest / mutmut / Stryker / cargo-mutants |

## 責務 6 本

### 95 cell coverage matrix 管理

5 verification_class × 19 軸（07-15 / 32 / 39 / infra01 / data01 / security15-16 / client15 / ops15 / test15 / formal15）= 95 cell の coverage matrix を管理する。各 cell に「担当 verification_class / ツール / cadence / threshold」を定義する。

### mutation score 維持

tier1-3 の実装コードに対して mutation testing を実行し、mutation score が設定閾値を下回らないことを監視する。閾値割れが検出された場合はテスト追加 PR を即座に起票する。

### contract test 維持

Pact broker に consumer / provider contract を登録し、CI で定期的に整合性を検証する。contract が破れた場合は関係する tier1 エンジニアに即座に通知する。

### chaos test 実施

Litmus を使って chaos experiment を設計・実行し、本番相当クラスタへの影響を事前に検証する。chaos experiment の結果は SLO との整合性を ops 軸エンジニアと確認する。

### property-based test 維持

Hypothesis / fast-check / jqwik / proptest を使って境界値・不変条件を自動生成する property-based test を整備する。tier1-3 エンジニアが書いたロジックに対して property-based test を追加する。

### scenario replay

本番ログから replay 可能なシナリオを生成し、regression test に組み込む。scenario は Pact broker とは別管理とする。

## 非責務（他ロールへの委譲）

| 事項 | 担当ロール |
|---|---|
| tier1 Rust / Go / C# / TypeScript 実装 | tier1 軸エンジニア |
| tier2 業務ドメイン実装 | tier2 軸エンジニア |
| tier3 UI / 帳票実装 | tier3 軸エンジニア |
| formal proof（定理証明） | formal 軸エンジニア |
| SLO 管理 / postmortem 主導 | ops 軸エンジニア |
| Kubernetes cluster 構築 | infra 軸エンジニア |
| SDK 配布管理 | client 軸エンジニア |

## LLM 補助の扱い

LLM（Claude Code 含む）による property-based test 草案 / Pact contract 草案 / Litmus experiment YAML 草案は許容する。ただし以下は人間 dual sign-off が必須：

- mutation score 閾値の変更
- contract test の pass 基準変更
- chaos experiment の blast radius 拡大
