# 前提 OS 環境

## 一文方針

- test 軸エンジニアの開発環境は **WSL2 + Ubuntu 22.04 LTS 以上** を前提とし、Docker Engine が WSL2 内で動作することが必須要件である。Pact broker / Litmus chaos hub / Testcontainers はコンテナとして起動するため Docker が動かない環境では検証不能である。

## OS 構成

| 項目 | 必須値 | 理由 |
|---|---|---|
| ホスト OS | Windows 11 | Docker Desktop の安定動作保証 |
| Linux 環境 | WSL2 + Ubuntu 22.04 LTS 以上 | Python 3.12 / Node 20 / Java 21 / Rust が安定インストール可能 |
| WSL2 バージョン | 2.0 以上 | Docker Engine の memory 制御安定 |
| Docker Engine | 24.0 以上 | Testcontainers / Pact broker コンテナの動作 |
| git | 2.40 以上 | `git log --format` の安定 |
| bash | 5.0 以上 | `set -euo pipefail` 安定 |
| GNU coreutils | Ubuntu 標準 | find / awk / grep / sort |

## Docker Engine の確認

```bash
docker version
docker compose version
```

## WSL2 のメモリ制限

Pact broker + Litmus + Testcontainers を同時起動するため、WSL2 に最低 6GB を割り当てる。

```ini
# %USERPROFILE%\.wslconfig
[wsl2]
memory=8GB
processors=4
```

## AFL++（fuzzing）の kernel 設定

AFL++ を使う場合は Linux kernel の core_pattern 設定が必要。

```bash
echo core | sudo tee /proc/sys/kernel/core_pattern
echo performance | sudo tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor 2>/dev/null || true
```

WSL2 では一部の kernel 設定が制限されるため、AFL++ のフル実行は Linux ネイティブ環境を推奨する。

## 検収コマンド

```bash
uname -r          # WSL2 kernel
git --version     # 2.40 以上
bash --version    # 5.0 以上
docker version    # Docker Engine 24.0 以上
docker compose version
```
