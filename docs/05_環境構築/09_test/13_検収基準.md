## 5 verification_class sample 実行

```bash

python3 -c "
from hypothesis import given, strategies as st
@given(st.integers(), st.integers())
def test_add_commutative(a, b):
    assert a + b == b + a
test_add_commutative()
print('unit: OK')
"

# mutation: cargo-mutants --version
```
