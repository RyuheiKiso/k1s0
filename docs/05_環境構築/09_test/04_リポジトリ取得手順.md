# リポジトリ取得手順

## 一文方針

- clone 直後に `bash tools/docs_lint/run_lint.sh` が exit 0 になることを「リポジトリ取得完了」の唯一の定義とする。それ以前の状態で test 作業を開始しない。

## clone 手順

```bash
git clone <repo-url> k1s0
cd k1s0
```

デフォルトブランチは `main`。作業ブランチは `main` からのみ切る。

## .gitignore の確認

```bash
cat .gitignore
# 確認項目: __pycache__/ *.pyc *.pyo .venv/ target/ node_modules/ が含まれること
# test 軸追加確認: .mutmut-cache/ stryker-tmp/ が含まれること
```

mutation testing の一時ファイル（`.mutmut-cache/` / `stryker-tmp/`）は commit 対象外。`.gitignore` に存在しない場合は追加する。

## venv の用意

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml pytest hypothesis mutmut testcontainers
```

## baseline lint 確認

```bash
bash tools/docs_lint/run_lint.sh
```

exit 0 が得られれば baseline が green。

## root allowlist 検査

```bash
python3 tools/docs_lint/run_lint.py 2>&1 | grep -E "FAIL|green"
```

## 検収コマンド

```bash
bash tools/docs_lint/run_lint.sh && echo "BASELINE GREEN"
python3 tools/docs_lint/run_lint.py && echo "PYTHON LINT GREEN"
```
