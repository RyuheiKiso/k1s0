# 必須ランタイム

## 一文方針

- test 軸エンジニアは Python 3.12（pytest + Hypothesis）/ Node 20 + pnpm（Vitest + fast-check + Stryker）/ Java 21（jqwik + pitest）/ Rust（proptest + cargo-mutants + cargo-afl）+ Docker Compose（Testcontainers + Litmus）の 5 ランタイムを全て手元で動かせることが本ページの検収条件である。

## Python 3.12（pytest + Hypothesis）

```bash
sudo apt install -y python3.12 python3.12-venv python3.12-distutils
python3.12 -m venv .venv
source .venv/bin/activate
pip install pytest hypothesis pytest-cov
pytest --version
python3 -c "import hypothesis; print(hypothesis.__version__)"
```

## Node 20 + pnpm（Vitest + fast-check + Stryker）

```bash
# nvm 経由
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.0/install.sh | bash
source ~/.bashrc
nvm install 20 && nvm use 20
npm install -g pnpm
pnpm --version

# Vitest + fast-check + Stryker
pnpm add -D vitest fast-check @stryker-mutator/core @stryker-mutator/vitest-runner
pnpm vitest --version
```

## Java 21（jqwik + pitest）

```bash
# Ubuntu での Java 21 インストール
sudo apt install -y openjdk-21-jdk
java -version  # 21.x

# Maven（pitest 用）
sudo apt install -y maven
mvn -version

# または sdkman 経由
curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk install java 21.0.3-tem
sdk install maven
```

jqwik と pitest は Maven プロジェクトの pom.xml 依存で管理する。インストールは `mvn dependency:resolve` で解決する。

## Rust（proptest + cargo-mutants + cargo-afl）

```bash
# rustup
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env
cargo --version

# cargo-mutants
cargo install cargo-mutants
cargo-mutants --version

# proptest は Cargo.toml の dev-dependencies で管理
# cargo-afl（AFL++ Rust bindings）
cargo install afl
cargo afl --version

# AFL++ を WSL2 で使う場合は core_pattern を設定する（セッション単位、再起動で消える）
# echo core | sudo tee /proc/sys/kernel/core_pattern
```

## Docker Compose（Testcontainers + Litmus）

Testcontainers は Java / Python から Docker を制御するライブラリ。Docker Engine が動いていれば追加インストール不要。

```bash
# Testcontainers for Python
pip install testcontainers

# Testcontainers for Java は pom.xml 依存
# <dependency>
#   <groupId>org.testcontainers</groupId>
#   <artifactId>testcontainers</artifactId>
# </dependency>

# Litmus CLI
curl -LO https://github.com/litmuschaos/litmus-go/releases/latest/download/litmus-linux-amd64
chmod +x litmus-linux-amd64
sudo mv litmus-linux-amd64 /usr/local/bin/litmus
litmus version
```

## mutmut（Python mutation）

```bash
pip install mutmut
mutmut --version
```

## 検収コマンド

```bash
pytest --version
python3 -c "import hypothesis; print('Hypothesis OK')"
pnpm vitest --version
java -version
mvn -version
cargo --version
cargo-mutants --version

```
