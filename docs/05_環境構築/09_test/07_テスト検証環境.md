## Pact broker ローカル起動（docker）

```bash
# docker compose で Pact broker + PostgreSQL を起動
cat > /tmp/pact-compose.yml << 'EOF'
version: "3.9"
services:
  postgres:
    image: postgres:15-alpine
    environment:
      POSTGRES_USER: pact
      POSTGRES_PASSWORD: pact
      POSTGRES_DB: pact
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U pact"]
      interval: 5s
  pact-broker:
    image: pactfoundation/pact-broker:latest
    ports:
      - "9292:9292"
    environment:
      PACT_BROKER_DATABASE_URL: postgres://pact:pact@postgres/pact
      PACT_BROKER_BASIC_AUTH_USERNAME: pact
      PACT_BROKER_BASIC_AUTH_PASSWORD: pact
    depends_on:
      postgres:
        condition: service_healthy
EOF

docker compose -f /tmp/pact-compose.yml up -d
# 起動確認
curl -u pact:pact http://localhost:9292/diagnostic/status
```

## contract test sample 実行

Pact の consumer 側 sample test（Python）:

```python
# /tmp/test_pact_sample.py
import json
from pact import Consumer, Provider

pact = Consumer('SampleConsumer').has_pact_with(
    Provider('SampleProvider'),
    host_name='localhost',
    port=1234,
    pact_dir='/tmp/pacts'
)

def test_sample_pact():
    (pact
     .given('a sample state')
     .upon_receiving('a sample request')
     .with_request('GET', '/sample')
     .will_respond_with(200, body={'status': 'ok'}))
    with pact:
        import requests
        result = requests.get('http://localhost:1234/sample')
        assert result.json() == {'status': 'ok'}
```

```bash
pip install pact-python requests
pytest /tmp/test_pact_sample.py -v 2>&1 | head -20 || echo "Pact sample: requires provider"
```
