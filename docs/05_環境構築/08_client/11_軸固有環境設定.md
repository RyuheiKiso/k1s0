# 軸固有環境設定

## 一文方針

- 5 distribution_class の手元 smoke 全件実行（native / legacy dotnet / browser SPA / tauri / thin API）と SDK conformance cadence 確認の 2 演習を全て完了することが、client 軸固有環境の検収条件である。

> **pre-P0 注記**: `src/` は P10 deliverable（pre-P0 時点で実体ゼロ）。以下の演習は P10 完了後に有効。

## 演習 1: 5 distribution_class 手元 smoke 全件実行

各 class のビルドと最小限の起動を確認する演習。

```bash
#!/bin/bash
set -euo pipefail
echo "=== 5 distribution_class smoke 起動 ==="

# v1_full_native_with_companion
echo "[1/5] v1_full_native_with_companion"
cd src/client/v1_full_native 2>/dev/null && cargo build --release && echo "OK" || echo "SKIP (dir not found)"
cd - > /dev/null

# v1_legacy_dotnet_framework
echo "[2/5] v1_legacy_dotnet_framework"
cd src/client/v1_legacy_dotnet 2>/dev/null && dotnet build && echo "OK" || echo "SKIP (dir not found)"
cd - > /dev/null

# v1_browser_spa_typescript
echo "[3/5] v1_browser_spa_typescript"
cd src/client/v1_browser_spa 2>/dev/null && pnpm install && pnpm build && echo "OK" || echo "SKIP (dir not found)"
cd - > /dev/null

# v1_thick_native_via_tauri
echo "[4/5] v1_thick_native_via_tauri"
cd src/client/v1_thick_native 2>/dev/null && cargo build --release && echo "OK" || echo "SKIP (dir not found)"
cd - > /dev/null

# v1_thin_business_api_only
echo "[5/5] v1_thin_business_api_only"
cd src/client/v1_thin_api 2>/dev/null && pnpm install && pnpm build && echo "OK" || echo "SKIP (dir not found)"
cd - > /dev/null

echo "=== smoke 完了 ==="
```
