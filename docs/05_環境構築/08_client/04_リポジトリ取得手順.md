# リポジトリ取得手順

## 一文方針

- clone 直後に `bash tools/docs_lint/run_lint.sh` が exit 0 になることを「リポジトリ取得完了」の唯一の定義とする。それ以前の状態で client 開発作業を開始しない。

> **pre-P0 注記**: `tools/docs_lint/` は P2 deliverable、`src/` は P10 deliverable。pre-P0 時点では以下のコマンドは実行不可。`git clone` 完了 + `ls docs/` で docs/ 存在確認をもって代替とする。

## clone 手順

```bash
git clone <repo-url> k1s0
cd k1s0
```

デフォルトブランチは `main`。作業ブランチは `main` からのみ切る。

## .gitignore の確認

```bash
cat .gitignore
# 確認項目: __pycache__/ *.pyc *.pyo .venv/ target/ node_modules/ が含まれること
```

`target/` は Rust の build artifact、`node_modules/` は Node の依存。共に commit 対象外。

## venv の用意

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## baseline lint 確認

```bash
bash tools/docs_lint/run_lint.sh
```

exit 0 が得られれば baseline が green。exit 1 の場合はエラーを確認してから次の手順に進む。

## root allowlist 検査

```bash
python3 tools/docs_lint/run_lint.py 2>&1 | grep -E "FAIL|green"
```

root に `target/` / `node_modules/` などが出現すると `root: 許可外ファイル` で FAIL する。これらは `.gitignore` で除外されているため、意図せず commit された場合は `git rm -r --cached` で除外する。

## 検収コマンド

```bash
bash tools/docs_lint/run_lint.sh && echo "BASELINE GREEN"
python3 tools/docs_lint/run_lint.py && echo "PYTHON LINT GREEN"
```
