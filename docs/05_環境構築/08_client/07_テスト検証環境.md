# テスト検証環境

## 一文方針

- 5 distribution_class それぞれのローカル smoke 起動 / Playwright browser matrix（Chrome + Firefox + Webkit）テスト実行 / SDK conformance test ローカル実行の 3 項目が全て通ることが本ページの検収条件である。

## 5 distribution_class のローカル smoke 起動

### v1_full_native_with_companion

```bash
# Tauri dev 起動（GTK on Linux / WSL2 display あり）
cd src/client/v1_full_native
cargo tauri dev
# または headless smoke test
cargo test --all-features
```

### v1_legacy_dotnet_framework

```bash
# .NET Framework は Windows 側でビルド（WSL2 内では .NET 8 compat mode）
dotnet build --configuration Debug
dotnet test
```

### v1_browser_spa_typescript

```bash
# Vite dev server 起動
cd src/client/v1_browser_spa
pnpm install
pnpm dev
# または
pnpm build && pnpm preview
```

### v1_thick_native_via_tauri

```bash
cd src/client/v1_thick_native
cargo tauri dev
```

### v1_thin_business_api_only

```bash
cd src/client/v1_thin_api
pnpm install
pnpm build
node dist/index.js --version
```

## Playwright browser matrix（Chrome + Firefox + Webkit）

```bash
# 全ブラウザで実行
pnpm playwright test --browser=all

# ブラウザ別に確認
pnpm playwright test --browser=chromium
pnpm playwright test --browser=firefox
pnpm playwright test --browser=webkit
```

`playwright.config.ts` の projects 設定で 3 ブラウザを定義する:

```typescript
import { defineConfig, devices } from '@playwright/test';
export default defineConfig({
  projects: [
    { name: 'chromium', use: { ...devices['Desktop Chrome'] } },
    { name: 'firefox',  use: { ...devices['Desktop Firefox'] } },
    { name: 'webkit',   use: { ...devices['Desktop Safari'] } },
  ],
});
```

## SDK conformance test ローカル実行

```bash
# conformance test runner
pnpm run conformance-test
# または
python3 tools/sdk_conformance/run_conformance.py --class all
```

conformance test は 5 distribution_class それぞれがプロトコル仕様と一致することを検証する。test runner が存在しない場合は各 class のユニットテストを代替とする。

## 検収コマンド

```bash
pnpm playwright test --browser=chromium --reporter=line 2>&1 | tail -5
pnpm playwright test --browser=firefox  --reporter=line 2>&1 | tail -5
pnpm playwright test --browser=webkit   --reporter=line 2>&1 | tail -5
```
