# 検収基準

## 一文方針

- `cargo tauri --version` / `pnpm playwright --version` / browser matrix 3 ブラウザ起動成功 / SDK conformance test pass の 4 項目が全て green であることが client 軸エンジニアの環境構築完了の唯一の定義である。

## 検収項目一覧

| # | 検収項目 | 検収コマンド | 期待結果 |
|---|---|---|---|
| 1 | WSL2 動作 | `uname -r` | WSL2 kernel 表示 |
| 2 | Node 20 動作 | `node --version` | v20.x.x 表示 |
| 3 | pnpm 動作 | `pnpm --version` | バージョン表示 |
| 4 | Rust / cargo 動作 | `cargo --version` | バージョン表示 |
| 5 | .NET 8 動作 | `dotnet --version` | 8.0.x 表示 |
| 6 | Tauri CLI 動作 | `cargo tauri --version` | バージョン表示 |
| 7 | Playwright 動作 | `pnpm playwright --version` | バージョン表示 |
| 8 | Chrome 起動 | `pnpm playwright test --browser=chromium` | passed |
| 9 | Firefox 起動 | `pnpm playwright test --browser=firefox` | passed |
| 10 | Webkit 起動 | `pnpm playwright test --browser=webkit` | passed |
| 11 | SDK conformance pass | `python3 tools/sdk_conformance/run_conformance.py` | all passed |
| 12 | docs_lint bash | `bash tools/docs_lint/run_lint.sh` | exit 0 |
| 13 | docs_lint python | `python3 tools/docs_lint/run_lint.py` | 8 check 全 green |
| 14 | VS Code extension | `code --list-extensions` | tauri / dotnet / playwright 含む |
