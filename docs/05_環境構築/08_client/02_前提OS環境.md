# 前提 OS 環境

## 一文方針

- client 軸エンジニアの開発環境は **WSL2 + Ubuntu 22.04 LTS 以上** を前提とし、Tauri のネイティブビルドは Windows 側（MSVC toolchain）でも実行できる構成を必須とする。Webkit ブラウザテストには追加の system dependency が必要である。

## OS 構成

| 項目 | 必須値 | 理由 |
|---|---|---|
| ホスト OS | Windows 11 | Tauri Windows ビルドの MSVC toolchain 利用 |
| Linux 環境 | WSL2 + Ubuntu 22.04 LTS 以上 | Rust / Node / Python の安定インストール |
| WSL2 バージョン | 2.0 以上 | `/mnt/c/` マウントの信頼性 |
| git | 2.40 以上 | `git log --format` の安定 |
| bash | 5.0 以上 | `set -euo pipefail` / `<<<` heredoc 安定 |
| GNU coreutils | Ubuntu 標準 | find / awk / grep / sort |

## Webkit / Playwright の system dependency

Playwright Webkit を WSL2 で動かすには追加パッケージが必要。

```bash
# Playwright の system dependency インストール
npx playwright install-deps webkit
# または
sudo apt install -y libwoff1 libopus0 libwebp7 libwebpdemux2 libenchant-2-2 \
  libgudev-1.0-0 libsecret-1-0 libhyphen0 libgdk-pixbuf2.0-0 \
  libegl1 libnotify4 libxslt1.1 libgles2
```

## Tauri の Windows ビルド prerequisite

Tauri v2.0 の Windows ビルドには Visual Studio Build Tools + WebView2 が必要。

```bash
# Windows 側（PowerShell）でインストール
# Visual Studio Build Tools: https://visualstudio.microsoft.com/visual-cpp-build-tools/
# WebView2 Runtime: https://developer.microsoft.com/microsoft-edge/webview2/
```

WSL2 から Tauri をビルドする場合は Linux ターゲット（GTK ベース）でのビルドになる。Windows 向けクロスコンパイルは WSL2 からは行わない。

## .NET 8 SDK の前提環境

```bash
# Ubuntu での .NET 8 SDK 前提
sudo apt install -y libc6 libgcc-s1 libgssapi-krb5-2 libicu70 libssl3 libstdc++6 zlib1g
```

## 検収コマンド

```bash
uname -r          # WSL2 kernel
git --version     # 2.40 以上
bash --version    # 5.0 以上
lsb_release -rs   # 22.04 以上
```
