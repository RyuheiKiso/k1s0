# 必須ランタイム

## 一文方針

- client 軸エンジニアは Node 20 + pnpm / Rust + cargo / .NET 8 SDK / Tauri CLI 2.0 / Playwright の 5 ランタイムを全て手元で `--version` 応答できる状態にすることが本ページの検収条件である。

> **pre-P0 注記**: `src/` は P10 deliverable（pre-P0 時点で実体ゼロ）。以下の手順は P10 完了後に有効。

## Node 20 LTS + pnpm

```bash
# nvm でインストール
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.0/install.sh | bash
source ~/.bashrc
nvm install 20
nvm use 20
nvm alias default 20
node --version   # v20.x.x

# pnpm インストール
npm install -g pnpm
pnpm --version
```

## Rust + cargo

```bash
# rustup でインストール
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env
rustup toolchain install stable
rustup default stable
cargo --version
rustc --version
```

Tauri v2.0 は Rust edition 2021 を使用する。`rustup update stable` で最新安定版に保つ。

## .NET 8 SDK

```bash
# Ubuntu での .NET 8 SDK インストール
wget https://packages.microsoft.com/config/ubuntu/22.04/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
sudo apt update && sudo apt install -y dotnet-sdk-8.0
dotnet --version   # 8.0.x
```

v1_legacy_dotnet_framework の開発には .NET Framework 4.x が必要だが、WSL2 ではサポートされない。legacy class のビルドは Windows 側（Visual Studio 2022）で行う。WSL2 内での開発は .NET 8 で行い、ビルド・パッケージングのみ Windows で実行する。

## Tauri CLI 2.0

```bash
# cargo install で Tauri CLI をインストール
cargo install tauri-cli --version "^2.0"
cargo tauri --version
```

インストールに時間がかかる場合は `--locked` オプションで Cargo.lock を固定する。

```bash
cargo install tauri-cli --version "^2.0" --locked
```

## Playwright

```bash
# pnpm でインストール（プロジェクトローカル）
pnpm add -D @playwright/test
pnpm playwright install   # browser binary のインストール
pnpm playwright --version

# または npm で
npm install -D @playwright/test
npx playwright install
```

browser binary（Chrome / Firefox / Webkit）は `playwright install` で自動取得される。

## Python 3.12 + venv（docs_lint 用）

```bash
sudo apt install -y python3.12 python3.12-venv
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## 検収コマンド

```bash
node --version      # v20.x.x
pnpm --version
cargo --version
rustc --version
cargo tauri --version
dotnet --version    # 8.0.x
pnpm playwright --version
```
