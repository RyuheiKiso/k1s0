# 前提 OS 環境

## 一文方針

- tier3 軸エンジニアの開発環境は **WSL2 + Ubuntu 22.04 LTS 以上** を前提とし、WPF 開発には Visual Studio 2022（Windows 側）が、Tauri 2.0 には Rust toolchain（WSL2 上）が必要である。

## OS 構成

| 項目 | 必須値 | 理由 |
|---|---|---|
| ホスト OS | Windows 11 | WPF / WinForms / Tauri の安定動作 |
| Linux 環境 | WSL2 + Ubuntu 22.04 LTS 以上 | Node / Rust (Tauri) / Python の全スタック対応 |
| WSL2 バージョン | 2.0 以上 | `/mnt/c/` マウント信頼性 |
| Visual Studio 2022 | Community 以上（Windows 側） | WPF / WinForms デバッグ・デザイナ |
| git | 2.40 以上 | `git log --format` の安定 |
| bash | 5.0 以上 | `set -euo pipefail` / heredoc 安定 |

## WPF 開発環境の注意事項

WPF は Windows 専用フレームワークであり、WSL2 上ではデザイナが動作しない。以下の分担を推奨する。

- XAML / WPF デザイナ: Visual Studio 2022（Windows 側）
- ビルド / テスト: `dotnet` CLI（WSL2 または Windows どちらでも可）
- コードエディタ: VS Code（WSL2 Remote）

## Tauri 2.0 環境の注意事項

Tauri はクロスプラットフォームだが、Windows 向けビルドには Windows 上での実行が必要。開発時は WSL2 上で `cargo tauri dev` を実行し、配布バイナリのビルドは Windows 上または GitHub Actions で行う。

## 検収コマンド

```bash
uname -r          # WSL2 kernel
git --version     # git 2.40 以上
bash --version    # bash 5.0 以上
```
