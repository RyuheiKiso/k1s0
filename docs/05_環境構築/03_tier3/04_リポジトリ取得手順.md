# リポジトリ取得手順

## 一文方針

- clone 直後に `bash tools/docs_lint/run_lint.sh` が exit 0 になり、`ls src/tier3/` で tier3 配下のディレクトリが確認できることを「リポジトリ取得完了」の定義とする。

## clone 手順

```bash
git clone <repo-url> k1s0
cd k1s0
```

デフォルトブランチは `main`。作業ブランチは `main` からのみ切る。

## .gitignore の確認

```bash
cat .gitignore
# 確認項目: node_modules/ dist/ .next/ target/ が含まれること
```

## venv の用意

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## baseline lint 確認

```bash
bash tools/docs_lint/run_lint.sh
```

exit 0 が得られれば baseline が green。

## tier3 ソース確認

```bash
ls src/tier3/
# 例: web/ wpf/ tauri/ が存在すること
```

## Node モジュールインストール（Web アプリ）

```bash
cd src/tier3/web
pnpm install
```

## 検収コマンド

```bash
bash tools/docs_lint/run_lint.sh && echo "BASELINE GREEN"
python3 tools/docs_lint/run_lint.py && echo "PYTHON LINT GREEN"
ls src/tier3/
```
