# 必須ランタイム

## 一文方針

- tier3 は Node 20 LTS + pnpm + TypeScript / .NET 8 SDK（WPF + WinForms）/ Rust（Tauri 2.0）の 3 スタックを全てインストールし、各バージョンが応答することを環境構築の前提とする。

## Node 20 LTS + pnpm 9+

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc
nvm install 20
nvm use 20
node --version   # v20.x.x

npm install -g pnpm@9
pnpm --version   # 9.x.x
```

TypeScript は `pnpm add -D typescript` で各プロジェクトにインストールする。

## .NET 8 SDK（WPF + WinForms）

```bash
sudo apt update
sudo apt install -y dotnet-sdk-8.0
dotnet --version   # 8.x.x
```

WPF / WinForms は .NET 8 以上で Linux / macOS でもビルドできるが、実行には Windows が必要。

```bash
# WPF テンプレート確認
dotnet new --list | grep wpf
```

## Rust（Tauri 2.0 向け）

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source ~/.cargo/env
rustup install stable
rustup default stable
cargo --version
```

Tauri 2.0 の追加依存:

```bash
# WSL2 / Ubuntu でのシステム依存
sudo apt update
sudo apt install -y libwebkit2gtk-4.1-dev libssl-dev libgtk-3-dev \
  libayatana-appindicator3-dev librsvg2-dev
```

## Python 3.12（docs_lint 用）

```bash
sudo apt install -y python3.12 python3.12-venv
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## 検収コマンド

```bash
node --version
pnpm --version
dotnet --version
cargo --version
python3 -c "import yaml; print('PyYAML ok')"
```
