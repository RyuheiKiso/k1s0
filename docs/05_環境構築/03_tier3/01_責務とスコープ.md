# tier3 軸エンジニア 責務とスコープ

## 一文方針

- tier3 軸エンジニアは個別業務 UI / 業務シナリオ / フォームレイアウト / 業務エラー UX / 帳票レイアウトを担う。プロトコル定義（tier1）/ 業務ロジック（tier2）/ cluster（infra）は非責務である。

## 責務

### 個別業務 UI

業務アプリケーションの画面（フォーム / 一覧 / 詳細 / 承認フロー）を実装する。対象プラットフォームは以下の 3 つ。

| プラットフォーム | 技術スタック | 用途 |
|---|---|---|
| Browser | TypeScript + React 19 + Vite | Web アプリ / SPA |
| Desktop WPF | .NET 8 + WPF + XAML | Windows 専用業務アプリ |
| Desktop Tauri | Rust (Tauri 2.0) + TypeScript | クロスプラットフォーム Desktop |

### 業務シナリオ

業務の流れ（ユーザー操作のシーケンス）を実装する。業務フローは tier2 の Workflow 定義に従い、tier3 が UI として具現化する。

### フォームレイアウト

業務入力フォームのレイアウト / バリデーション / エラー表示を実装する。デザインシステム（Storybook）で管理されたコンポーネントを使用する。

### 業務エラー UX

tier1 / tier2 から返されたエラーを業務文脈に変換してユーザーに提示する。エラーコードと業務メッセージのマッピングを tier3 が管理する。

### 帳票レイアウト

PDF / Excel 帳票のレイアウトを定義し、帳票生成エンジンと連携する。

## 非責務（他ロールへの委譲）

| 事項 | 担当ロール |
|---|---|
| proto 定義 / OSS インターフェース定義 | tier1 軸エンジニア |
| 業務ドメインロジック / DB schema | tier2 軸エンジニア |
| cluster 構築 / Kubernetes 設定 | infra 軸エンジニア |
| 脅威モデル / penetration testing | security 軸エンジニア |
| formal 証明 | formal 軸エンジニア |
| production cluster 運用 | ops 軸エンジニア |
| toolchain / 軸登録 governance | k1s0 作者 |
