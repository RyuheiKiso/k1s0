# 検収基準

## 一文方針

- `node --version` / `pnpm --version` / `dotnet --version` / `cargo tauri --version` 全応答 + browser smoke pass + docs_lint green を tier3 環境構築完了の唯一の定義とする。

## 検収コマンド一覧

```bash
node --version          # v20.x.x
pnpm --version          # 9.x.x
dotnet --version        # 8.x.x
cargo --version         # Rust stable
cargo tauri --version   # Tauri CLI
```

## docs_lint 検収

```bash
bash tools/docs_lint/run_lint.sh
# 期待: === docs_lint: 7 check 全 green ===

python3 tools/docs_lint/run_lint.py
# 期待: === docs_lint (Python): 8 check 全 green ===
```

## browser smoke 検収

```bash
cd src/tier3/web
pnpm exec playwright test --reporter=list
# 全テストが PASSED であること
```

## WPF ビルド検収

```bash
cd src/tier3/wpf
dotnet build
# Build succeeded
```

## Tauri ビルド検収

```bash
cd src/tier3/tauri
cargo tauri build --debug
# Finished 応答
```

## 検収チェックリスト

| 項目 | コマンド | 合格基準 |
|---|---|---|
| Node | `node --version` | v20.x |
| pnpm | `pnpm --version` | 9.x |
| .NET | `dotnet --version` | 8.x |
| Rust | `cargo --version` | バージョン応答 |
| Tauri CLI | `cargo tauri --version` | バージョン応答 |
| browser smoke | `playwright test` | 全 PASSED |
| WPF ビルド | `dotnet build` | Build succeeded |
| Tauri ビルド | `cargo tauri build --debug` | Finished |

全項目が合格した時点で「tier3 環境構築完了」とする。
