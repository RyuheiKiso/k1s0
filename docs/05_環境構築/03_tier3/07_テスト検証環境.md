# テスト検証環境

## 一文方針

- Vitest（unit）+ Playwright（E2E browser）/ `dotnet test`（WPF unit）/ `cargo tauri dev`（Tauri 起動確認）の全プラットフォームテストが動作することを本ページの検収とする。

> **pre-P0 注記**: `src/` は P10 deliverable（pre-P0 時点で実体ゼロ）。以下の手順は P10 完了後に有効。

## Vitest（browser unit テスト）

```bash
cd src/tier3/typescript/spa
pnpm exec vitest run
```

コンポーネント単体テスト / ロジックテストを実行する。

## Playwright（E2E browser テスト）

```bash
cd src/tier3/typescript/spa
pnpm exec playwright test
```

browser smoke テスト（業務画面の起動確認 / 主要シナリオ実行）を含む。

```bash
# ブラウザを表示しながら実行（デバッグ用）
pnpm exec playwright test --headed
```

## WPF unit テスト（.NET）

```bash
cd src/tier3/wpf
dotnet test
# 詳細出力
dotnet test --verbosity normal
```

WPF の unit テストは xUnit + Moq / NSubstitute を使用する。UI コンポーネント（Window / UserControl）は直接テストせず、ViewModel / Service のテストを優先する。

## Storybook 起動確認

```bash
cd src/tier3/typescript/spa
pnpm exec storybook dev
# http://localhost:6006 でコンポーネントカタログが表示されること
```

## Tauri 起動確認（`cargo tauri dev`）

```bash
cd src/tier3/tauri
cargo tauri dev
# Tauri ウィンドウが起動すること
```

WSL2 上では GUI が表示されないため、X11 forwarding または Windows 側で実行する。起動確認のみであれば `--no-watch` オプションで静的確認も可能。

## 検収コマンド

```bash
pnpm exec vitest run && echo "Vitest: GREEN"
pnpm exec playwright test --reporter=list && echo "Playwright: GREEN"
dotnet test && echo "WPF test: GREEN"
```
