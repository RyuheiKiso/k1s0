# 軸固有環境設定

## 一文方針

- Backstage Software Template を使った tier3 repo 自動生成演習 / 帳票レイアウト editor 起動確認 / 業務 UI smoke（browser + WPF + Tauri 全起動）を完了することを本ページの検収とする。

## Backstage Software Template 演習

Backstage を使って tier3 アプリケーションの雛形を自動生成する演習を行う。

```bash
# Backstage CLI（ローカル Backstage インスタンス想定）
npx @backstage/create-app@latest

# または既存 Backstage サーバへの接続
# http://localhost:3000 で Backstage UI にアクセス
# Create → Software Template → tier3-web-template を選択
```

生成された repo 構造を確認する:

```bash
ls -la generated-app/src/
```

## 帳票レイアウト editor 起動確認

帳票生成エンジンとのローカル連携を確認する。

```bash
# BIRT / JasperReports 等の帳票エンジン（Docker 経由）
docker pull eclipse/birt:latest
docker run -d -p 8085:8080 --name birt-server eclipse/birt:latest
# http://localhost:8085/birt でアクセス確認
curl -s http://localhost:8085/birt | head -5
```

## 業務 UI smoke（全プラットフォーム）

### browser smoke

```bash
cd src/tier3/web
pnpm exec playwright test --grep "@smoke"
```

### WPF 起動確認

```bash
cd src/tier3/wpf
dotnet run --project src/App.WPF/App.WPF.csproj
# ウィンドウが起動すること（Windows 側で実行）
```

WSL2 からビルド確認のみ行う場合:

```bash
dotnet build src/App.WPF/App.WPF.csproj
echo "WPF ビルド: OK"
```

### Tauri 起動確認

```bash
cd src/tier3/tauri
cargo tauri dev --no-watch &
# プロセスが起動すること
sleep 5
kill %1
echo "Tauri 起動確認: OK"
```

## 検収コマンド

```bash
pnpm exec playwright test --grep "@smoke" && echo "browser smoke: GREEN"
dotnet build src/tier3/wpf/ && echo "WPF ビルド: OK"
cargo tauri build --debug && echo "Tauri ビルド: OK"
```
