# 前提 OS 環境

## 一文方針

- 業務管理者の主要作業環境は **Windows 11 PC + ブラウザ（Chrome 最新 / Edge 最新）** であり、WSL2 は不要だが tier2 admin API CLI 操作のために導入すると便利（任意）とする。

## OS 構成

| 項目 | 必須値 | 理由 |
|---|---|---|
| ホスト OS | Windows 11 | Backstage 管理 UI はブラウザ操作のため Windows 11 で十分 |
| ブラウザ | Chrome 最新 / Edge 最新 | Backstage UI / 監査検索 UI の動作保証 |
| WSL2 | 任意 | CLI 操作（k1s0-admin / curl + jq）を使いたい場合のみ導入 |
| git | 2.40 以上（WSL2 利用時） | runbook / 決定表の変更管理 |

## ブラウザ設定

Backstage UI と監査検索 UI にアクセスするために、以下の設定を確認する。

```
確認項目:
- JavaScript が有効であること
- Cookie が有効であること（SSO 認証に使用）
- 社内プロキシ / VPN の設定が完了していること
```

## WSL2（任意）のセットアップ

tier2 admin API CLI を使いたい場合のみ WSL2 を導入する。

```powershell
# Windows PowerShell（管理者権限）で実行
wsl --install -d Ubuntu-22.04
```

WSL2 導入後は Ubuntu 22.04 上に `k1s0-admin` コマンドをインストールする（`05_主要OSS導入.md` 参照）。

## 検収コマンド

```
ブラウザ確認:
- Chrome / Edge を開き、バージョンを確認する
- [設定] → [Chromeについて] でバージョンを確認
```

WSL2 を導入した場合:

```bash
uname -r          # WSL2 kernel 確認
git --version     # git 2.40 以上
```
