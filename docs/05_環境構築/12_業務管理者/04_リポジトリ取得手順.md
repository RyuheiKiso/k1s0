# リポジトリ取得手順

## 一文方針

- WSL2 を導入している場合は clone 直後に `bash tools/docs_lint/run_lint.sh` が exit 0 になることを「リポジトリ取得完了」の定義とし、ブラウザのみの環境では staging URL へのアクセス確認を取得完了の条件とする。

## clone 手順（WSL2 利用時）

```bash
git clone <repo-url> k1s0
cd k1s0
```

## ブラウザのみ環境での確認

WSL2 を導入していない場合は staging 環境 URL にブラウザでアクセスし、Backstage UI が表示されることを確認する。

```
確認 URL（例）:
- Backstage UI: https://backstage.staging.example.internal
- 監査検索 UI: https://audit.staging.example.internal
- tier2 admin API ドキュメント: https://api.staging.example.internal/docs
```

## venv の用意（WSL2 利用時）

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## baseline lint 確認（WSL2 利用時）

```bash
bash tools/docs_lint/run_lint.sh
```

exit 0 が得られれば baseline が green。

## 検収コマンド

WSL2 利用時:

```bash
bash tools/docs_lint/run_lint.sh && echo "BASELINE GREEN"
python3 tools/docs_lint/run_lint.py && echo "PYTHON LINT GREEN"
```

ブラウザのみ:

```
ブラウザで Backstage UI にアクセスしてページが表示されることを目視確認
```
