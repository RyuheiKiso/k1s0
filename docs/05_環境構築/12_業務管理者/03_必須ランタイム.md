# 必須ランタイム

## 一文方針

- 業務管理者の必須ランタイムはブラウザ（Chrome / Edge 最新）と tier2 admin API CLI（`k1s0-admin` コマンド、または `curl` + `jq` による代替）の 2 種類であり、WSL2 上での docs lint 実行のために Python venv（PyYAML）を追加で用意する。

## ランタイム一覧

| ツール | 必須 | 用途 |
|---|---|---|
| Chrome / Edge 最新 | 必須 | Backstage UI / 監査検索 UI へのアクセス |
| `k1s0-admin` CLI | 必須 | tier2 admin API の操作（テナントマスタ管理等） |
| `curl` + `jq` | 代替可 | `k1s0-admin` CLI の代替（API を直接叩く） |
| Python venv + PyYAML | WSL2 利用時必須 | docs lint 実行のため |

## tier2 admin API CLI（k1s0-admin）

`k1s0-admin` は tier2 admin API へのアクセスを簡略化するラッパーコマンド（仮実装）。WSL2 上でインストールする。

```bash
# インストール手順（例）
curl -L https://example.internal/k1s0-admin/latest/k1s0-admin-linux-amd64 \
  -o /usr/local/bin/k1s0-admin
chmod +x /usr/local/bin/k1s0-admin
k1s0-admin --version
```

`k1s0-admin` が存在しない場合は `curl` + `jq` で代替する。

```bash
# curl + jq による代替例
curl -s -H "Authorization: Bearer $ADMIN_TOKEN" \
  https://api.example.internal/v2/admin/tenants | jq '.items[]'
```

## Python venv（WSL2 利用時）

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## バージョン固定方針

ブラウザは最新版を常に使用する（セキュリティパッチの適用が優先）。`k1s0-admin` CLI のバージョンは staging / production で一致させる。

## 検収コマンド

ブラウザ確認はブラウザのバージョン確認画面で目視。CLI 確認:

```bash
k1s0-admin --version 2>/dev/null || (curl --version | head -1 && jq --version)
```
