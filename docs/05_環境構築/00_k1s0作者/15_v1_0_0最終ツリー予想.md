# v1.0.0 最終ツリー予想

## 一文方針

本ドキュメントは pre-P0（現状 stub のみ）から P11 完遂時点（v1.0.0 ship）へのリポジトリディレクトリ進化を「予想」として記述する。`ARCHITECTURE.md` / `CLAUDE.md` / 19 軸 / lock.yaml 体系 / `tools/docs_lint/run_lint.py` の enforcement 制約を SoT とし、実装が進む過程で本ドキュメントを更新すること。

### status transition

各 `.md` の `status` は以下の条件で遷移する:

| 遷移 | 条件 |
|---|---|
| `draft` → `locked` | `depends_on` 全 ID の `locked` 化 + dual sign-off（human cosign × 1 + AI static analysis evidence × 1）+ `tools/docs_lint/run_lint.py` の `check_empty_locked` green |
| `locked` 後の変更 | dual sign-off による re-review が必須（CLAUDE.md 至高路線）。`locked` を `draft` に戻してから再 locked 化。 |

### lint 確定制約（v1 範囲で不変）

`tools/docs_lint/run_lint.py` `check_repository_layout()` が B 層 lint で物理 enforce する。**lint allowlist の拡張は v1 範囲では行わない**（拡張する場合は dual sign-off + ARCHITECTURE.md 改訂が前提）。

| 区分 | 許可 | 不許可の例（CI fail） |
|---|---|---|
| root 直下ファイル（6 本） | `CLAUDE.md README.md LICENSE ARCHITECTURE.md .claudeignore .gitignore` | `Cargo.toml go.work Makefile pyproject.toml` |
| root 直下 dir（6 本） | `.claude .github docs img src tools` | `lock/ deploy/ charts/ proto/ pack/` |
| `src/` 直下 dir | 10 軸 + `_meta _crosscutting` + `README.md` | `sdk/ proto/ crates/` |
| `src/_crosscutting/` 直下 | `NN_<slug>/`（NN = 01〜13）| `http2/`（番号なし）|
| `img/` 直下拡張子 | `.svg .drawio` | `.png .pdf` |

### 命名規則

| スコープ | 規則 | 根拠 |
|---|---|---|
| root / `src/` 直下 | unnumbered（軸名のみ）| `ARCHITECTURE.md:91`「axis 数字番号は言語識別子として合法でない」|
| `src/_crosscutting/` 直下 | `NN_<slug>/`（強制）| `run_lint.py:241` `CROSSCUTTING_SLUG_PATTERN`（**上限 13 spec**。追加時は lint + ARCHITECTURE.md dual sign-off 要）|

| `lock/<軸>/` 配下 | `<name>.lock.yaml` — `run_lint.py:40` `LOCK_PATTERN` | 正規表現 `^[a-z][a-z0-9_]*\.lock\.yaml$` |

### 8 cluster × 13 spec 対応表

全 git 管理 lock.yaml 共通規律（`docs/04_詳細設計/05_lock_yaml体系/README.md` 準拠）:
- cosign 署名必須（OpenBao Transit + sign-on-demand）
- Ceph RGW Object Lock Compliance（10 年 / cryptographic proof 15 年）
- build artifact は手書き禁止（`tools/lock_yaml_generator/` 生成物のみ）

### PR ごと・append-only の git 管理外 lock.yaml

git tree に入らない lock.yaml は以下 2 種:

| lock.yaml | 保存先 | 特記事項 |
|---|---|---|
| `dual_review.lock.yaml` | Ceph RGW Object Lock bucket（PR ごと）| schema: `docs/00_format/dual_review_schema.yaml`。dual sign-off: human cosign × 1 + (AI evidence \| cosign_history) × 1。10 year retention |
| `audit_event.lock.yaml` | Ceph RGW Object Lock bucket（append-only WORM）| security 軸で管理。git diff 不可。hash chain で tamper-evidence。15 year retention |
