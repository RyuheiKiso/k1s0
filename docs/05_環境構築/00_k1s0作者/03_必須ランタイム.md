# 必須ランタイム

## 一文方針

- CI は **Python 3.12**（`.github/workflows/docs_lint.yml` L32 でピン）を前提とする。作者はローカルでも Python 3.12 を使い、`python3 -m venv .venv` で分離することを規律とする。

## Python 3.12 インストール

```bash
sudo apt update
sudo apt install -y python3.12 python3.12-venv python3.12-distutils
python3.12 --version   # 3.12.x を確認
```

既に 3.12 以上が入っている場合は `python3 --version` で確認して再インストール不要。

## venv の作成と有効化

```bash
python3.12 -m venv .venv
source .venv/bin/activate
```

`.venv/` は `.gitignore` に登録済みのため commit 対象外。

## PyYAML インストール

```bash
pip install pyyaml
python3 -c "import yaml; print(yaml.__version__)"
```

PyYAML は `tools/docs_lint/run_lint.py`（L24）と `tools/lock_yaml_generator/generate_release_gate.py`（L20）が共通で依存する唯一の外部パッケージ。

## Python バージョンの固定方針

CI ピンと手元で diff が生じると lint 結果が発散する。バージョンを上げる場合は `.github/workflows/docs_lint.yml` の `python-version` も同時に変更し、dual sign-off を経てから変更する。

## 検収コマンド

```bash
source .venv/bin/activate
python3 --version                              # 3.12.x
python3 -c "import yaml; print('PyYAML ok')"  # PyYAML ok
```
