- 新軸を追加する場合は `00_軸登録適合仕様.md` の registry.yaml に entry を追加し、同型の 14 方針メモ + 1 構造仕様を配置してから PR を作る。v1 cap は 20 であり残 1 の上限を守る。

## 新軸追加の手順（v2 cap 昇格後）

1. `docs/01_企画/90_メモ/<NN>_<axis>/` ディレクトリを作成する
2. `01_責務.txt` ～ `14_強制機構.txt` の 14 方針メモを既存軸と同型で作成する
3. `15_<軸名>適合仕様.txt` を作成する（命名は `NN_<軸名>適合仕様.txt`）
4. `00_軸登録適合仕様.md` の registry.yaml に entry を追加する（`spec_name` / `axis` / `cap` / `connects_to` を記入）
5. 全 lint が green になることを確認してから PR を作る
6. PR に dual sign-off を得る

## 軸の cap evolve 手順

major version が上がるたびに cap は +5。`00_軸登録適合仕様.md` の `cap.v<N>` を変更し、`release_gate.lock.yaml` の meta cell が red に戻るため再度 AND-gate を green にする必要がある。

## 同型構造の確認
