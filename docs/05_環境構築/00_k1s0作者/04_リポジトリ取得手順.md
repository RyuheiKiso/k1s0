# リポジトリ取得手順

## 一文方針

- clone 直後に `bash tools/docs_lint/run_lint.sh` が exit 0 になることを「リポジトリ取得完了」の唯一の定義とする。それ以前の状態で作業を開始しない。

> **pre-P0 注記**: `tools/docs_lint/` は P2 deliverable、`src/` は P10 deliverable。pre-P0 時点では以下のコマンドは実行不可。`git clone` 完了 + `ls docs/` で docs/ 存在確認をもって代替とする。

## clone 手順

```bash
git clone <repo-url> k1s0
cd k1s0
```

デフォルトブランチは `main`。作業ブランチは `main` からのみ切る。

## .gitignore の確認

```bash
cat .gitignore
# 確認項目: __pycache__/ *.pyc *.pyo .venv/ が含まれること
```

## venv の用意

clone 後に venv を作成し PyYAML を入れる（03_必須ランタイムの手順通り）。

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## baseline lint 確認

```bash
bash tools/docs_lint/run_lint.sh
```

exit 0 が得られれば baseline が green。exit 1 の場合はエラーを確認し、schema 変更漏れや dangling link を修正してから次の手順に進む。

## root allowlist 検査

`run_lint.py check_repository_layout()` は root 直下の許可ファイル / ディレクトリを検査する。以下が root に存在することを確認する。

- ファイル: `CLAUDE.md` / `README.md` / `LICENSE` / `ARCHITECTURE.md` / `.claudeignore` / `.gitignore`
- ディレクトリ: `.claude` / `.github` / `docs` / `img` / `src` / `tools`

これ以外のファイル / ディレクトリを root に置いた場合、`run_lint.py` が fail する。

```bash
python3 tools/docs_lint/run_lint.py 2>&1 | grep -E "FAIL|green"
```

## 検収コマンド

```bash
bash tools/docs_lint/run_lint.sh && echo "BASELINE GREEN"
python3 tools/docs_lint/run_lint.py && echo "PYTHON LINT GREEN"
```
