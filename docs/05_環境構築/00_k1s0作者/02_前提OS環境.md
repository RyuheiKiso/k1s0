# 前提 OS 環境

## 一文方針

- k1s0 作者の開発環境は **WSL2 + Ubuntu 22.04 LTS 以上** を前提とする。drawio Desktop が Windows 側（`/mnt/c/Program Files/draw.io/draw.io.exe`）に存在し WSL2 から呼び出せることが必須要件である。

## OS 構成

| 項目 | 必須値 | 理由 |
|---|---|---|
| ホスト OS | Windows 11 | draw.io Desktop の安定動作保証 |
| Linux 環境 | WSL2 + Ubuntu 22.04 LTS 以上 | Python 3.12 / bash 5.2 が apt でインストール可能 |
| WSL2 バージョン | 2.0 以上 | `/mnt/c/` マウントの信頼性 |
| git | 2.40 以上 | `git log --format` の安定 |
| bash | 5.0 以上 | `set -euo pipefail` / `<<<` heredoc 安定 |
| GNU coreutils | Ubuntu 標準 | find / awk / grep / sort / uniq / sed / mktemp |

## draw.io Desktop のパス確認

```bash
ls -la "/mnt/c/Program Files/draw.io/draw.io.exe"
```

存在しない場合は `DRAWIO_BIN` 環境変数で代替パスを指定する（07_drawio作図ツール手順を参照）。

## WSL2 が使えない場合

Linux ネイティブ環境（Ubuntu 22.04 以上）でも動作するが、drawio-export スクリプトが要求する draw.io.exe がないため SVG エクスポートは手動となる。`drawio-lint` / `svg-postcheck` は drawio.exe 不要で実行できる。

## 検収コマンド

```bash
uname -r          # WSL2 kernel (例: 5.15.xx-microsoft-standard-WSL2)
git --version     # git 2.40 以上
bash --version    # bash 5.0 以上
find --version    # GNU findutils
```
