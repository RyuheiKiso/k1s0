# テスト検証環境

## 一文方針

- OWASP ZAP ローカル proxy でのターゲットスキャン / Trivy による image scan / SPIRE agent ローカル起動の 3 検証を手元で実行できることを security 軸の検証環境確認条件とする。

> **pre-P0 注記**: `src/` は P10 deliverable（pre-P0 時点で実体ゼロ）。以下の手順は P10 完了後に有効。

## OWASP ZAP によるスキャン

OWASP ZAP を daemon モードで起動し、ローカルターゲットをスキャンする。

```bash
# ZAP を daemon モードで起動
docker run -d --name zap-daemon \
  -p 8090:8090 \
  ghcr.io/zaproxy/zaproxy:stable \
  zap.sh -daemon -host 0.0.0.0 -port 8090 \
  -config api.disablekey=true \
  -config api.addrs.addr.name='.*' \
  -config api.addrs.addr.regex=true

# ZAP が起動するまで待機
sleep 10

# スキャン対象（例: httpbin）をスパイダー
curl "http://localhost:8090/JSON/spider/action/scan/?url=http://httpbin.org/"

# スキャン結果の確認
curl "http://localhost:8090/JSON/core/view/alerts/" | python3 -m json.tool | head -50

# ZAP の停止
docker stop zap-daemon && docker rm zap-daemon
```

実際の penetration testing では対象 URL を適切なテスト環境のエンドポイントに変更する。

## Trivy による image scan

```bash
# 公開イメージのスキャン
trivy image nginx:latest

# 重大度フィルタ（HIGH / CRITICAL のみ）
trivy image --severity HIGH,CRITICAL nginx:latest

# JSON 出力
trivy image --format json --output /tmp/trivy-results.json nginx:latest
cat /tmp/trivy-results.json | python3 -m json.tool | head -30

# ファイルシステムスキャン
trivy fs --security-checks vuln,config .
```

## SPIRE agent のローカル起動

```bash
# SPIRE server の起動（バックグラウンド）
mkdir -p /tmp/spire-data/server
spire-server run -config /tmp/spire-config/server.conf &
SPIRE_SERVER_PID=$!
sleep 3

# join token の発行
TOKEN=$(spire-server token generate -spiffeID spiffe://k1s0.local/agent/test 2>/dev/null | awk '{print $2}')
echo "Join token: $TOKEN"

# SPIRE server の停止（演習なので起動確認のみ）
kill $SPIRE_SERVER_PID 2>/dev/null || true
```

## Trivy による IaC スキャン

```bash
# k8s manifest のスキャン
trivy config --severity HIGH,CRITICAL <path-to-manifests>/

# Terraform ファイルのスキャン（IaC 設定ファイルがある場合）
trivy config --severity HIGH,CRITICAL <path-to-terraform>/
```

## 検収コマンド

```bash
trivy image --severity CRITICAL nginx:latest 2>&1 | tail -5
# スキャン結果が出力されること

spire-agent --version
# バージョンが応答すること

docker run --rm ghcr.io/zaproxy/zaproxy:stable zap.sh -version 2>/dev/null | head -1
# ZAP バージョンが応答すること
```
