# 検収基準

## 一文方針

- `trivy --version` / `cosign version` / SPIRE agent `--version` の 3 コマンド全応答 + shamir split 演習完了 + docs_lint green を「security 軸環境構築完了」の検収条件とし、1 つでも欠けた場合は完了とみなさない。

## 検収チェックリスト

以下を全て満たすこと。

### 必須ランタイム

```bash
trivy --version
# → Trivy 0.50.x 以上

cosign version
# → GitVersion: v2.x.x 以上

spire-agent --version
# → バージョン応答

bao --version
# → OpenBao バージョン応答
```

### 主要 OSS

```bash
docker run --rm falcosecurity/falco-no-driver:latest falco --version 2>/dev/null | head -1
# → Falco バージョン応答

docker run --rm ghcr.io/zaproxy/zaproxy:stable zap.sh -version 2>/dev/null | head -1
# → ZAP バージョン応答

source .venv/bin/activate && semgrep --version
# → Semgrep バージョン応答

source .venv/bin/activate && checkov --version
# → Checkov バージョン応答
```

### shamir split 演習完了

```bash
# OpenBao dev mode で shamir 演習が完了していること
# （Step 1 の演習を実行済みであること）
bao --version && echo "OpenBao: shamir rehearsal 実施済み（手動確認）"
```

### penetration testing baseline チェックリスト確認

OWASP TOP 10 の全 10 項目チェックリスト確認が完了していること（11_軸固有環境設定 Step 3 参照）。

### docs_lint

> **pre-P0 注記**: `tools/docs_lint/` は P2 deliverable（pre-P0 時点で実体ゼロ）。以下の手順は P2 完了後に有効。

```bash
bash tools/docs_lint/run_lint.sh 2>&1 | tail -1
# → === docs_lint: 7 check 全 green ===

python3 tools/docs_lint/run_lint.py 2>&1 | tail -1
# → === docs_lint (Python): 8 check 全 green ===
```

## 一括検収スクリプト

```bash
set -e
echo "=== security 軸 環境構築 検収 ==="

echo "[1/4] 必須ランタイム確認"
trivy --version
cosign version | head -1
spire-agent --version
bao --version

echo "[2/4] Falco / ZAP 確認"
docker run --rm falcosecurity/falco-no-driver:latest falco --version 2>/dev/null | head -1 || echo "Falco: docker pull 必要"

echo "[3/4] SAST / IaC lint ツール確認"
source .venv/bin/activate
semgrep --version
checkov --version

echo "[4/4] docs_lint 確認"
bash tools/docs_lint/run_lint.sh 2>&1 | tail -1
python3 tools/docs_lint/run_lint.py 2>&1 | tail -1

echo "=== 検収完了（shamir 演習は手動確認が必要） ==="
```
