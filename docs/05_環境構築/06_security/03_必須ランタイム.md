# 必須ランタイム

## 一文方針

- security 軸エンジニアは Trivy CLI / Cosign / SPIRE (SPIFFE) / Falco / OpenBao CLI の 5 ツールを必須ランタイムとし、全て `--version` または `--help` が応答することを確認してから次の手順に進む。

## Trivy CLI のインストール

```bash
sudo apt install -y wget apt-transport-https gnupg lsb-release
wget -qO - https://aquasecurity.github.io/trivy-repo/deb/public.key | gpg --dearmor | sudo tee /usr/share/keyrings/trivy.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/trivy.gpg] https://aquasecurity.github.io/trivy-repo/deb $(lsb_release -sc) main" | sudo tee /etc/apt/sources.list.d/trivy.list
sudo apt update
sudo apt install -y trivy
trivy --version
```

## Cosign のインストール

```bash
curl -LO https://github.com/sigstore/cosign/releases/latest/download/cosign-linux-amd64
chmod +x cosign-linux-amd64
sudo mv cosign-linux-amd64 /usr/local/bin/cosign
cosign version
```

security 軸では cosign を使ってビルド成果物（コンテナイメージ）の署名検証を行う。署名鍵の生成は k1s0 作者が担当。

## SPIRE (SPIFFE) のインストール

```bash
# SPIRE server と agent のバイナリをダウンロード
curl -LO https://github.com/spiffe/spire/releases/latest/download/spire-1.10.0-linux-amd64-musl.tar.gz
tar xf spire-1.10.0-linux-amd64-musl.tar.gz
sudo mv spire-1.10.0 /opt/spire
sudo ln -sf /opt/spire/bin/spire-server /usr/local/bin/spire-server
sudo ln -sf /opt/spire/bin/spire-agent /usr/local/bin/spire-agent
spire-agent --version
```

## Falco のインストール（Docker 経由）

```bash
# Falco は docker で起動する（kernel module 不要）
docker pull falcosecurity/falco-no-driver:latest
docker run --rm falcosecurity/falco-no-driver:latest falco --version
```

## OpenBao CLI のインストール

```bash
curl -LO https://github.com/openbao/openbao/releases/latest/download/bao_linux_amd64
chmod +x bao_linux_amd64
sudo mv bao_linux_amd64 /usr/local/bin/bao
bao --version
```

## Python venv（docs_lint 用）

```bash
sudo apt install -y python3.12 python3.12-venv
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## 検収コマンド

```bash
trivy --version
cosign version
spire-agent --version
docker run --rm falcosecurity/falco-no-driver:latest falco --version 2>/dev/null | head -1
bao --version
```

5 コマンド全て応答することを確認する。
