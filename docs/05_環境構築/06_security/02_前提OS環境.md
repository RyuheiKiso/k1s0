# 前提 OS 環境

## 一文方針

- security 軸エンジニアの開発環境は **WSL2 + Ubuntu 22.04 LTS 以上** を前提とし、Yubikey ハードウェアトークン（FIDO2/PIV）の使用を強く推奨する。ハードウェアトークンなしでの SC-7 / SC-8 操作は規律違反とみなす。

## OS 構成

| 項目 | 必須値 | 理由 |
|---|---|---|
| ホスト OS | Windows 11 または Linux | WSL2 または ネイティブ Linux |
| Linux 環境 | WSL2 + Ubuntu 22.04 LTS 以上 | Trivy / SPIRE / Falco が apt / binary でインストール可能 |
| WSL2 バージョン | 2.0 以上 | Docker Engine の安定動作 |
| Docker | Docker Desktop 4.x または Docker Engine 24.x | OWASP ZAP / Falco を docker で起動 |
| git | 2.40 以上 | credential commit 防止のため gpg 署名設定必須 |
| bash | 5.0 以上 | セキュリティスクリプト実行 |

## Yubikey の設定（推奨）

Yubikey 5 シリーズ以上の FIDO2/PIV 対応モデルを使用する。

```bash
# Yubikey Manager のインストール
sudo apt install -y yubikey-manager
ykman info
# デバイス情報が表示されること
```

PIV スロットに証明書を設定し、SSH 鍵として使用することを推奨する。

## git の gpg 署名設定

```bash
# GPG 鍵の生成
gpg --full-gen-key
# RSA 4096 / 有効期限: 2y を選択

# git の署名設定
git config --global commit.gpgsign true
git config --global user.signingkey <key-id>
```

## WSL2 で Yubikey を使う場合

Windows 側の usbipd-win でデバイスを WSL2 にアタッチする。

```bash
# Windows PowerShell (管理者) で実行:
# winget install usbipd
# usbipd wsl attach --hardware-id <yubikey-vid:pid>

# WSL2 側で確認
lsusb | grep Yubico
```

## 検収コマンド

```bash
uname -r          # WSL2 kernel 確認
git --version     # git 2.40 以上
docker --version  # Docker 24.x 以上
gpg --version     # GPG 確認
ykman info 2>/dev/null || echo "Yubikey: 未接続（推奨: 接続すること）"
```
