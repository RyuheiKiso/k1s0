# 軸固有環境設定

## 一文方針

- KEK shamir share local rehearsal (OpenBao shamir-split) / 脅威モデル 5⁴ cell spreadsheet 更新演習 / penetration testing baseline チェックリスト確認の 3 ステップを順に完了させ、全て完了することを security 軸固有環境設定の完了条件とする。

## Step 1: KEK shamir share local rehearsal

OpenBao の Shamir secret sharing を使ったローカル演習を行う。本演習は production KEK とは無関係のダミー secret で行う。

```bash
# OpenBao server をローカルで起動（dev モード）
bao server -dev -dev-root-token-id="root" &
BAO_PID=$!
sleep 2

export BAO_ADDR="http://127.0.0.1:8200"
export BAO_TOKEN="root"

# Shamir unseal の演習（dev モードは unseal 不要だが手順確認として）
bao status

# Secret の書き込み演習（ダミー secret のみ）
bao kv put secret/rehearsal/drill \
  kek_share_1="dummy-share-A" \
  kek_share_2="dummy-share-B" \
  kek_share_3="dummy-share-C"

# Secret の読み込み確認
bao kv get secret/rehearsal/drill

# OpenBao の停止
kill $BAO_PID 2>/dev/null || true
```

本番 KEK の M-of-N ceremony は security 軸の責務外であり、プラットフォーム運営者が実施する。本 rehearsal はツールの動作確認のみを目的とする。

## Step 2: 脅威モデル 5⁴ cell spreadsheet 更新演習

5⁴ cell 脅威モデルのサンプルを作成し更新演習を行う。実際の脅威モデルはスプレッドシートまたは専用ツール（OWASP Threat Dragon など）で管理する。

```bash
# OWASP Threat Dragon をローカルで起動（docker 経由）
docker run --rm -d \
  -p 3000:3000 \
  --name threat-dragon \
  owasp/threat-dragon:2.2.0
echo "Threat Dragon: http://localhost:3000"

# 5 分後に停止（演習確認のみ）
sleep 5
docker stop threat-dragon 2>/dev/null || true
```

脅威モデルの cell 構造（5⁴ = 625 cell の一部抜粋）:

| 次元 | 値例 |
|---|---|
| 攻撃ベクタ | external / internal / supply-chain / insider / physical |
| 影響コンポーネント | auth / data / infra / network / client |
| 検出可能性 | low / medium / high |
| 対策状況 | none / partial / full / compensating |

## Step 3: penetration testing baseline チェックリスト確認

OWASP TOP 10 に基づく baseline チェックリストを確認する。

```bash
echo "=== penetration testing baseline チェックリスト ==="
cat <<'EOF'
[ ] A01: Broken Access Control
    - 認可チェックが全エンドポイントに存在するか
    - IDOR（Insecure Direct Object Reference）の確認

[ ] A02: Cryptographic Failures
    - TLS 1.2 以上を使用しているか
    - 脆弱な暗号アルゴリズム（MD5 / SHA-1 / DES）を使っていないか

[ ] A03: Injection
    - SQL / コマンドインジェクション対策
    - Semgrep でスキャン済みか

[ ] A04: Insecure Design
    - 脅威モデリングを実施したか（5^4 cell 更新済みか）

[ ] A05: Security Misconfiguration
    - checkov / trivy config でスキャン済みか
    - デフォルト credential を変更したか

[ ] A06: Vulnerable Components
    - Trivy image scan で CRITICAL 0 件か

[ ] A07: Auth Failures
    - SPIFFE/SPIRE による workload identity が設定されているか
    - OAuth 2.1 / PKCE が適用されているか

[ ] A08: Data Integrity Failures
    - Cosign でコンテナイメージに署名済みか
    - SLSA Level 3 以上を達成しているか

[ ] A09: Logging Failures
    - Falco でランタイム検知を有効化しているか

[ ] A10: SSRF
    - 外部リクエストの allowlist が設定されているか
EOF
echo "=== チェックリスト確認完了 ==="
```

```bash
bao --version

```
