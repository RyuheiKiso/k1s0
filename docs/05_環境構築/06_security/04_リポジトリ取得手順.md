# リポジトリ取得手順

## 一文方針

- clone 直後に `bash tools/docs_lint/run_lint.sh` が exit 0 になることを「リポジトリ取得完了」の唯一の定義とする。secret / credential 類を誤って commit しないための予防措置を確認してから作業を開始する。

## clone 手順

```bash
git clone <repo-url> k1s0
cd k1s0
```

デフォルトブランチは `main`。security 作業ブランチは `main` からのみ切る。

## secret の commit 防止設定

セキュリティ軸では誤 commit 防止が最優先。git-secrets または pre-commit hook を設定する。

```bash
# git-secrets のインストール（推奨）
sudo apt install -y git-secrets 2>/dev/null || pip install detect-secrets

# detect-secrets を使う場合
pip install detect-secrets
detect-secrets scan > .secrets.baseline
# 以降は pre-commit hook で detect-secrets audit を実行

# .gitignore に secret 関連のパターンを追加
cat >> .gitignore << 'EOF'
*.key
*.pem
*.p12
cosign.key
bao-token
.vault-token
EOF
```

## .gitignore の確認

```bash
cat .gitignore
# 確認項目: *.key / *.pem / cosign.key が含まれること
```

## venv の用意

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## baseline lint 確認

```bash
bash tools/docs_lint/run_lint.sh
```

exit 0 が得られれば baseline が green。

## 検収コマンド

```bash
bash tools/docs_lint/run_lint.sh && echo "BASELINE GREEN"
python3 tools/docs_lint/run_lint.py && echo "PYTHON LINT GREEN"
```
