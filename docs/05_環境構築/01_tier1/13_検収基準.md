# 検収基準

## 一文方針

- `cargo --version` / `go version` / `dotnet --version` / `pnpm --version` / `buf --version` が全て応答し、docs_lint が green になることを tier1 環境構築完了の唯一の定義とする。

## 検収コマンド一覧

以下の全コマンドが exit 0 かつ期待バージョン以上を返すことを確認する。

```bash
cargo --version       # cargo 1.7x.x 以上
go version            # go1.22.x 以上
dotnet --version      # 8.x.x
node --version        # v20.x.x
pnpm --version        # 9.x.x
buf --version         # 1.x.x
```

## docs_lint 検収

```bash
bash tools/docs_lint/run_lint.sh
# 期待: === docs_lint: 7 check 全 green ===

python3 tools/docs_lint/run_lint.py
# 期待: === docs_lint (Python): 8 check 全 green ===
```

## 全言語テスト検収

```bash
cargo test --workspace
go test ./...
dotnet test
pnpm test
```

全コマンドが exit 0 であることを確認する。

## 検収チェックリスト

| 項目 | コマンド | 合格基準 |
|---|---|---|
| Rust | `cargo --version` | バージョン応答 |
| Go | `go version` | 1.22 以上 |
| .NET | `dotnet --version` | 8.x |
| Node | `node --version` | v20.x |
| pnpm | `pnpm --version` | 9.x |
| Buf | `buf --version` | バージョン応答 |
| docs_lint bash | `bash tools/docs_lint/run_lint.sh` | exit 0 |
| docs_lint python | `python3 tools/docs_lint/run_lint.py` | exit 0 |
| Rust test | `cargo test --workspace` | exit 0 |
| Go test | `go test ./...` | exit 0 |
| .NET test | `dotnet test` | exit 0 |
| TS test | `pnpm test` | exit 0 |

全項目が合格した時点で「tier1 環境構築完了」とする。
