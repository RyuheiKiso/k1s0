# 前提 OS 環境

## 一文方針

- tier1 軸エンジニアの開発環境は **WSL2 + Ubuntu 22.04 LTS 以上** を前提とする。Rust toolchain はネイティブ Linux ビルドが必要であり、WSL2 環境で要件を満たす。

## OS 構成

| 項目 | 必須値 | 理由 |
|---|---|---|
| ホスト OS | Windows 11 | WSL2 の安定動作保証 |
| Linux 環境 | WSL2 + Ubuntu 22.04 LTS 以上 | Rust / Go / .NET 8 / Node の全スタックが apt / rustup / snap でインストール可能 |
| WSL2 バージョン | 2.0 以上 | `/mnt/c/` マウント信頼性 + Docker Desktop 連携 |
| git | 2.40 以上 | `git log --format` の安定 |
| bash | 5.0 以上 | `set -euo pipefail` / heredoc 安定 |
| GNU coreutils | Ubuntu 標準 | find / awk / grep / sort / uniq / sed / mktemp |

## Rust toolchain の注意事項

Rust の cross-compilation（`--target x86_64-unknown-linux-musl` 等）はネイティブ Linux 環境が安定する。WSL2 上の Ubuntu 22.04 で `rustup` インストールすることで要件を満たす。Windows ネイティブ（MSVC toolchain）は本プロジェクトでは使用しない。

## Docker Desktop の必要性

tier1 開発には Docker Desktop（WSL2 integration 有効）が必要。Apicurio Registry / Kafka のローカル起動に使用する。

```bash
docker --version   # Docker Desktop が WSL2 から呼べること
docker compose version
```

## 検収コマンド

```bash
uname -r          # WSL2 kernel (例: 5.15.xx-microsoft-standard-WSL2)
git --version     # git 2.40 以上
bash --version    # bash 5.0 以上
docker --version  # Docker が応答すること
```
