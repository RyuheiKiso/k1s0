# 必須ランタイム

## 一文方針

- tier1 は Rust stable / Go 1.22+ / .NET 8 SDK / Node 20 LTS + pnpm 9+ の 4 言語ランタイムを全てインストールし、各バージョンが応答することを環境構築の前提とする。

## Rust stable

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source ~/.cargo/env
rustup install stable
rustup default stable
cargo --version   # cargo 1.7x.x 以上
```

`~/.cargo/bin` が `PATH` に含まれることを確認する。`.bashrc` または `.profile` に `source ~/.cargo/env` を追記する。

## Go 1.22+

```bash
# snap を使う場合
sudo snap install go --classic
go version   # go1.22.x 以上

# apt では古いバージョンが入る場合がある。snap 推奨。
```

`GOPATH` は `~/go` がデフォルト。`export PATH=$PATH:$(go env GOPATH)/bin` を `.bashrc` に追記する。

## .NET 8 SDK

```bash
sudo apt update
sudo apt install -y dotnet-sdk-8.0
dotnet --version   # 8.x.x
```

複数バージョンが共存する場合は `global.json` で固定する。

```json
{
  "sdk": {
    "version": "8.0.0",
    "rollForward": "latestMinor"
  }
}
```

## Node 20 LTS + pnpm 9+

```bash
# nvm でインストール（推奨）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc
nvm install 20
nvm use 20
node --version   # v20.x.x

# pnpm
npm install -g pnpm@9
pnpm --version   # 9.x.x
```

## Python 3.12（docs_lint 用）

docs_lint スクリプトが Python 3.12 を要求する。

```bash
sudo apt install -y python3.12 python3.12-venv
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## 検収コマンド

```bash
cargo --version
go version
dotnet --version
node --version
pnpm --version
python3 -c "import yaml; print('PyYAML ok')"
```
