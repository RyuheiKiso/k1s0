# 軸固有環境設定

## 一文方針

- `buf generate` を実行して 4 言語 stub が生成されること / 9 適合仕様ページが参照できること / OSS lifecycle 監視設定が完了することを本ページの検収とする。

## proto → 4 言語 stub 生成演習

`buf.gen.yaml` に 4 言語のプラグイン設定が記述されている。設定ファイルは `src/tier1/schema/buf.gen.yaml` に存在する。

```bash
cd src/tier1
buf generate
ls gen/go gen/python
```

TypeScript stub は `ts-proto` プラグインを使用する。

```bash
# buf.gen.yaml に ts-proto を追加した場合
buf generate
ls gen/ts
```

C# stub は `Grpc.Tools` NuGet パッケージが `dotnet build` 時に自動生成するため手動の `buf generate` は不要。

## 9 適合仕様ページの参照確認

tier1 の 9 適合仕様は `docs/04_詳細設計/01_適合仕様/` 配下に存在する。

```bash
ls docs/04_詳細設計/01_適合仕様/ | grep -E "^0[1-9]_"
```

各適合仕様の Markdown ファイルが存在することを確認する。

## OSS lifecycle 監視設定

tier1 は OSS ライフサイクル軸（14 番）の責任者として、依存 OSS のバージョン監視を設定する。

```bash
# Rust: cargo audit でセキュリティ脆弱性確認
cargo install cargo-audit
cargo audit

# Go: govulncheck
go install golang.org/x/vuln/cmd/govulncheck@latest
govulncheck ./...

# .NET: dotnet list package --vulnerable
dotnet list package --vulnerable

# Node: pnpm audit
pnpm audit
```

## 検収コマンド

```bash
buf generate && echo "stub 生成: OK"
cargo audit && echo "Rust audit: OK"
govulncheck ./... && echo "Go vuln: OK"
```
