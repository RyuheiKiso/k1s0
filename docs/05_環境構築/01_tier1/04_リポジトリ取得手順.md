# リポジトリ取得手順

## 一文方針

- clone 直後に `bash tools/docs_lint/run_lint.sh` が exit 0 になり、`ls src/tier1/` で tier1 配下の README が確認できることを「リポジトリ取得完了」の定義とする。

> **pre-P0 注記**: `tools/docs_lint/` は P2 deliverable、`src/` は P10 deliverable。pre-P0 時点では以下のコマンドは実行不可。`git clone` 完了 + `ls docs/` で docs/ 存在確認をもって代替とする。

## clone 手順

```bash
git clone <repo-url> k1s0
cd k1s0
```

デフォルトブランチは `main`。作業ブランチは `main` からのみ切る。

## .gitignore の確認

```bash
cat .gitignore
# 確認項目: __pycache__/ *.pyc *.pyo .venv/ target/ が含まれること
```

`target/` は Rust のビルド成果物ディレクトリ。`.gitignore` に含まれていることを確認する。

## venv の用意

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## baseline lint 確認

```bash
bash tools/docs_lint/run_lint.sh
```

exit 0 が得られれば baseline が green。exit 1 の場合はエラーを確認し修正してから次の手順に進む。

## tier1 ソース確認

```bash
ls src/tier1/
```

tier1 配下の README または初期ファイルが存在することを確認する。

## root allowlist 検査

```bash
python3 tools/docs_lint/run_lint.py 2>&1 | grep -E "FAIL|green"
```

## 検収コマンド

```bash
bash tools/docs_lint/run_lint.sh && echo "BASELINE GREEN"
python3 tools/docs_lint/run_lint.py && echo "PYTHON LINT GREEN"
ls src/tier1/
```
