# テスト検証環境

## 一文方針

- `cargo test` / `dotnet test` / `go test ./...` / `pnpm test` の全言語ローカル実行が exit 0 になることを本ページの検収とする。

## Rust テスト

```bash
cd src/tier1
cargo test
# または全 workspace
cargo test --workspace
```

`cargo test` は unit test + integration test を実行する。doc test も含まれる。

## Go テスト

```bash
cd src/tier1
go test ./...
# カバレッジ付き
go test ./... -cover
```

## .NET テスト

```bash
cd src/tier1
dotnet test
# 詳細出力
dotnet test --verbosity normal
```

xUnit / NUnit のいずれかをテストフレームワークとして使用する。

## TypeScript テスト

```bash
cd src/tier1
pnpm test
# または vitest を直接実行
pnpm exec vitest run
```

## 並列実行（全言語一括）

以下のスクリプトで全言語テストを順次実行する。

```bash
set -euo pipefail
cd src/tier1
cargo test --workspace
go test ./...
dotnet test
pnpm test
echo "全言語テスト: GREEN"
```

## CI との対応

CI での test job は各言語の `test` コマンドを順次実行する構成。手元での再現手順は上記と同一。

## 検収コマンド

```bash
cargo test --workspace 2>&1 | tail -5
go test ./... 2>&1 | tail -5
dotnet test 2>&1 | tail -5
pnpm test 2>&1 | tail -5
```

各コマンドが exit 0 であることを確認する。
