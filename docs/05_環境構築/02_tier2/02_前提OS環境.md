# 前提 OS 環境

## 一文方針

- tier2 軸エンジニアの開発環境は **WSL2 + Ubuntu 22.04 LTS 以上** を前提とし、Docker Desktop（WSL2 integration 有効）で postgres / kafka / clickhouse / apicurio の 4 サービスをローカル起動できることが必須要件である。

## OS 構成

| 項目 | 必須値 | 理由 |
|---|---|---|
| ホスト OS | Windows 11 | WSL2 + Docker Desktop の安定動作保証 |
| Linux 環境 | WSL2 + Ubuntu 22.04 LTS 以上 | 4 言語ランタイム全対応 |
| WSL2 バージョン | 2.0 以上 | Docker Desktop 連携の安定性 |
| Docker Desktop | 4.x 以上 | WSL2 integration 有効、compose v2 同梱 |
| git | 2.40 以上 | `git log --format` の安定 |
| bash | 5.0 以上 | `set -euo pipefail` / heredoc 安定 |

## Docker Desktop の設定確認

```bash
docker --version         # Docker Desktop が WSL2 から呼べること
docker compose version   # Compose V2
```

Docker Desktop の Settings → Resources → WSL Integration で Ubuntu が有効になっていることを確認する。

## メモリ要件

postgres / kafka / apicurio を同時起動するため、Docker Desktop に最低 4 GB のメモリを割り当てること。

WSL2 のメモリ上限設定（`~/.wslconfig`）:

```ini
[wsl2]
memory=8GB
processors=4
```

## 検収コマンド

```bash
uname -r                  # WSL2 kernel
git --version             # git 2.40 以上
bash --version            # bash 5.0 以上
docker --version          # Docker Desktop
docker compose version    # Compose V2
```
