# 検収基準

## 一文方針

- 4 言語ランタイム全応答 + docker compose で postgres / kafka / clickhouse / apicurio の 4 サービス起動 + ドメイン bound CT 通過 + docs_lint green を tier2 環境構築完了の唯一の定義とする。

## 検収コマンド一覧

```bash
cargo --version       # Rust stable
go version            # Go 1.22 以上
dotnet --version      # .NET 8.x
node --version        # v20.x
pnpm --version        # 9.x
```

## 4 サービス起動検収

```bash
docker compose -f src/tier2/docker-compose.dev.yml up -d
docker compose -f src/tier2/docker-compose.dev.yml ps
# postgres / kafka / clickhouse / apicurio が全て Up になること
```

各サービスの疎通確認:

```bash
psql -h localhost -U postgres -d tier2_dev -c "SELECT 1;"
curl http://localhost:8080/apis/registry/v2/system/info
```

## ドメイン bound CT 検収

```bash
cargo test --test domain_ct --features integration
go test ./... -tags integration -run TestDomain
dotnet test --filter Category=DomainCT
```

## docs_lint 検収

```bash
bash tools/docs_lint/run_lint.sh
python3 tools/docs_lint/run_lint.py
```

| 項目 | コマンド | 合格基準 |

| Rust | `cargo --version` | バージョン応答 |

全項目が合格した時点で「tier2 環境構築完了」とする。
