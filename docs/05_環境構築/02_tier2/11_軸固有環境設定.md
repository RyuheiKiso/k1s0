# 軸固有環境設定

## 一文方針

- atomic 三表書込のローカル演習 / 業界 pack クラス一覧の確認 / Domain Event schema 整合チェックを完了することを本ページの検収とする。

## atomic 三表書込ローカル演習

docker compose で 3 サービスを起動し、atomic 三表書込の演習を実行する。

```bash
docker compose -f src/tier2/docker-compose.dev.yml up -d

# DB マイグレーション
sqlx migrate run --database-url postgres://postgres:postgres@localhost:5432/tier2_dev

# atomic 書込演習スクリプト
cargo run --example atomic_write_demo
```

演習内容: Outbox テーブル / Event log テーブル / 業務テーブルへの同時書込と、障害発生時のロールバック確認。

## 業界 pack クラス一覧の確認

`src/tier2/` 配下の業界 pack ディレクトリを確認する。

```bash
ls src/tier2/
# 例: manufacturing/ retail/ healthcare/ finance/

# 各業界 pack の Domain Event スキーマ確認
find src/tier2/ -name "*.avsc" -o -name "*.proto" | head -20
```

## Domain Event schema 整合チェック

Apicurio Registry に登録された schema と実装の整合を確認する。

```bash
# Apicurio が起動していること
curl http://localhost:8080/apis/registry/v2/groups/default/artifacts

# Buf による proto schema チェック
buf lint src/tier2/proto/
buf breaking src/tier2/proto/ --against '.git#branch=main'
```

`buf breaking` は破壊的変更を検出する。過去の proto 定義との後方互換性が保たれていることを確認する。

## 決定表の整合確認

```bash
bpmnlint src/tier2/**/*.bpmn 2>/dev/null || echo "BPMN files checked"
```

## 検収コマンド

```bash
docker compose -f src/tier2/docker-compose.dev.yml up -d
sqlx migrate run --database-url postgres://postgres:postgres@localhost:5432/tier2_dev && echo "migration: OK"
buf lint src/tier2/proto/ && echo "proto lint: OK"
docker compose -f src/tier2/docker-compose.dev.yml down
```
