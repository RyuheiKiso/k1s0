# 必須ランタイム

## 一文方針

- tier2 は tier1 と同等の 4 言語（Rust stable / Go 1.22+ / .NET 8 SDK / Node 20 LTS + pnpm 9+）ランタイムに加え、業界 pack ビルドツールを導入する。

## Rust stable

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source ~/.cargo/env
rustup install stable
rustup default stable
cargo --version
```

## Go 1.22+

```bash
sudo snap install go --classic
go version
export PATH=$PATH:$(go env GOPATH)/bin
```

## .NET 8 SDK

```bash
sudo apt update
sudo apt install -y dotnet-sdk-8.0
dotnet --version   # 8.x.x
```

## Node 20 LTS + pnpm 9+

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc
nvm install 20
nvm use 20
npm install -g pnpm@9
pnpm --version
```

## 業界 pack ビルドツール

業界 pack は業種別ビルド定義を持つ。共通ビルドツールとして以下を導入する。

```bash
# sqlx-cli（PostgreSQL マイグレーション管理）
cargo install sqlx-cli --features postgres

# migrate（Go マイグレーションツール）
go install -tags 'postgres' github.com/golang-migrate/migrate/v4/cmd/migrate@latest

# flyway（.NET / Java 向けマイグレーション）
# Docker image を使用
docker pull flyway/flyway
```

## Python 3.12（docs_lint 用）

```bash
sudo apt install -y python3.12 python3.12-venv
python3.12 -m venv .venv
source .venv/bin/activate
pip install pyyaml
```

## 検収コマンド

```bash
cargo --version
go version
dotnet --version
node --version
pnpm --version
sqlx --version
migrate --version
```
