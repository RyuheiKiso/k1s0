============================================================
プラットフォーム構成
============================================================

■ 空間分割（5 階層）
  - tier1 : システムとしての共通処理。
            ログ、infra への接続、認証認可など。
  - tier2 : ドメインの業務共通化処理。
            tier3 の共通ロジック。
            （例：製造業であれば FA、調達、検査の各共通処理）
  - tier3 : 個別業務に特化した Web サイト・exe。
  - infra : インフラ層。
  - data  : データ層。

■ 設計方針
  - クリーンアーキテクチャを採用する。
  - ドメイン駆動開発を採用する。
