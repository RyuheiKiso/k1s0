============================================================
tier2 の国際化方針（i18n / TZ / 単位 / 通貨）
============================================================

■ 方針
  - tier2 は 1.0.0 出荷時点で日本国内のみへの対応を前提と
    しない。製造業のグローバル展開（複数国・複数言語・複数
    通貨）に対応可能な構造を day-1 から組み込む。
  - 内部表現は canonical（言語非依存・UTC・SI 単位・基準通貨）
    を保ち、表示時に locale / TZ / 単位 / 通貨に変換する。

■ 言語（i18n）
  - 識別子 : IETF BCP 47 言語タグ（ja / ja-JP / en / en-US /
    de-DE 等）を使用。
  - スコープ :
      - テナント既定言語 : テナントマスタに保持。
      - ユーザー既定言語 : ユーザープロファイル（tier1
        Authentication）に保持。
      - リクエスト言語 : Accept-Language header / gRPC
        metadata で個別指定可。
  - 解決順 : リクエスト言語 → ユーザー既定 → テナント既定 →
    プラットフォーム既定（en）。
  - 翻訳対象 :
      - 業務メッセージ（業務エラー詳細、通知テンプレート、
        承認 workflow のメッセージ）
      - マスタの表示名（品目名 / 拠点名 等）— マスタは多言語
        フィールドを持つ
      - 監査エントリ : 内部表現は言語中立な business_event
        名（「14_業務エラー監査コンプライアンス」参照）。
        表示時に翻訳。
  - 翻訳リソース管理 : 翻訳カタログ（業界横断 / 業界 pack
    ごと）を tier2 が所有。tier3 は override 拡張点で追加翻訳
    を提供可能（「07_業務資産所有権」参照）。

■ タイムゾーン（TZ）
  - 保管 : 全 timestamp は UTC で保管。RDB は TIMESTAMP WITH
    TIME ZONE。
  - 表示 / 入力 : テナント既定 TZ + ユーザー既定 TZ + リクエ
    スト指定 TZ の解決順で表示。
  - スケジュール評価（cron 等）: テナント既定 TZ で評価する
    （「20_スケジューラ・バッチ」テナント別実行節と整合）。
  - DST（夏時間）: tzdata（IANA Time Zone Database）に従う。
    tier2 は最新 tzdata を含む image で配布する。
  - 業務カレンダー（「10_提供機能カテゴリ」業界横断 業務
    カレンダー）と TZ は連動する（営業日判定はテナント TZ で
    評価）。

■ 単位（Unit of Measurement）
  - 内部表現 : 数値（Decimal）+ 単位 enum を value object
    として保持。換算は明示的なメソッドで行う（暗黙換算禁止）。
  - 標準単位 enum :
      - 質量 : kg, g, t, lb, oz
      - 長さ : m, mm, cm, km, in, ft
      - 体積 : L, mL, m3, gal
      - 数量 : 個, ケース, パレット, ダース
      - 時間 : 秒, 分, 時間, 日
  - 換算 : tier2 が換算ライブラリを Library で提供。係数は
    不変（SI 換算）。製造業特有の換算（ケース → 個 等）は
    品目マスタの換算係数で表現する。
  - 表示 : テナント / ユーザー設定の表示単位に変換。

■ 通貨
  - 識別子 : ISO 4217 通貨コード（JPY / USD / EUR / CNY 等）。
  - 内部表現 : 金額（Decimal）+ 通貨コード の value object。
    通貨を持たない金額型は提供しない。
  - 為替レート : tier2 がレートマスタを提供。レートはレート
    プロバイダ（業務的な参照源、tier3 が override で接続）
    から取得。
  - 換算時刻 : 為替換算は「取引時点のレートで snapshot」を
    原則とする（事後の為替変動で過去取引が変化しない）。
    snapshot した換算金額は元金額と並べて保持する。
  - 表示 : テナント / ユーザー設定の表示通貨に on-demand
    換算。内部処理は元通貨のまま。

■ 数値・日付の表示形式
  - 表示形式（小数点・桁区切り・日付フォーマット）は locale
    に従う。標準ライブラリ（ICU 等）を tier2 Library で wrap
    する。
  - 内部処理は canonical 表現（小数点 . / 千区切りなし / ISO
    8601）を維持する。

■ override 拡張点
  - 翻訳カタログへの追加 / 上書き（テナント固有 / 業界固有の
    語彙）。
  - 為替レートプロバイダの差し替え。
  - 業務カレンダー（祝日 / 営業日）の差し替え。
  - 単位換算係数の追加（業界 / テナント固有の単位）。
  - 上記すべて override 拡張点として「07_業務資産所有権」に
    準拠する。

■ 機械的担保
  - 翻訳キーの未定義検出 : 翻訳カタログに未登録のキーを CI
    で検出。
  - timestamp の TZ 抜け検出 : ローカル時刻型（TZ なし
    timestamp）を業務 entity に持たせることを CI で禁止する。
  - 単位なし数値の禁止 : 業務 entity の数量 / 金額フィールド
    に単位 / 通貨が紐付かない型を持たせることを CI で禁止
    する。
  - これらは「16_強制機構」と同枠で組み込む。

■ 1.0.0 出荷時の対応範囲
  - 1.0.0 では翻訳カタログとして日本語 / 英語の 2 言語を
    提供。追加言語はテナント運用が翻訳追加で対応可能。
  - TZ / 単位 / 通貨は機構を提供。具体的なマスタ値はテナント
    運用責任。
