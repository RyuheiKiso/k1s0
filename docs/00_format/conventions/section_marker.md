# セクション記法規約（■ → ## 変換）

## 一文方針
- メモ層の `■` 記法は MD の `##` に 1:1 対応させ、ネスト深度を物理的に制限する。`#` は frontmatter 直後のタイトル 1 箇所のみ、`####` 以下は使わない。意味の区切りはセクション分割で表現する。

## 至高路線における原則
- 章立ての深度は読者の認知負荷であり、深いネストは構造設計の不備である。深さで逃げず、章の昇格 / 軸の分割 / 適合仕様化のいずれかで構造解決する。
- 「章番号」は安定 ID として扱う。リネーム / 番号付け替えは下流の参照を全て破壊する操作であり、原則禁止。新章は末尾追加。

## 章立ての階層

| MD レベル | 用途 | 個数制約 |
|---|---|---|
| `#` | ドキュメントタイトル | frontmatter 直後 1 箇所のみ。本文中に `#` は出現しない |
| `##` | メモ層 `■ ◯◯` の 1:1 投影。当該ドキュメントの主セクション | 制限なし。ただし 20 を超える場合は分割を検討 |
| `###` | `##` 内の小区分 | 必要に応じて。原則 1 階層のみ |
| `####` 以下 | **使用禁止** | 構造設計の不備を示すため、章の昇格で解決する |

## ネストリスト記法

メモ層の indent ルールを MD 規約に変換する:

| メモ層 (.txt) | MD (.md) |
|---|---|
| `  - 項目` (indent 2) | `- 項目`（最上位） |
| `      - 子項目` (indent 6) | `  - 子項目`（indent 2） |
| `          - 孫項目` (indent 10) | `    - 孫項目`（indent 4） |

- MD のリスト indent は 2 space で固定する（4 space は使わない）。
- 孫より深い階層は使わない。出てきた場合は段落 / 表 / サブセクションに格上げする。
- リスト項目内の改行は半角空白 2 個 + 改行（hard break）または空行（段落区切り）で表現する。

## 表（table）の規約

メモ層の罫線表（`┌─┬─┐` / `+---+---+`）は MD table に変換する:

```markdown
| ヘッダ1 | ヘッダ2 | ヘッダ3 |
|---|---|---|
| セル | セル | セル |
```

- 列揃え（`:---` / `---:` / `:---:`）は原則使わず、左寄せに統一。
- セル内改行が必要な場合は `<br>` を使う（MD table の制約）。
- 表が複雑化（10 列以上 / 200 行以上）した場合は別ファイルの YAML / TSV に分離し、本文では link する。

## コードブロック

- 言語タグ必須（` ```yaml ` / ` ```rust ` / ` ```protobuf ` / ` ```rego ` / ` ```bash ` 等）。
- 言語不明 / 疑似コードは ` ```text ` を使う。
- 引用形式（`>`）はメモ層からの転載に限り使用可。それ以外は使わない。

## 見出しに含めない要素

- 番号（`## 1. 〇〇`）は禁止。番号は配置パスとファイル名で表現する。`##` の 1 行目から本文を書く。
  - 例外: メモ層に `[N] セクション` 記法があった場合、変換時に番号は落として `## セクション` とする。
- リンク（`## [〇〇](url)`）は禁止。見出しは plain text。
- 絵文字 / 装飾文字は禁止。

## 見出し名の規約

- メモ層の `■` 直後の文言を 1:1 で MD 見出しに移す。
- ただし以下のメモ層慣用見出しは MD 側で標準化する:

| メモ層 | MD 標準見出し |
|---|---|
| `■ 一文方針` / `■ 一文定義` / `■ 方針` | `## 一文方針` |
| `■ 背景・狙い` / `■ 背景` | `## 背景` |
| `■ 至高路線における立ち位置` / `■ 立ち位置` | `## 至高路線における立ち位置` |
| `■ 至高路線における原則` | `## 至高路線における原則` |
| `■ 配下ファイル（下位章）` | `## 配下ドキュメント` |

- 標準化されない `■ ◯◯` は原文の文言を維持する。

## 空行の規約

- セクション見出し（`##`）の前に必ず 1 行空行。
- リストブロック / 表 / コードブロックの前後に 1 行空行。
- 段落は 1 行空行で区切る（連続改行 2 行以上は禁止）。
