# 開発者体験統合

## 一文方針
- 本企画の開発者体験は Backstage 統合 + Software Template + ChatOps（Mattermost）+ inner loop（Tilt + dev container）+ contract test（Pact）+ Playwright + Lighthouse CI + axe-core + Litmus chaos drill の 8 機構を tier1 / tier2 / tier3 / client / ops / test / formal の 7 軸に統合する。

## Backstage 統合
- 開発者ポータル（service catalog / tech docs / Software Template）
- 認証: Keycloak OIDC、tenant_id を JWT claim から取得
- Software Template: tier3 / tier2 リポジトリ生成時点で全強制機構自動組込
- TechDocs: MkDocs Material plugin で docs/ を publish

## Software Template
- **tier3 リポジトリ生成**: 13 層強制機構 + contract test + a11y + Web Vitals 自動組込
- **tier2 リポジトリ生成**: 8 層強制機構 + atomic 三表書込 + property test 自動組込
- **Tauri sidecar 配布申請**: cosign signed exe + MDM 配布 channel
- **ABAC policy 編集**: Keycloak Realm Operator 連携
- **マスタ編集 / 決定表編集**: PR 形式 + git レビュー
- **break-glass token 発行**: ceremony commander 署名 + audit emit

## ChatOps（Mattermost）
- slash command:
  - `/ops` (oncall / incident)
  - `/formal review-assign` / `/formal break-glass` / `/formal status`
  - `/data restore-drill` / `/security audit-search`
- Tekton Triggers + Argo Events で workflow 起動
- 全 ChatOps 操作を audit emit

## inner loop（Tilt + dev container）
- Tilt: K8s ローカル開発、proto 変更 → buf generate → 言語別 build → contract test を 1 session で iterative
- dev container（VS Code Remote Containers / GitHub Codespaces）: 全 toolchain（.NET / Java / Node / Rust / Python / Ruby / Go / protoc / buf / Tilt / ctlptl / kind / Tauri CLI）を含む

## inner loop time budget
- proto 変更 → buf generate: ≤ 10s
- 言語別 build（変更 1 言語）: ≤ 30s
- 全言語 build（lockstep release 時）: ≤ 5min
- contract test 全実行: ≤ 10min
- E2E（Browser SPA）: ≤ 5min

## 観察 UI
- **Perses**: メトリクス可視化（Grafana の代替、Apache 2.0）
- **Apache Superset**: ad-hoc SQL（ClickHouse / PostgreSQL）
- **Jaeger v2**: トレース UI（first-party、内蔵 ClickHouse storage）
- **Headlamp**: K8s Web UI（Octant / Lens の代替）

## オンボーディング
- 1 day onboarding（Backstage Software Template + dev container）
- onboarding workflow:
  1. Backstage account 作成（Keycloak OIDC）
  2. dev container 起動
  3. Software Template で tier3 / tier2 リポジトリ生成
  4. Tilt + Companion local mock で local 開発開始
  5. contract test green 確認
  6. PR 作成 → 自動 lint / 自動 test / dual reviewer sign-off

## docs 規約
- 全 docs は MkDocs Material で codify、Backstage tech docs plugin で publish
- 利用例コードは「テスト済みコード」として CI 検査
- 図は drawio（drawio-authoring skill 規約）

## 採用しない設計
- 商用 internal developer portal（Cortex / OpsLevel 商用 / Roadie SaaS）
- 商用 SaaS test platform（BrowserStack / Sauce Labs / LambdaTest）
- 商用 chaos（Gremlin / AWS FIS）
- 商用 incident management SaaS（PagerDuty / Opsgenie 有償 SLA）
- AGPL-3 OSS（Grafana / Tempo / Loki / k6 / Grafana OnCall）

## 受入条件
- Backstage onboarding が 1 day で完結
- 8 軸別運用 UI 動作
- ChatOps slash command 動作
- inner loop time budget 内
- AGPL-3 OSS 不採用が CI 検査 green
