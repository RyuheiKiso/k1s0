# スキーマ進化

## 一文方針
- proto / Avro / DDL / yaml / OTel SemConv の 5 軸を `aggregate_qualified_name` 名前空間（`<industry>.<domain>.<aggregate>`）で束ね、cross-axis sync property を CI で物理 enforce する。schema 6 class × 4 dimension の bundle で互換性 mode / deprecation_period / breaking_change_policy / registry_backend を一意に導出。

## 6 schema_class（[スキーマ進化適合仕様](../../04_詳細設計/01_適合仕様/06_スキーマ進化適合仕様.md)）
- `v1_external_proto`: BACKWARD / 12 ヶ月 / major_only / buf_bsr
- `v1_internal_proto`: NONE / N/A / additive_with_migration / buf_bsr_internal
- `v1_event_avro`: FULL / 24 ヶ月 / major_with_dual_write / apicurio
- `v1_db_ddl`: forward_backward_via_migration / N/A / additive_with_migration / sqlx_migrations
- `v1_config_yaml`: BACKWARD / 6 ヶ月 / additive_only / yaml_in_repo
- `v1_otel_semconv`: FULL / 12 ヶ月 / additive_only / weaver

## aggregate_qualified_name 名前空間
- 共通名前空間: `<industry>.<domain>.<aggregate>`（例: `manufacturing.procurement.purchase_order`）
- 5 軸での declaration:
  - proto: `package manufacturing.procurement.v1`
  - Avro subject: `manufacturing.procurement.purchase_order-value`
  - DDL: schema `manufacturing_procurement` / table `purchase_order`
  - yaml: ネスト key `manufacturing.procurement.purchase_order`
  - SemConv: attribute prefix `manufacturing.procurement.purchase_order.*`

## cross-axis sync property
- 「同 aggregate 名で field / type 同形」を CI で全数検査
- proto を権威とする / DDL を権威とする の片寄せは取らず、各軸が同名で同型の declaration を持つことを invariant とする

## codegen 出力（build artifact、手書き禁止）
- proto → 各言語 stub（Buf workflow）
- proto → Avro schema（buf-for-apicurio plugin）
- proto → DDL ヘッダ
- proto → SemConv attribute schema（OpenTelemetry Weaver）
- 同 input → 同 output bit hash（reproducibility）

## Apicurio Registry GitOps SoT
- Apicurio Registry instance を git lock の物理 cache として再定義
- `apicurio_subjects/` git repo を SoT、Argo CD + Apicurio Operator が reconcile
- Registry API への直接 write は admission policy `block-direct-apicurio-write` で物理拒否
- 詳細は [apicurio_gitops_sot](../../04_詳細設計/03_クロスカッティング適合仕様/03_apicurio_gitops_sot.md)

## 5 層 defense-in-depth
- 層 A: codegen 出力のみ消費、生 schema 文字列なし
- 層 B: Buf breaking / Apicurio compat API / sqlx-cli plugin / Weaver validate / yaml schema validation
- 層 C: cross-version integration test（n-1 / n+1 互換性）
- 層 D: registry runtime（Apicurio が違反 schema を reject）
- 層 E: cross-axis sync property（5 軸の同 aggregate 名で field / type 同形）

## 採用しない設計
- 同 aggregate を真とする「片寄せ」
- schema_class dimension override
- 手書き codegen 出力
- BACKWARD でない外部 wire（External Proto は BACKWARD 必須）
- breaking change の deprecation_window 省略
