# tier3 端末オフラインデバイス

## 一文方針
- オフライン業務は Pending Queue（IndexedDB encrypted）+ 4 layer reducer で構造化、25h 以上の連続オフラインは PWA installed + best-effort（iOS Safari ITP）。WebUSB / Web Bluetooth / Web Serial は Chromium 系直 API + Firefox / Safari 用 Tauri sidecar bridge で全 UA 成立、kiosk / BYOD / MDM 不可端末向けの `v1_no_sidecar` capability_class で degrade 経路を持つ。

## オフライン storage
- distribution_class 別に固定（[client オフライン耐性方針](../09_client設計方針/03_オフライン耐性方針.md) と双方向 lock）:
  - `v1_browser_spa_typescript`: IndexedDB + WebCrypto AES-GCM + non_extractable_cryptokey
  - `v1_thick_native_via_tauri`: IndexedDB（WebView）+ Rust 側 sled or sqlite + WebCrypto AES-GCM + OS keychain wrap
  - `v1_legacy_dotnet_framework`: DPAPI protected blob

## ua_offline_subclass（offline 永続化要件）
12_client/15 capability_matrix.lock.yaml の `ua_offline_subclass` 軸:
- `ios_safari`: ITP（7 日未訪問で script-writable storage 自動削除）の対象。25h 以上の連続オフライン運用は iOS 16.4+ Add-to-Home-Screen インストール済 PWA（display-mode standalone）に限り **best-effort** 対応
- `android_chrome`: navigator.storage.persisted 必須
- `windows_chromium_edge`: navigator.storage.persisted 必須

## health probe（Service Worker registration / installed PWA / persisted storage）
- 業務開始時に health probe 実行:
  - `navigator.storage.persisted()` が true
  - `display-mode: standalone`（iOS）
  - `navigator.standalone === true`（iOS）
- health probe 不合格時は「オフライン業務不適合」として UI で警告

## device 機能（WebUSB / Web Bluetooth / Web Serial）
- Chromium 系（Chrome / Edge）: browser native API 直接利用
- Firefox / Safari: Tauri sidecar bridge 経由（[Tauri Companion sidecar](../../04_詳細設計/03_クロスカッティング適合仕様/07_Tauri_companion_sidecar.md)）
- kiosk / BYOD / MDM 不可端末: `v1_no_sidecar` capability_class で degraded mode（fallback ファイル選択 + サーバ側変換）

## Tauri sidecar の role
- 全 tier3 Web SPA に Tauri sidecar exe を MDM 必須配布
- 認証 + transport: 既定経路は `ws://127.0.0.1:<port>/...` + Origin pin + DPoP 署名済 payload + per-tenant PSK の HMAC（PSK は OS keystore 保管、SPA JS 不可視）
- kiosk 限定 optional 経路: `wss://127.0.0.1:<port>/...` + 自署 cert（per-device root CA を OS / NSS trust store に MDM script で install）
- 詳細は [Tauri Companion sidecar](../../04_詳細設計/03_クロスカッティング適合仕様/07_Tauri_companion_sidecar.md) を参照

## 25h オフラインケース（製造業 pack）
- 検査担当が 25h オフラインで検査入力 → 復帰時に Idempotency-Key TTL（24h）超過判定
- ユーザに再送 / 破棄を確認、新 Idempotency-Key で resend のフローを完全自動
- 製造業 pack stress test で全自動検証

## background sync / Service Worker
- v1: Service Worker は cache-first read-through cache のみ採用
- background sync は v2 候補（`v2_sw_background_sync`）

## purge triggers
- `logout` / `refresh_token_expiry` / `tenant_switch` / `actor_switch` / `device_bound_key_rotate`
- 全 trigger で 4 layer storage を purge + audit emit

## 採用しない設計
- LocalStorage / SessionStorage / cookie への PII 平文書込
- 自製 crypto
- iOS Safari タブ単独での 25h 以上連続オフライン運用（installed PWA 必須）
- Tauri sidecar PSK の SPA / SDK / window.* / localStorage / memory への露出
- background tab での全 subscription 切断
- WebUSB / Web Bluetooth / Web Serial の自製 protocol
