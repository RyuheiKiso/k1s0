# tier3 検索一覧 UX

## 一文方針
- 検索 / 一覧 UI は tier2 read model 経由で表示、cursor-based pagination + sort + filter + 差分強調 + virtual scroll で標準化する。検索フィールド入力は debounce、async response は 4 layer state（Server Truth）に reflect。

## 検索 UI
- 検索フィールド: 入力中は debounce（300ms）
- async response: Server Truth layer に reflect、検索結果一覧を update
- 検索条件は URL query string で deep link 可能

## 一覧 UI
- cursor-based pagination（offset-based 不採用）
- 列ソート（昇順 / 降順）+ 多列ソート
- 列フィルタ（範囲 / 完全一致 / 部分一致）
- 列固定（左側 / 右側）
- 差分強調: server_truth_advance event で更新行を highlight

## virtual scroll
- 100 行以上の一覧は virtual scroll（react-window 等）で performance 確保
- スクロール位置は URL fragment で deep link 可能

## 一覧の選択 UI
- 単一選択 / 複数選択（checkbox）
- 一括操作（bulk action）は admin API 経由（tier3 業務 UI に admin 機能を載せない、[管理境界](../03_tier2設計方針/14_管理境界.md)）

## 検索結果の操作
- 行クリックで詳細画面 navigate
- 行内に inline action（edit / archive / delete）
- すべて tier2 read model + Repository abstraction 経由

## 採用しない設計
- offset-based pagination
- client-side で全データ取得後に sort / filter（必ず server-side）
- 認可結果の client-side cache（[tier3 強制機構](../../04_詳細設計/02_強制機構/03_tier3強制機構.md) 層 4）
