# tier3 UI 技術スタック

## 一文方針
- 3 アプリケーション形態（Web SPA / デスクトップ exe / レガシー）の各形態で固定の技術スタック。Web SPA = TypeScript + React、デスクトップ exe = C# (.NET 8+) WPF または Rust + Tauri、レガシー = .NET Framework 4.6.2+ + WinForms / WPF。

## Web SPA 技術スタック
- **言語**: TypeScript（strict mode）
- **UI framework**: React（latest LTS）
- **ビルド / バンドラ**: Vite
- **パッケージマネージャ**: pnpm（内部 Verdaccio mirror）
- **state**: tier2 SDK 内蔵 4 layer reducer + React hooks
- **routing**: React Router
- **form**: react-hook-form（tier2 schema validator 経由）
- **HTTP / fetch / WebSocket / SSE**: native + tier2 SDK
- **OTel**: `@opentelemetry/sdk-trace-web` + `@opentelemetry/auto-instrumentations-web`

## デスクトップ exe 技術スタック
- **C# (.NET 8+)**: WPF / Avalonia
- **Rust + Tauri**: Tauri framework + Rust 側 + WebView 側 React

## レガシー（.NET Framework 4.6.2+）技術スタック
- **言語**: C# / VB.NET
- **UI framework**: WinForms / WPF
- **HTTP**: HttpClient + WinHttpHandler（ALPN h2 必須環境）
- **OTel**: OpenTelemetry .NET Auto-Instrumentation（CLR Profiler）+ `k1s0.Companion.NetFx.OTelExt`
- **Companion runtime**: `k1s0.Companion.NetFx`

## ブラウザサポート
- Chromium 系（Chrome / Edge）latest LTS
- Firefox latest LTS
- Safari latest LTS
- Internet Explorer / Edge Legacy: v1 unsupport

## 採用しない技術
- Angular / Vue / Svelte（React L1+ 単一深耕）
- Redux / MobX / Recoil / Pinia / NgRx（tier2 SDK 内蔵 4 layer reducer に集約）
- Electron（Tauri L1+ 単一深耕、Tauri は Rust + native WebView でメモリ効率良好）
- jQuery（モダン web standards のみ）
- AGPL-3 OSS
