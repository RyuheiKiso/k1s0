# tier3 添付帳票 UX

## 一文方針
- 業務添付ファイルアップロード / 帳票生成 UI は MIME type validation + virus scan + signed URL ダウンロード + sandbox iframe 表示で標準化する。本体保管は tier1 Object Storage Library 経由（Rook+Ceph RGW）、UI は signed URL のみ取得。

## アップロード UX
- ファイル選択（drag & drop + file picker）
- MIME type validation（業務 use case 別 allowlist）
- ファイルサイズ check（業務 use case 別上限）
- progress bar（chunked upload）
- アップロード後に virus scan 結果 polling
- メタデータ入力（タイトル / 説明 / カテゴリ）

## ダウンロード UX
- tier2 経由で signed URL 生成（短期 TTL）
- Content-Disposition header で download 実行
- 表示は sandbox iframe で開く（XSS 防御）

## 帳票生成 UX
- 帳票テンプレート選択（業界横断 / 業界共通 / 業界固有）
- パラメータ入力（期間 / 対象 aggregate）
- 帳票生成 button → tier2 経由で帳票生成 + Object Storage 保管 + signed URL 受領
- preview + 印刷 button + ダウンロード button

## オフライン中のアップロード
- offline 中は Pending Queue に enqueue
- 復帰時に自動 send（IndexedDB encrypted）

## tier3 拡張点
- 帳票レイアウトは tier3 で override 可能（[tier2 業務資産所有権](../03_tier2設計方針/06_業務資産所有権.md)）
- 添付ファイルの業務 use case 別 MIME type allowlist 追加は tier3 / テナント運用責任

## 採用しない設計
- 添付ファイル本体を tier3 client side で保管（必ず tier1 Object Storage 経由）
- MIME type validation 不在のアップロード
- virus scan 不在のアップロード
- 直接 URL でファイル表示（必ず signed URL + sandbox iframe）
