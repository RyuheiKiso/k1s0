# tier3 フォーム設計規約

## 一文方針
- フォームは Section / Step / Wizard の構造化、validation 表示位置 / IME 対応 / 楽観更新差戻し / 自動保存 Draft 状態 / 未保存変更破棄警告の 8 標準パターンで構成。tier2 が提供する form schema validator を消費し、独自 validator は禁止。

## 構造化（Section / Step / Wizard）
- **Section**: 同一画面内で論理グループ化（業務カテゴリ別）
- **Step**: 多段入力の段階表示（業務 wizard）
- **Wizard**: 多画面トランザクション境界（aggregate 作成 / 確定の連続 step）
- 各 Section / Step は collapse / expand 可、accessibility（aria 属性）必須

## Validation 表示
- Inline（入力欄直下）: field-level validation
- Summary（画面上部）: form-level validation summary
- Toast（一時表示）: server-side validation 失敗
- screen reader 通知: aria-live="polite"

## ValidationError と DomainError の UI 区別
- **ValidationError**: client / server 両側の field-level validation（型 / 範囲 / 必須）
  - inline 表示、入力欄に focus
- **DomainError**: business logic 違反（[業務エラー UX](13_業務エラーUX.md)）
  - tier2 BusinessConflict subtype（[クライアント状態適合仕様](../../04_詳細設計/01_適合仕様/11_クライアント状態適合仕様.md)）に従う

## 入力支援
- placeholder text（hint）
- input mask（電話番号 / 日付 / 郵便番号）
- autocomplete（マスタ参照、tier2 経由）
- file picker（添付ファイル、tier1 Object Storage 経由）

## IME / 全半角 / 桁区切り / 数値 / Decimal
- IME on/off の field-level 制御（数値入力は IME off）
- 全角 / 半角 自動変換（電話番号 / 郵便番号）
- 桁区切り表示（数値 / 通貨）
- Decimal 精度: business-specific、tier2 schema で固定

## 単位 / 通貨入力
- 単位は dropdown + tier2 master（質量 / 長さ / 容量 等）
- 通貨は ISO 4217 code、業務 master からテナント default

## 楽観更新と server validation 後の差戻し
- 4 layer state（[状態管理](04_状態管理.md)）の Draft → Pending Queue → Optimistic Local → Server Truth
- server validation 失敗時 → BusinessConflict subtype に従い rollback + UI 表示
- field-level diff で stale_write の auto rebase（[クライアント状態適合仕様](../../04_詳細設計/01_適合仕様/11_クライアント状態適合仕様.md)）

## 自動保存 / Draft 状態
- 入力中は Draft layer に reflect（IndexedDB encrypted）
- 30s 間 inactivity で auto save（明示的な save ボタン押下なし）
- Draft は confirm 成功 / 明示破棄で消滅
- Draft restore: 画面 reopen 時に「保存中の編集があります」を表示

## 未保存変更の破棄警告
- 画面遷移時に Draft dirty state があれば confirmation dialog
- ブラウザ tab close 時に `beforeunload` event で警告（browser 標準）

## 採用しない設計
- 自製 form validator（tier2 schema validator のみ）
- 楽観更新なしの全 form server side blocking
- Draft の localStorage 平文保管（IndexedDB encrypted のみ）
- IME 対応なしの数値入力
- 未保存変更破棄警告の opt-out
