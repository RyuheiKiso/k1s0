# tier3 配布デプロイ運用

## 一文方針
- tier3 業務 UI の配布は 3 形態別に固定。Web SPA = CDN 静的配信 + bundle versioning + cache busting、デスクトップ exe = MDM 配布（cosign signed exe）+ Tauri sidecar、レガシー = MSI / MSIX 配布。Argo Rollouts による progressive delivery + AnalysisTemplate auto rollback。

## Web SPA 配布
- **CDN 静的配信**: Cloudflare / CloudFront 等（vendor lock-in 回避は infra GitOps 経由）
- **bundle versioning**: fingerprint hash（content hash）
- **cache busting**: HTML（index.html）は `Cache-Control: no-store`、bundle は `max-age=31536000, immutable`
- **CSP / セキュリティヘッダ**: 必須宣言（[tier3 強制機構](../../04_詳細設計/02_強制機構/03_tier3強制機構.md) 層 11）
- **TLS**: cert-manager + ACME

## デスクトップ exe 配布
- **MDM 配布**: Microsoft Intune / Jamf / Workspace ONE
- **cosign signed exe**: 署名検証必須
- **Tauri bundle**: msi / dmg / AppImage
- **auto-update**: MDM の auto-update 機構

## レガシー（.NET Framework）配布
- **MSI / MSIX**: 既存 .NET Framework 4.6.2+ 端末に配布
- **prerequisite check**: Windows 10 1607+ / Server 2016+ / WinHttpHandler 必須
- **Companion runtime（k1s0.Companion.NetFx）の同梱**: NuGet 配布

## progressive delivery
- **Argo Rollouts**: canary deployment + analysis template
- **canary**: 5% / 25% / 50% / 100% の段階的 rollout
- **AnalysisTemplate**: error rate / latency / Web Vitals の閾値で auto rollback
- **PR preview env**: Argo CD ApplicationSet で各 PR の preview env 自動生成

## 採用しない設計
- 古い bundle 版での deep link 強制 navigate（必ず最新 bundle にリダイレクト + 復元）
- cosign signed なしの配布
- AnalysisTemplate なしの canary（必ず auto rollback 機構）
- 商用 CDN への依存（vendor lock-in 回避、複数 CDN provider に対応）
