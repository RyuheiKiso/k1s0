# tier3 セキュリティアーキテクチャ

## 一文方針
- クライアント側 surface の脅威モデルを security/15 脅威モデル適合仕様の 5⁴ cell として表現。XSS / CSRF / token 漏洩 / PII 漏洩 / supply chain / session 固定 の 6 主要脅威に対し、CSP + SameSite + HttpOnly cookie + access_token getter ゼロ + Cosign signed bundle + BFF auth-edge の 6 層で物理 enforce する。

## 脅威モデル（クライアント側 surface）
- 5 actor class（curious user / malicious tenant / external attacker / supply chain attacker / privileged insider）× 5 capability × 5 surface × 5 asset × 5 mitigation の cross-product
- tier3 が client-side surface（browser sandbox / IndexedDB / cookie / Service Worker / Tauri sidecar）の所有者
- 詳細は [脅威モデル適合仕様](../../04_詳細設計/01_適合仕様/15_脅威モデル適合仕様.md)

## 主要脅威と緩和策

| 脅威 | 緩和策 |
|---|---|
| XSS | CSP `default-src 'self'` + `unsafe-inline` 禁止 + SRI |
| CSRF | SameSite=Lax + Double-Submit Cookie + Origin/Referer 二重検査（[BFF auth-edge](../../04_詳細設計/03_クロスカッティング適合仕様/06_BFF_auth_edge.md) BFF-E） |
| token 漏洩 | httpOnly cookie + access_token getter ゼロ（[認証認可マルチテナント](07_認証認可マルチテナント.md)） |
| PII 漏洩 | localStorage / sessionStorage / cookie への PII 平文書込禁止（[tier3 強制機構](../../04_詳細設計/02_強制機構/03_tier3強制機構.md) 層 5）+ OTel Collector redaction |
| supply chain | Cosign signed bundle + SBOM + 内部レジストリ唯一化（層 12, 13） |
| session 固定 | session ID rotation on login + back-channel logout broadcast |

## クライアント側 Secret
- access_token: window.* / localStorage / IndexedDB / sessionStorage / memory / Service Worker いずれにも置かない（BFF 経由のみ）
- refresh_token: BFF process memory + Valkey（HttpOnly cookie 不可視）
- Tauri sidecar PSK: OS keystore（DPAPI / Keychain / Secret Service）保管、SPA JS 不可視
- device_bound_key: WebCrypto non-extractable CryptoKey

## ブラウザ拡張機能との境界
- ブラウザ拡張機能は信頼境界外（user 設定で disable 不可、企業ポリシーでブロック推奨）
- 業務 critical 操作には拡張機能が干渉できない（CSP + iframe sandbox）

## 添付ファイル攻撃面
- ファイルアップロードは MIME type validation + virus scan（tier1 経由）
- 業務 use case 別の許可 MIME type allowlist
- ファイルダウンロードは Content-Disposition header + sandbox iframe で開く

## third-party 依存管理
- npm audit / pnpm audit で日次 CVE スキャン
- Cosign signed package のみ install（[tier3 強制機構](../../04_詳細設計/02_強制機構/03_tier3強制機構.md) 層 13）
- license 監査（AGPL / SSPL 系除外）

## セッション固定 / セッション切替
- login 時に session ID rotation
- tenant_switch / actor_switch 時に 4 layer storage 全 purge + 新 session 開始
- back-channel logout broadcast で全 SPA tab を同期 logout

## ログ / RUM への PII 漏洩防止
- OTel Collector redaction processor で PII 物理削除
- 自由テキスト attribute 禁止（CI で deny）
- HTTP body / SQL を log に含めない（uri / method / status のみ）

## 同意管理 / GDPR cookie consent
- cookie consent banner（GDPR 対応）
- 必須 cookie（session_id）のみ default、analytics cookie は opt-in
- 同意変更は profile 画面でいつでも可能

## 採用しない設計
- CSP の `unsafe-inline` / `unsafe-eval`
- SameSite=Strict cookie（OIDC redirect 落ち）
- access_token の SPA storage
- localStorage / sessionStorage への PII 平文
- Tauri sidecar PSK の SPA 露出
- analytics cookie の opt-out（GDPR consent 必須）
