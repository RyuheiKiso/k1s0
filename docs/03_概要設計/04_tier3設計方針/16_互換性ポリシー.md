# tier3 互換性ポリシー

## 一文方針
- tier3 は tier2 互換性ポリシーに追従しつつ、ブラウザ更新 + bundle versioning + cache busting + データ移行 + レガシー並走 + API バージョニングの 7 規律で物理 enforce。1.0.0 完璧主義との整合のもと、ブラウザは Chromium / Firefox / Safari の latest LTS のみサポート。

## 1.0.0 完璧主義との整合
- 段階的 release を採らず、1.0.0 で全機能完備
- 1.0.0 後の MINOR up は purely additive のみ

## tier2 minor 追従
- tier2 minor up: tier3 は purely additive 範囲で吸収
- tier3 業務コード変更なし（拡張点 signature の追加は purely additive）
- 観測 SemConv の minor up は OTel Weaver で生成定数自動更新

## tier2 major 追従
- tier2 major up: tier3 の override 部に修正が入る可能性
- tier2 が提供する移行 codemod を tier3 リポジトリに適用
- 拡張点 signature 変更の影響範囲を [override 実装規約](15_override実装規約.md) の contract test で検出

## tier3 自身の SemVer
- MAJOR.MINOR.PATCH（SemVer 2.0.0）
- MAJOR up: 破壊的 UI 変更（routing 変更 / form 構造変更 等）
- MINOR up: purely additive（新画面 / 新機能 / 新 locale 追加）
- PATCH up: バグ修正のみ

## ブラウザ更新追従
- サポート対象: Chromium 系 + Firefox + Safari の latest LTS
- ブラウザ EOL → サポート対象から除外（v1_legacy_http11 capability_class へ降格）
- Internet Explorer / Edge Legacy は v1.0.0 unsupport

## bundle versioning / cache busting
- bundle filename に fingerprint hash（content hash）
- HTTP response header に `Cache-Control: max-age=31536000, immutable`
- HTML（index.html）は `Cache-Control: no-store`
- 古い bundle 版での deep link は最新 bundle にリダイレクト + 復元

## データ移行影響
- tier2 の DDL migration / event schema major up に追従
- tier3 業務コード側の影響は extension point 経由
- migration era の dual-read（旧 schema / 新 schema 両対応）は tier2 SDK が透過

## レガシー（Companion 経由）との並走
- レガシー .NET Framework 形態（[レガシー資産統合](09_レガシー資産統合.md)）と Web SPA / exe 形態を並走
- 業務処理は tier2 で一致、UI のみ形態別

## API バージョニング
- tier2 公開 API の wire バージョン（proto package `vN`）に追従
- tier3 は generated stub 経由でのみ API 呼出（tier3 リポジトリ内 .proto 配置禁止）
- API MAJOR up は 180 日 deprecation_window で並行 deploy

## deprecation 対応
- deprecated API は使用箇所を CI で検出
- deprecation 期限内に migration codemod 適用
- 期限超過は CI fail

## 採用しない設計
- 段階的 release（1.0.0 完璧主義）
- Internet Explorer / Edge Legacy サポート
- bundle に fingerprint hash なし
- tier3 リポジトリ内 .proto 配置
- deprecation 期限超過での運用継続
- レガシー .NET Framework での Connect-RPC bidi（[レガシー資産統合](09_レガシー資産統合.md)）
