# tier3 アクセシビリティと国際化

## 一文方針
- WCAG 2.1 AA を最低基準とし、axe-core / Lighthouse CI で自動検査 + merge 阻止（[tier3 強制機構](../../04_詳細設計/02_強制機構/03_tier3強制機構.md) 層 10）。国際化は i18n key の locale ファイル管理 + pseudolocalization の文字長変動検出を CI 必須化。

## アクセシビリティ最低基準
- WCAG 2.1 AA 準拠
- axe-core で自動検査、CI で merge 阻止
- 全 interactive element に aria 属性
- 全 form input に label（visible / aria-label）

## キーボード操作
- Tab navigation 順序: 上から下、左から右
- Skip to main content link
- shortcut keys: 業務 critical な操作（save / cancel）に統一
- focus trap: modal / dialog 内

## スクリーンリーダ対応
- 主要 OS スクリーンリーダ（NVDA / JAWS / VoiceOver）で test
- live region: status update / error message を `aria-live="polite"` で announce
- semantic HTML（`<button>` / `<nav>` / `<main>` / `<article>`）

## カラーコントラスト
- 通常 text: contrast ratio ≥ 4.5:1
- large text: ≥ 3:1
- color のみで意味を伝えない（icon + text）
- color blind 対応 palette

## 動きの抑制（prefers-reduced-motion）
- ユーザの OS 設定 `prefers-reduced-motion` を尊重
- アニメーションは最小限、必須でない場合は OFF

## フォーカス表示
- focus indicator visible（outline）
- custom focus style: contrast ratio ≥ 3:1

## フォーカス管理
- modal open 時: 最初の interactive element に focus
- modal close 時: open trigger に focus 戻し
- async loaded content: 適切な location に focus

## 国際化対象（tier2 21 国際化方針 整合）
- text content: i18n key で表現
- 日付 / 時刻 / 数値 / 通貨 / 単位 表示形式: locale-aware
- 文字方向: LTR / RTL（Arabic / Hebrew 対応は v2 候補）
- character set: UTF-8 統一

## 数値・日付の表示形式
- 数値: locale-aware 桁区切り（`Intl.NumberFormat`）
- 日付: locale-aware 形式（`Intl.DateTimeFormat`）
- 通貨: ISO 4217 code + locale-aware 表示
- 時刻: 24h / 12h locale-aware
- timezone: ユーザ設定 + tenant default

## i18n 規律
- 翻訳キーは `t('xxx.yyy.zzz')` 形式
- locale ファイル（JSON / YAML）を git 管理
- 未定義キー / 未使用キーを CI で検出（[tier3 強制機構](../../04_詳細設計/02_強制機構/03_tier3強制機構.md) 層 7）
- pseudolocalization での文字長変動検出（CI で実行）

## 1.0.0 出荷時の対応 locale
- 日本語（ja-JP）
- 英語（en-US）
- 追加 locale は purely additive（業界 / テナント要件次第）

## 採用しない設計
- WCAG 2.1 AA 違反 / Web Vitals 閾値違反の merge
- color のみで意味を伝える UI
- 翻訳キー未定義のまま deploy
- LTR 専用 hard-coded UI（v1 は LTR のみだが、RTL 拡張余地を残す）
- timezone hard-coded
