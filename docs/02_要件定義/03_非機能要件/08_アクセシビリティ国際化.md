# アクセシビリティ国際化要件

## 一文方針
- WCAG 2.1 AA を最低基準、axe-core / Lighthouse CI で merge 阻止。i18n は 1.0.0 で日本語 / 英語 ship、追加 locale は purely additive。pseudolocalization 文字長変動検出を CI 必須化。

## アクセシビリティ要件
- WCAG 2.1 AA 準拠
- axe-core で自動検査、CI で merge 阻止
- 全 interactive element に aria 属性
- 全 form input に label
- カラーコントラスト: 通常 text ≥ 4.5:1 / large text ≥ 3:1
- 動きの抑制: `prefers-reduced-motion` を尊重
- フォーカス表示: outline visible、custom focus contrast ≥ 3:1
- スクリーンリーダ: NVDA / JAWS / VoiceOver で test

## キーボード操作
- Tab navigation 順序: 上から下、左から右
- Skip to main content link
- shortcut keys: 業務 critical な操作（save / cancel）に統一
- focus trap: modal / dialog 内

## Web Vitals 要件
- LCP（Largest Contentful Paint）p95 ≤ 2.5s
- INP（Interaction to Next Paint）p95 ≤ 200ms
- CLS（Cumulative Layout Shift）p95 ≤ 0.1
- Lighthouse CI で merge 阻止

## i18n 要件
- 1.0.0 出荷 locale: 日本語（ja-JP）/ 英語（en-US）
- 追加 locale は purely additive
- 数値 / 日付 / 通貨 / 単位: locale-aware（`Intl.NumberFormat` / `Intl.DateTimeFormat`）
- 文字方向: LTR（RTL は v2 候補）
- character set: UTF-8 統一
- timezone: ユーザ設定 + tenant default

## i18n 規律
- 翻訳キーは `t('xxx.yyy.zzz')` 形式
- locale ファイル（JSON / YAML）を git 管理
- 未定義キー / 未使用キーを CI で検出
- pseudolocalization での文字長変動検出を CI 必須化

## 受入条件
- WCAG 2.1 AA 違反ゼロ
- Web Vitals 閾値内（Lighthouse CI green）
- 翻訳キー未定義参照ゼロ
- pseudolocalization テスト green
