# 互換性ポリシー要件

## 一文方針
- 6 schema_class × 5 dimension（schema_kind / compatibility_mode / deprecation_period / breaking_change_policy / registry_backend）の bundle で全 schema 互換性を固定。SemVer + 並行バージョン提供 + 移行コミットメント を必須要件とする。

## 6 schema_class 要件
- `v1_external_proto`: BACKWARD / 12 ヶ月 / major_only / buf_bsr
- `v1_internal_proto`: NONE / N/A / additive_with_migration / buf_bsr_internal
- `v1_event_avro`: FULL / 24 ヶ月 / major_with_dual_write / apicurio
- `v1_db_ddl`: forward_backward_via_migration / N/A / additive_with_migration / sqlx_migrations
- `v1_config_yaml`: BACKWARD / 6 ヶ月 / additive_only / yaml_in_repo
- `v1_otel_semconv`: FULL / 12 ヶ月 / additive_only / weaver

## SemVer 規律
- MAJOR.MINOR.PATCH（SemVer 2.0.0）
- MAJOR up: 破壊的変更 + 180 日 deprecation_window + 1 LTS overlap + 移行 codemod
- MINOR up: purely additive
- PATCH up: バグ修正のみ

## 並行バージョン提供
- MAJOR up 時は旧 / 新 MAJOR を並行 deploy
- tier3 は段階的に新 version に移行
- 旧 MAJOR の sunset は deprecation_window 経過後

## 移行コミットメント
- L1+ カテゴリの 4 primary pair（CloudNativePG↔StackGres / Kafka↔RedPanda / Temporal↔Cadence / ZEN↔自製 DSL）の dry_run.lock.yaml の last_green_at が 365 日以内
- toolchain は Library 本体と同じリポジトリで継続的維持

## 受入条件
- 6 schema_class × 全 schema instance の compatibility test green
- aggregate_qualified_name 5 軸（proto / Avro / DDL / yaml / SemConv）同期 property green
- 4 primary pair dry_run green
