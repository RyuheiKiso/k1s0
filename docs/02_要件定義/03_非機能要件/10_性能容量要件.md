# 性能容量要件

## 一文方針
- 5 quota_class × 4 dimension（enforcement_layer / fairness_model / burst_window / exhaustion_response）の bundle で全 quota を機械可読に固定。4 階層 enforcement（envoy_local_rate_limit / library_token_bucket / oss_native_quota / storage_layer_quota / broker_layer）+ noisy neighbor isolation の物理 property を必須要件とする。

## 5 quota_class 要件
| class | enforcement_layer | fairness_model | burst_window | exhaustion_response |
|---|---|---|---|---|
| `v1_per_tenant_qps` | envoy_local_rate_limit | per_tenant | short_1s | reject_429 |
| `v1_per_tenant_concurrency` | library_token_bucket | per_tenant_per_action | medium_1m | queue_with_timeout |
| `v1_per_tenant_volume` | storage_layer_quota | per_tenant | long_1h | overflow_to_cold |
| `v1_per_tenant_compute` | oss_native_quota | per_tenant_per_action | medium_1m | shed_by_priority |
| `v1_global_fair_queue` | broker_layer | global_share | continuous | partition_rebalance |

## 4 階層 enforcement
- **階層 1 ingress**: Envoy Gateway Local Rate Limit filter
- **階層 2 Library**: in-process token bucket
- **階層 3 OSS native quota**: Temporal namespace quota / KEDA / pgvector workload pool
- **階層 4 storage / broker**: Rook+Ceph namespace quota / CloudNativePG / ClickHouse / Kafka

## noisy neighbor isolation
- 「1 テナントの burst が他テナントの SLO を破らない」を chaos test で必ず検証
- 「波及確率 ≤ 5%」+ 自動昇格 5 min 以内（[SLO_protection_layers](../../04_詳細設計/03_クロスカッティング適合仕様/05_SLO_protection_layers.md)）

## per-tab subscription 上限
- 業務 listener: per-tab 16 subscription（HTTP/2 multiplex）
- v1_legacy_http11 listener: per-tab 6 subscription（HTTP/1.1 物理上限）

## 受入条件
- 5 quota_class × 全 enforcement point の完全 conformance green
- noisy neighbor isolation chaos test green
- 13 SLO 適合仕様 と双方向 lock（quota 違反時に SLO burn-rate alert 連動）
