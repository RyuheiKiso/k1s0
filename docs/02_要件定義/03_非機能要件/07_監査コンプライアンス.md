# 監査コンプライアンス要件

## 一文方針
- audit signal の SoR は ClickHouse、hash chain（hash_prev / hash_self）+ 外部公証 attestation（RFC 3161 trusted timestamp + Sigstore transparency log）+ WORM Object Lock Compliance mode + 7 年〜10 年 retention で immutable 保管。GDPR 物理削除は KEK destroy で wrapped DEK を不可逆失効（crypto-shred）。

## audit signal SoR
- ClickHouse `audit` table（PII 構造的不在）
- atomic 三表書込（State change + Outbox + Audit を同 transaction）で書込
- audit relay が `audit_local` → ClickHouse に転送（at-least-once + ReplacingMergeTree で idempotent）

## hash chain
- 各 audit_event に対し `hash_self = SHA256(hash_prev || canonicalize(audit_event))`
- 年次 root（tenant 別）に `v1_audit_root_signing` 鍵で署名
- 外部公証（RFC 3161 trusted timestamp + Sigstore transparency log）に提出
- ClickHouse 側で hash chain を再検証

## audit ingest gap monitor
- audit_event hash chain の「書かれた行同士の改竄検知」しか保証できない事実を honest に受け止める
- ingest pipeline の gap / drop を別経路で検出: heartbeat insert（1 min）+ gap monitor + ops-edge cluster での SPOF 対策

## immutable 保管
- Ceph RGW Object Lock Compliance mode（root 権限でも解除不可）
- WORM retention: 7 年〜10 年（規制要件次第）

## GDPR 対応
- データポータビリティ: テナント data export
- 物理削除: KEK destroy で wrapped DEK 不可逆失効（crypto-shred）
- 同意管理: cookie consent banner + analytics opt-in

## actor 表現の固定
- actor 識別子は Keycloak subject（不可逆 ID、`sub` claim）
- 氏名 / メール / 電話 / 端末 ID は audit signal に出さない

## 規制対応
- 日本: 個人情報保護法
- EU: GDPR + データ局所性
- 製造業: ISO 9001 / 医薬品 GMP / 食品 HACCP / 環境 ISO 14001
- 業界 pack ごとに retention 要件を宣言

## 受入条件
- audit hash chain divergence ゼロ
- audit ingest gap = 0（heartbeat + gap monitor）
- 外部公証 attestation 経路 green
- crypto-shred 互換 property test green
- WORM retention 設定 green
