# 言語スタック要件

## 一文方針
- tier1 Server 系 = Rust 単一深耕（Operator のみ Go）。tier1 Library 対応 = Rust / C# (.NET 8+) / Go / TypeScript の 4 言語。tier2 / tier3 は同 4 言語。Companion = .NET Framework 4.6.2+。SDK 配布は 9 言語（+ Java 21 / Python 3.12 / Ruby 3.3）の lockstep release。

## tier1 言語
- **Server 系**: Rust（主言語、stable）
- **Operator / Controller**: Go 1.22 + controller-runtime / kubebuilder（生態系都合）
- **Library 対応**: Rust / C# (.NET 8+) / Go / TypeScript

## tier2 言語
- 主要言語: Rust / C# (.NET 8+) / Go / TypeScript
- 業務 service の bounded context ごとに選択

## tier3 言語
- Web SPA: TypeScript + React
- デスクトップ exe: C# (.NET 8+) または Rust + Tauri
- レガシー: .NET Framework 4.6.2+ + WinForms / WPF

## SDK 配布言語（9 言語、lockstep release）
- .NET 8 LTS / .NET Framework 4.6.2+ / Java 21 LTS / Node.js 20 LTS / Browser TypeScript / Tauri / Rust stable / Python 3.12 / Ruby 3.3 / Go 1.22

## Companion 言語
- .NET Framework 4.6.2+（tier1 Library 対応外、Companion で代替）

## 言語追加の手順
- 新言語追加は purely additive
- tier1 / tier2 / tier3 の言語追加は同期、SDK 言語追加は SDK lockstep に乗る

## 採用しない言語
- iOS Swift / Android Kotlin: v1 出荷外（v2 候補、tier1 / tier2 / SDK の言語追加が先行）
- Java 8 など古い JVM: v1 unsupport
- C / C++: tier1 Server 系 / Library 対応外（formal 軸 CBMC 検査対象として infra 側のみ）
- Scala: formal 軸（Stainless）入力言語のみ

## 受入条件
- tier1 / tier2 / tier3 / SDK 全言語が build green
- 4 言語等価強度（compile-time 不正遷移防止）の property test green
- lockstep release（MAJOR.MINOR skew = 0）
