# OS 固有依存例外

## 一文方針
- OS native API（APNs / FCM / DPAPI / Keychain / Secret Service / WebCrypto non-extractable CryptoKey）の利用は (e) OS native 例外として用途限定で許容する。本企画の OSS L1+ 単一深耕方針の例外として、OS 提供機能のみが満たせる物理 enforcement（at-rest encryption / mobile push 通知 / OS keychain アクセス）に限定する。

## OS native 依存の用途限定

### モバイル push 通知
- **APNs**（Apple Push Notification service）: ops-edge escalation cluster の last-mile 通知（iOS 端末への on-call page）
- **FCM**（Firebase Cloud Messaging）: 同（Android 端末）
- 業務 push 通知（業界横断 通知 機能）には用途しない、ops-edge cluster の escalation のみ

### at-rest encryption（OS keychain）
- **Windows DPAPI**: .NET Framework Companion の refresh_token / device cert 暗号化
- **macOS Keychain**: Tauri sidecar の per-tenant PSK / refresh_token 保管
- **Linux Secret Service**: 同上
- **WebCrypto AES-GCM + non-extractable CryptoKey**: Browser SPA の IndexedDB encrypted storage

### Tauri sidecar 配布
- **Windows MSI / Microsoft Intune**: MDM 配布
- **macOS DMG / Jamf**: MDM 配布
- **Linux deb / rpm / AppImage**: 自製 MDM 配布 channel

## OS 版数 prerequisite
- **Windows 10 1607+ / Server 2016+**: WinHttpHandler の HTTP/2 ALPN 対応（[HTTP/2 enforcement](../../04_詳細設計/03_クロスカッティング適合仕様/01_HTTP2_enforcement.md)）
- **iOS 16.4+**: Add-to-Home-Screen インストール済 PWA（25h オフライン best-effort）
- **macOS Ventura+ / Windows 10+ / Linux kernel 5.10+**: Tauri sidecar の CSP 互換性

## OS 固有 API の SDK 隠蔽
- SDK 公開 API としては OS 固有 API を露出しない（distribution_class が一意に決める）
- アプリ作者は SDK API を呼ぶだけで OS 固有部は隠蔽
- 例外: Tauri sidecar の OS 固有部（OS keystore アクセス）は sidecar 内部のみ、SPA JS から不可視

## 採用しない OS 依存
- iOS Swift / Android Kotlin の業務 SDK（v1 出荷外）
- Internet Explorer / Edge Legacy（v1 unsupport）
- Windows 7 / 8.1 / Server 2008R2 / Server 2012（`v1_legacy_http11` 専用 listener fall back）
- 古い Java 8（v1 unsupport）

## 受入条件
- OS 固有 API 利用箇所がすべて [OSS 採用一覧](../04_技術選定/01_OSS採用一覧.md) `OS 固有依存例外` 節で明示
- SDK 公開 API として OS 固有 API ゼロ（CI 検査）
- prerequisite OS 版数 check が Backstage onboarding workflow で必須
