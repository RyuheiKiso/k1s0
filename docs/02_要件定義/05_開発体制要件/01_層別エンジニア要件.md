# 層別エンジニア要件

## 一文方針
- 5 階層論に対応する 5 階層エンジニア体制 + formal / security / ops / test の 4 横断軸専任 + プラットフォーム運営者 + 業務管理者 の混合組織。tier3 担当はジュニア級、tier1 / formal / security はシニア級、cross-cutting は senior + domain expert の dual structure。

## 階層別エンジニア要件

### infra 軸エンジニア（シニア級）
- 必須スキル: Kubernetes / Argo CD / Istio / Calico BGP / Envoy / OpenBao / Cosign / Litmus
- 想定人数: 3-5 名

### data 軸エンジニア（シニア級）
- 必須スキル: PostgreSQL / CloudNativePG / Kafka / Strimzi / ClickHouse / Apicurio Registry / Valkey / Rook+Ceph
- 想定人数: 3-5 名

### tier1 軸エンジニア（シニア級）
- 必須スキル: Rust（主言語）/ Go / C# / TypeScript / proto / Buf / OSS lifecycle
- 想定人数: 5-8 名

### tier2 軸エンジニア（中堅級）
- 必須スキル: 4 言語 + ドメイン業務 / 業界 pack
- 想定人数: 5-10 名（業界 pack ごとに増減）

### tier3 軸エンジニア（ジュニア級）
- 必須スキル: TypeScript + React / C# WPF / .NET Framework + WinForms / Tauri
- 想定人数: 業界 pack × 業務領域 × tenant 数で増減

## 横断軸専任エンジニア

### formal 軸専任（シニア級）
- 必須スキル: TLA+ / Apalache / Stainless / Dafny / Lean 4 / Kani / CBMC / formal methods
- 想定人数: 2-3 名

### security 軸専任（シニア級）
- 必須スキル: 5⁴ cell threat model / KEK shamir / OAuth 2.1 + DPoP / OWASP / penetration testing
- 想定人数: 2-3 名

### ops 軸専任（シニア級）
- 必須スキル: SRE 50% rule / SLO / MWMBR alerting / Argo Rollouts / Backstage TechDocs / Tekton
- 想定人数: 3-5 名

### test 軸専任（シニア級）
- 必須スキル: 5 verification_class / Pact / Playwright / Litmus / mutation testing / property based test
- 想定人数: 2-3 名

## プラットフォーム運営者
- 必須スキル: cluster 運用 + KEK shamir custodian + ops on-call + audit hash chain + 外部公証 attestation
- 想定人数: 5-8 名（24h on-call 3 階層 escalation）

## 業務管理者
- 必須スキル: 業界知識 + tier2 admin API（Backstage プラグイン）
- 想定人数: テナント単位

## 受入条件
- 5 階層 + 4 横断軸 + プラットフォーム運営者 + 業務管理者 の体制完備
- dual reviewer sign-off rate = 100%
- LLM 単独 sign-off rate = 0%
- on-call rotation gap zero（v1_zero_gap または v1_auto_covered_gap [60 分 cap]）
- SRE 50% rule 維持
