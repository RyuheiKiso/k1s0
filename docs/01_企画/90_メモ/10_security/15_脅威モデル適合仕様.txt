============================================================
脅威モデル適合仕様（v1）
（00_軸登録適合仕様 における security 軸 = 14 軸目候補）
============================================================

■ 一文定義
  - 脅威モデル適合仕様は、5 actor × 5 capability × 5
    surface × 5 asset の cross-product として完全列挙
    される threat catalog の各 cell に対し、5 mitigation
    class のいずれかを必ず物理 pointer として bind し、
    全 13 軸 + meta + 自軸の defense-in-depth 層 D / E に
    bind 済みであることを 5 層 defense-in-depth + 13 項
    CI 不変条件 + 13 件製造業 pack stress test で物理
    enforce する meta-axis である。

■ 単一の真（5 yaml、うち 2 が build artifact）
  - classes.yaml（軸 5 class enum）
        actor / capability / surface / asset / mitigation
        の 5 enum 軸を宣言。class 名は version prefix
        固定（v1_xxx）、追加は purely additive。
  - threat_model.lock.yaml（build artifact 1）
        生成器：threat-catalog-builder
        input：classes.yaml + 各軸 spec の defense-in-
              depth 層 D / E + boundary_mitigation
              section
        出力：5⁴ = 625 cell の row（unreachable cell の
              explicit_unreachable=true marking 含む）、
              各 cell に mitigation pointer ≥ 1
        手書き禁止、CI fail。
  - mitigation_bindings.lock.yaml（build artifact 2）
        生成器：mitigation-binder
        input：threat_model.lock.yaml + 13 軸 + meta の
              全 spec の build artifact + boundary_
              mitigation
        出力：mitigation pointer ⇔ 物理 artifact の
              双方向 lock 表（pointer kind / ref /
              source_axis / source_layer）
        手書き禁止、CI fail。
  - pii_classification.lock.yaml（build artifact、本層
    管掌だが 10_PII保護方針 の primary key、threat_
    model.lock.yaml の asset = v1_pii section の primary
    key として参照される）
        生成器：pii-classifier
        input：Apicurio Registry の全 subject + 各
              column の pii_class 注釈 + tier2/22 /
              28 / 06_tier2 の pii_class 規律
        出力：column ↔ pii_class ↔ DEK class の三項関係
  - drill_progress.lock.yaml（build artifact、本層 +
    11_インシデント対応方針 + 12_セキュリティ訓練方針
    が共有管掌、infra 11 / data 11 の failover_drill /
    restore_drill と同型）
        生成器：drill-runner（Tekton job）
        input：scenario_catalog.lock.yaml + drill 実行
              ログ + audit_event の v1_ir fact
        出力：drill_class 別 last_green_at / next_due_at
              / cadence_status

  - 共通制約：
        - 全 yaml は CUE schema で type 検証
        - 全 yaml は cosign signed snapshot として periodic
          に publish（hash chain root とも整合）
        - drift 検出時は Argo CD が self-heal、build
          artifact ↔ runtime の divergence ゼロ

■ 5 層 defense-in-depth（脅威モデル軸全体）
  - 層 A：compile
        - threat_model.lock.yaml の cell = 5⁴ で完全列挙
          （ビルド時に行数 check）
        - mitigation pointer kind enum 検証（textual は
          cap 5%、boundary section は cap 0%）
        - PII column の DEK class binding が tier1/11
          階層内に存在
        - scenario_catalog の全 threat_class coverage
        - CUE 型 check（class enum / pointer kind /
          weight enum）

  - 層 B：lint
        - Conftest custom rule（Rego）：mitigation
          pointer の重複禁止 / textual cap / 軸別最低
          mitigation 数 / coverage gap の zero-tolerance
        - Semgrep meta-rule：threat_class が schema /
          policy に登場するときの命名整合
        - Apicurio compatibility rule：pii_class_only_
          strengthens（PII class の弱化を breaking 判定）

  - 層 C：integration test
        - chainsaw / kuttl で全 admission policy
          （security 担当 23 policy）が intended state
          を block / pass
        - Testcontainers で OpenBao + ClickHouse +
          Kafka + CloudNativePG を local 起動、PII
          access path の audit_event emit を end-to-end
          で確認
        - hash chain divergence 試験（人為的 row 改竄
          → CI 検出 verify）
        - drill scenario の自動 replay（red_team_
          table_top 全 scenario）

  - 層 D：runtime（cluster 上の actual enforcement）
        - Kyverno admission webhook（23 policy）
        - Falco / Tetragon の常駐 detection
        - cosign verify in admission（unsigned image
          deploy block）
        - ClickHouse mutation block（audit_event UPDATE
          / DELETE 物理拒否）
        - cert-manager / OpenBao の auto rotation
        - Vector pipeline の PII redaction
        - audit_event hash chain の online 検証（行
          insert 時 prev hash 一致 check、ClickHouse
          MV）

  - 層 E：物理 enforcement
        - cosign signature の cryptographic verification
          （Sigstore 標準、公開鍵の真正性）
        - Ceph RGW Object Lock Compliance mode（root
          権限でも archive 物理 delete 不可）
        - OpenBao Transit + HSM-backed KEK（鍵 export
          物理不可）
        - audit chain hash の cryptographic forgery
          impossibility（SHA-256 / Blake3 等）
        - mTLS / TLS 1.3 cipher suite OS 強制（weakcipher
          handshake reject）
        - ClickHouse Replicated MergeTree + Keeper Raft
          （audit data の replication consistency 物理
            保証）

■ CI 不変条件（13 項、全て違反は merge 不可）
  - 不変 1 ：classes.yaml の 5 軸 enum が version 別に

            手書き diff = 0

            に mitigation pointer ≥ 1（coverage_full）
  - 不変 4 ：mitigation_bindings.lock.yaml の全 pointer
            が実在 artifact を ref（pointer_resolution）
  - 不変 5 ：mitigation pointer kind の textual / runbook
            が cap 5%、boundary_mitigation cap 0%
  - 不変 6 ：軸別 active mitigation 数が class 別最低値
            ≥ を満たす（actor class 別 30 / 35 / 40 /
            35 / 30 等）
  - 不変 7 ：pii_classification.lock.yaml の全 column が
            Apicurio subject 内、unspecified ゼロ、DEK
            class binding 完全
  - 不変 8 ：scenario_catalog.lock.yaml が threat_model
            の全 threat_class を coverage（全 class
            が一度以上演習対象）
  - 不変 9 ：drill_progress.lock.yaml が全 drill_class
            cadence 内、red 状態ゼロ
  - 不変 10：mitigation_bindings.lock.yaml が 13 軸 +
            meta の全 build artifact と双方向 lock
            （cross-axis assertion 整合）
  - 不変 11：cosign signed image / SBOM attached が
            cluster-wide で runtime drift = 0
  - 不変 12：audit_event の hash chain が日次 verify
            green、過去 7 日 divergence ゼロ
  - 不変 13：Trivy / Grype double-bound scan 結果が
            critical CVE で一致、不一致は admission
            block

■ v2 拡張ルール（purely additive、dimension override
   禁止維持）
  - v2 で actor class 追加（例：v2_third_party_partner、
    B2B 連携 actor）：classes.yaml に entry 追加、threat_
