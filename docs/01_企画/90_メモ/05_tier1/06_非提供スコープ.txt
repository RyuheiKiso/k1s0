============================================================
tier1 Library スコープ外（非提供）
============================================================

■ 業務固有領域
  - tier3 固有の業務ロジック、UI、画面遷移制御。

■ Operator / Controller 実装
  - Kubernetes Operator / Controller は Go で別途実装する
    （Library としては配布しない）。

■ 可視化 UI
  - 可視化ダッシュボードは Perses をプラットフォーム標準として採用する。
    Library としては配布せず、プラットフォーム側で運用する。
  - tier2 / tier3 はダッシュボード UI に直接アクセスし、Library 経由では
    扱わない。

■ サービスメッシュ（Istio）
  - mTLS / トラフィック制御はメッシュが透過的に担う。
    Library は認証 / トレースコンテキストの伝播のみを担当し、
    メッシュ機能を Library API として再露出しない。

■ ブロックストレージ（Longhorn / Ceph RBD）
  - tier2 / tier3 は Kubernetes の PVC 経由で扱う。
    Library では抽象化しない（オブジェクトストレージのみ Library 提供）。

■ 証明書 / PKI（cert-manager）
  - 証明書はプラットフォーム側で発行・配布する。
    Library は受領済み TLS コンテキストを利用するのみ。

■ 開発体験 / 運用ツール
  - Backstage（開発者ポータル）。
  - Testcontainers / Tilt（ローカル開発）。
  - Helm / Kustomize（マニフェスト管理）。
  - sqlx-cli（DB マイグレーション CLI）。
  - これらは Library としては配布せず、テンプレート / ドキュメント
    で利用方法を案内する。
