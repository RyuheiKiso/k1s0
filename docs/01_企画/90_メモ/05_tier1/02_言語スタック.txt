============================================================
tier1 の言語スタック
============================================================

■ Server系
  - 主要言語：Rust
  - 例外：Kubernetes Operator / Controller は controller-runtime /
    kubebuilder の生態系都合で Go を許容する。

■ tier2 / tier3 への配布用 Library
  - 対応言語：Rust, C#(.NET 8+), Go, TypeScript
  - tier2 / tier3 のユーザー（業務）に適する言語で開発できるよう
    Library でサポートする。
  - .NET Framework（4.6.2 / 4.7.2 / 4.8 等）は本 Library の対応言語に
    含めない。理由：
      - Grpc.Net.Client を .NET Framework で動かす場合、HTTP/2 を
        WinHttpHandler 経由で扱う必要があり、client streaming や
        一部 TLS 設定 / プロキシ周りに制約がある。Library が抽象する
        Messaging / Workflow / Relational Store 等を素直に載せる土台
        として安定しない。
      - Library 非対応経路は「ビジネス API は Gateway 経由
        （HTTP/1.1 + JSON, External Proto 由来）」「観測可能性 /
        認証コンテキスト伝播は Observability Companion」で代替する
        枠を既に持っている（01_概要 / 04_Library 参照）。
  - 将来的に .NET Framework での gRPC 周辺事情が変わった場合も、
    Library 対応に組み入れるかどうかは「Library が抽象する全カテゴリ
    を素直に載せられるか」を基準に再判断する。Gateway + Companion で
    足りているうちは Library 対応に追加しない。
