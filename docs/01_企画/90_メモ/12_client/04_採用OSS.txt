[2] gRPC / wire 実装
------------------------------------------------------------
  カテゴリ                       | プロダクト                        | ライセンス
  -------------------------------+-----------------------------------+---------------
  gRPC C++ コア                  | gRPC                              | Apache 2.0
  gRPC .NET                      | grpc-dotnet (Grpc.Net.Client)     | Apache 2.0
  gRPC Java                      | grpc-java                         | Apache 2.0
  gRPC Node                      | @grpc/grpc-js                     | Apache 2.0
  gRPC-Web TypeScript            | grpc-web (improbable / official)  | Apache 2.0
  gRPC Python                    | grpcio                            | Apache 2.0
  gRPC Ruby                      | grpc                              | Apache 2.0
  gRPC Go                        | google.golang.org/grpc            | Apache 2.0
  gRPC Rust                      | tonic                             | MIT
  HTTP/3 + WebTransport (Browser)| native browser API                | -
  HTTP/3 + WebTransport (server) | quinn / s2n-quic 経由 Companion   | Apache 2.0 / Apache 2.0
  WebSocket (TS)                 | native WebSocket                  | -
  WebSocket (.NET)               | System.Net.WebSockets             | MIT
  SSE parser (Browser)           | native EventSource                | -
  SSE parser (.NET / 他言語)     | 自製（言語別、Buf 生成側で固定）  | Apache 2.0

  - SDK 内部で利用する transport library。gRPC bidi が default、
    Browser は gRPC-Web、HTTP/3 + WebTransport / WebSocket /
    SSE は capability matrix で明示宣言された case のみ。
  - SSE parser は data: / id: / event: / retry: の 4 directive
    を解釈する。id: は resume_token として用い、再接続時に
    Last-Event-ID リクエストヘッダで server へ送出する。
    Browser 側は EventSource ネイティブで足りるが、.NET
    Framework など EventSource 非対応環境向けには言語別の
    自製パーサを Companion 同梱で配布する。
  - 横並びの代替（Connect-go-Web 等）は不採用、v2 候補。

[5] パッケージレジストリ / 配信
------------------------------------------------------------
  カテゴリ                       | プロダクト                        | ライセンス
  -------------------------------+-----------------------------------+---------------
  汎用 artifact registry         | Harbor                            | Apache 2.0
  NuGet feed (proxy)             | Harbor (NuGet repo)               | Apache 2.0
  npm registry (proxy)           | Verdaccio                         | MIT
  cargo registry (proxy)         | crates.io mirror via Harbor       | Apache 2.0
  Maven (proxy)                  | Harbor (Maven repo)               | Apache 2.0
  PyPI (proxy)                   | Harbor (PyPI repo)                | Apache 2.0
  RubyGems (proxy)               | Harbor (RubyGems repo)            | Apache 2.0
  Go module (proxy)              | Athens                            | MIT
  package signing                | Cosign / sigstore (npm/PyPI/cargo)| Apache 2.0
  SBOM 生成                      | Syft                              | Apache 2.0
  SBOM 脆弱性スキャン            | Grype                             | Apache 2.0

  - 全 SDK パッケージは Harbor mirror から配信、Cosign signed
    必須、Syft で SBOM 生成 + Grype で脆弱性スキャン CI 必須。
    npm / cargo / NuGet / Maven / PyPI / RubyGems の各 official
    registry への直接配信もするが、内部 enterprise 利用では
    Harbor mirror 経由を強制（infra 側 Kyverno admission policy
    と整合）。
  - npm 系では sigstore の npm signing、PyPI は PEP 740 の
    sigstore signing、cargo は cargo-sigstore experimental（v2）
    を採用評価中、それまでは Harbor の Cosign で必ず署名。

------------------------------------------------------------
  カテゴリ                       | プロダクト                        | ライセンス
  -------------------------------+-----------------------------------+---------------
  IndexedDB ラッパー             | idb (Jake Archibald)              | ISC
  WebCrypto API                  | native browser API                | -

  OS keychain (macOS)            | Tauri tauri-plugin-keychain       | MIT / Apache 2.0
  OS keychain (Windows)          | Tauri DPAPI plugin                | MIT / Apache 2.0
  OS keychain (Linux)            | Tauri Secret Service plugin       | MIT / Apache 2.0
  Service Worker                 | native browser API                | -

  - Browser SPA / Tauri 配下では IndexedDB を offline storage、
    WebCrypto AES-GCM を at-rest 暗号化、device_bound_key を OS
    keychain（Tauri）または non-extractable CryptoKey（pure
    browser）で保管。
  - Service Worker は v1 では offline cache のみ、background
    sync は v2 候補。
