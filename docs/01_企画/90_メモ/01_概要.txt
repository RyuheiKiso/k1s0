============================================================
企画メモ
============================================================

■ 概要
  - OSS として開発・公開する。
  - 企業内に構築するプラットフォームを提供する。
  - 無料利用可能な OSS（Kubernetes、Istio など）を最大限活用する。
  - マイクロサービスの構築を支援する基盤を提供する。

■ ターゲット
  - 企業の情報システム部門。

■ 既存資産への配慮
  - レガシー資産（.NET Framework など）も最小限のカスタマイズで
    プラットフォームの恩恵を受けられるようにする。
  - tier1 SDK を直接組み込めない言語からは tier1 が提供する
    ゲートウェイ経由で infra にアクセスさせる。
    .proto を単一の真とし、Envoy Gateway の gRPC-JSON Transcoder で
    HTTP/1.1 + JSON エンドポイントを派生させる方式を採る。
    （詳細は「tier1 SDK 設計方針」を参照）
