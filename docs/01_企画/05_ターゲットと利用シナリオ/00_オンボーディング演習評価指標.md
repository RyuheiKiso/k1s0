**演習シナリオ**: #3 proto二層化スキーマ進化 + #8 公開API snapshot違反対応  
**提出物**: proto 変更 PR (互換性保持) + snapshot 違反修正 PR  
**self-check**:
- [ ] proto の breaking change / non-breaking change の区別ができる

### Week3-4
**演習シナリオ**: #9 supply_chain障害対応 + #10 SBOM CVE 月次トリアージ  
**提出物**: supply chain 障害対応報告書 + CVE トリアージ結果表

- [ ] SBOM から影響 library を 5 分以内に特定できた
- [ ] CVE の severity 評価基準 (CVSS スコア) を適用できた

### Month2
**演習シナリオ**: #12 L1plus migration dryrun  
**提出物**: dry-run 実行ログ + migration toolchain 設計書  
**自己評価卒業条件**: dry-run が staging で全 artifact に対して合格すること  
**self-check**:
