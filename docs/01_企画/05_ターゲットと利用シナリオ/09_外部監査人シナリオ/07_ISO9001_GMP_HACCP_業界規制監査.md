# ISO9001_GMP_HACCP_業界規制監査

## 一文方針

業界規制（ISO 9001 / GMP / HACCP / ISO 14001）の証跡を audit から抽出し、独立監査を実施する。

> 年次外部審査の中核フェーズ、外部監査人は業務管理者が準備した自主点検資料（シナリオ 10 の出力）をベースに、audit hash chain から独立に証跡を再抽出して自主点検との整合性を確認する。ISO 9001 の品質管理プロセス記録・GMP の製造プロセス記録・HACCP のハザード管理記録を業界規制チェックリストにマッピングし、規制要件との適合性を判断する。

## ペルソナ要約

主役: 外部監査人（公認会計士 / ISO 9001 審査員 / 食品安全審査員）、目的: ISO 9001 / GMP / HACCP / ISO 14001 の外部監査において、業務管理者の自主点検と独立に証跡を確認し規制適合性を判断する

## 現状業務での痛み

- 業務管理者が準備した自主点検資料を監査人が確認するだけでは、資料の選択性バイアスが排除できない
- 監査現場で大量の紙ドキュメントを照合する作業が監査時間の大半を消費する
- 業界規制のチェックリストと実際の業務プロセス記録の対応関係が不明確で、適合判断に時間がかかる
- 証跡の改竄不在を証明する手段がなく、提供された証跡の真正性を前提として監査を行わざるを得ない

## k1s0 でこう変わる

- 外部監査人専用ポータルから業務管理者の自主点検とは独立に audit hash chain を検索できるため、選択性バイアスが排除される
- 業界規制別チェックリストへの証跡マッピングが自動化されており、照合作業時間が大幅に削減される
- hash chain と RFC 3161 タイムスタンプにより証跡の真正性が技術的に保証されており、改竄不在を前提として監査を進められる
- 外部監査人の独立抽出結果と業務管理者の自主点検結果を比較するダッシュボードが提供される

## Trigger

ISO 9001 / GMP / HACCP / ISO 14001 の外部審査時（審査契約に基づく年次実施スケジュールをトリガーとする）

## 想定頻度 / 典型きっかけ / 頻度根拠

- 想定頻度: 年次
- 典型きっかけ: 「ISO 9001 認証更新審査（3 年ごとの更新 + 年次サーベイランス審査）」「食品製造業の GMP / HACCP 年次外部審査」
- 頻度根拠: ISO 9001 等の認証制度では年次の外部審査が義務付けられている

## 個人 KPI / 達成感

- 業界規制チェックリスト全項目の証跡マッピングと適合性判断完了
- 自主点検との差分（業務管理者が見落とした証跡 / 外部監査人が独立抽出した追加証跡）の識別
- 監査報告書（初版）の審査終了後 5 営業日以内発行

## 工数 / 関与人数 / コスト感

- ISO 9001 サーベイランス審査（1〜2 日）: 1〜2 営業日
- ISO 9001 更新審査 / GMP 年次審査（2〜3 日）: 2〜3 営業日
- 関与人数: 1〜3 名（外部監査人 + 必要に応じて補助審査員）

## 前提

- 業務管理者が自主点検を完了しており（シナリオ 10 の出力が準備されている）、自主点検資料が外部監査人に事前提供されている
- 外部監査人専用の短期 credential が発行されており、audit hash chain 検索 UI へのアクセスが可能
- 審査対象の業界規制（ISO 9001 / GMP / HACCP / ISO 14001）のチェックリストテンプレートが Backstage に設定されている

## 流れ

1. 審査開始前に業務管理者の自主点検資料を受け取り、内容を確認する
2. 外部監査人専用ポータルの audit hash chain 検索 UI を開き、審査対象期間と業界規制を指定して独立証跡抽出を実施する
3. 業界規制チェックリストへの証跡マッピングが自動生成されたものを確認する（業務管理者の自主点検とは独立に実施）
4. 自主点検との差分を比較ダッシュボードで確認する
5. 差分がある項目（業務管理者が見落とした / 外部監査人が独立抽出した）について、業務管理者に追加説明を求める
6. 現場インタビュー（品質保証担当者 / 現場作業者）で証跡の内容を実際のプロセスと照合する
7. チェックリスト全項目の適合 / 不適合を判断し、不適合事項を記録する
8. 審査終了後に観察事項と不適合事項のサマリを業務管理者にフィードバックする
9. 監査報告書を作成し発行する（審査終了後 5 営業日以内）

## 独立性宣言

外部監査人は本シナリオにおいても独立性宣言を確認済みであること。業務管理者の自主点検資料を参照するが、独立証跡抽出は外部監査人が単独で実施し、自主点検の内容に引きずられない判断を行う。

| 証拠番号 | 証拠種別 | 取得日時 | 取得方法 | 保管場所 | 完全性確認 |

| EVD-060 | 独立証跡抽出 CSV | 抽出日時を記録 | 外部監査人ポータル | 監査人ラップトップ（暗号化） | SHA-256 hash を記録 |
| EVD-061 | チェックリスト照合結果 | 照合日時を記録 | 外部監査人ポータル出力 | 監査人ラップトップ（暗号化） | SHA-256 hash を記録 |

## 期待結果 / 観測指標 / 受入条件

- 業界規制チェックリスト全項目の適合 / 不適合が判断されている
- 独立証跡抽出と業務管理者自主点検の差分が識別されている
- 不適合事項が業務管理者にフィードバックされている
- 監査報告書が審査終了後 5 営業日以内に発行されている
- 受入条件: 外部監査人が独立の技術的証跡確認に基づいて適合性判断を行えたこと

## 失敗時の挙動 / escalation

- **重大な不適合（ISO 9001 の重大 NC）が発見**: 外部監査人は即座に業務管理者と経営層に書面で通知し、是正処置の期限（通常 90 日）を設定する
- **audit hash chain に gap が発見**: 01 のシナリオと同様に security 担当者に通知し、gap の範囲と重大性を評価する
- **独立証跡抽出で自主点検に含まれない重大な証跡が発見**: 業務管理者に追加説明を求め、説明が不十分な場合は不適合として記録する

## 失敗パターン（3 例）

1. **自主点検資料に依存して独立証跡抽出をスキップする**: 業務管理者が都合の悪い証跡を除外している場合に気づかない。独立証跡抽出は自主点検とは完全に独立に実施することを審査手順書に明記する
2. **現場インタビューなしに書類だけで適合性を判断する**: 実際の現場プロセスが書類と乖離している場合に気づかない。現場インタビューを審査の必須ステップとして手順書に明記する
3. **不適合事項を審査報告書発行前に業務管理者に修正させる**: 修正後の状態で合格とみなすと、監査の実効性が失われる。発見された不適合事項は審査報告書に事実として記録し、是正処置の完了を別途確認する
