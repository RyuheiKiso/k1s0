# a11y / i18n 修正

## 一文方針

CI の axe-core 自動検査 fail または i18n 翻訳キー未定義を起点に、個別 override ではなくデザインシステム側の color token / component 仕様を修正し、axe-core CI green と Web Vitals 閾値を両立させる。

## Trigger（発火条件）

CI の axe-core 自動検査が fail した、または国際化（i18n）の翻訳キー未定義が検出された時。

## 想定頻度 / 典型きっかけ

想定頻度: イベント駆動（CI fail 時）。典型きっかけ: 「axe-core が aria-label 欠落 x 3 / color contrast 違反 x 1 を検出し merge が阻止された」

## 主役 / 関与者

- **主役**: tier3 担当者（ジュニア級）
- **関与**: デザインシステム担当者（color token / component 変更）/ dual reviewer

## 前提

- axe-core が CI に組込済み（WCAG 2.1 AA 基準）
- デザインシステムの color token と component 仕様が一元管理されている
- i18n locale file が共有リポジトリで管理されている
- （責務境界: [README 重要原則](./README.md#重要原則-tier3-が所有するもの--所有しないもの) を参照）

## 流れ

1. axe-core fail: 違反 rule（aria-label 欠落 / color contrast / keyboard navigation）を特定
2. 修正方針を決定（role / aria-label / tabIndex / focus management / color token 変更）
3. デザインシステムの color token / component 仕様に反映（個別 override ではなくシステム変更）
4. pseudolocalization テスト: i18n key の文字列を長い疑似言語に置換して layout が崩れないか確認
5. 翻訳キー未定義: locale file に key を追加（英語 fallback 必須 / 機械翻訳を使わず担当者が意味を確認）
6. axe-core CI が green になるまで修正を繰り返す（Web Vitals 閾値も再確認）
7. dual reviewer sign-off

## 期待結果 / 観測指標

- axe-core: WCAG 2.1 AA 違反 0 件
- pseudolocalization: 全画面で layout 崩れ 0 件
- 翻訳キー: 英語 fallback 必須 / 未定義キー 0 件
- Web Vitals: LCP ≤ 2.5s / INP ≤ 200ms / CLS ≤ 0.1
- dual reviewer 2 名 sign-off 完了

## 失敗時の挙動 / escalation

- WCAG 2.1 AA 違反のまま merge → CI merge 阻止。**escalate 先**: デザインシステム担当者に Mattermost `#a11y-fail` で連絡（**SLA**: 24h 以内）。**runbook**: Backstage runbook `a11y-wcag-violation` を参照
- Web Vitals 閾値違反 → merge 阻止、ボトルネック特定。**escalate 先**: tier2 担当者に Mattermost `#perf-review` で相談（**SLA**: 48h 以内）
- color token の個別 override → lint 検出 → merge 阻止。**escalate 先**: デザインシステム担当者に Mattermost `#a11y-fail` で修正依頼（**SLA**: 24h 以内）
- 機械翻訳のまま merge → レビューで差し戻し。**escalate 先**: i18n 担当者に Mattermost `#i18n-review` で翻訳依頼（**SLA**: 48h 以内）
